This model describes a system for managing and defining digital images intended for use as graphical icons within a software application or modeling environment. It provides a structured way to handle all the information needed to locate, interpret, and display a picture.

The system is centered around two main concepts: the 'Image' and the 'Icon'.

An **Image** is the fundamental component, representing a single digital picture. It's designed to be flexible, allowing the actual picture data to be either embedded directly within the system or stored externally and referenced via a web address (URI). To ensure the picture can be correctly displayed, the 'Image' definition also includes critical technical details, such as its file format (like PNG, JPEG, or SVG) and its data encoding scheme (such as Base64), which is important when image data is stored as text.

Building on this, an **Icon** acts as a set of display rules that uses one or more 'Image' definitions. It's designed to associate a visual representation with another object. An 'Icon' can specify both a primary, full-sized image to be used as the main visual for an object, and an optional smaller image. This smaller image is intended to be used as an adornment or a status badge, much like the shortcut arrow or sync symbol that can appear on a desktop file icon.

In essence, this is a framework for handling the visual assets used to represent elements in a graphical interface. It ensures that any icon is self-contained and has all the necessary information for a system to render it correctly, whether as a primary symbol or a small decorative marker.
