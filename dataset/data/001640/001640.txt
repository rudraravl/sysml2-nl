This is an Arduino-based environmental monitoring system designed for real-time surveillance of indoor conditions such as temperature, humidity, and ambient light levels. Its primary purpose is to ensure that environmental parameters remain within a safe and comfortable range for sensitive equipment or living spaces.

The system is built around a central Arduino microcontroller, which acts as the brain, processing data and controlling all other components. It gathers information from a dedicated temperature and humidity sensor and a separate light sensor. These real-time measurements are continuously shown to the user on a 16x2 character LCD display.

A key feature of the system is its automated alert capability. If the measured temperature or humidity exceeds predefined safe thresholds, the system immediately activates both an audible alarm through a buzzer and a visual warning using a red LED indicator. This provides an immediate notification of an environmental issue.

In addition to local monitoring and alerts, the system can transmit its sensor data, complete with a timestamp, via a serial communication port. This allows it to be connected to an external computer or data logger for long-term analysis and record-keeping. The system operates in a continuous cycle, moving through different states such as initialization, normal monitoring, and an active alert mode when conditions are breached.
