This is a model of a conventional, configurable automobile designed for transporting a driver and passengers. It features a traditional rear-wheel-drive powertrain, starting with a fuel tank that supplies an internal combustion engine, which can be configured with either four or six cylinders.

The engine's power is transferred through a transmission (with options for automatic or manual variants), down a driveshaft, to a differential in the rear axle assembly. The differential then distributes torque to the two rear wheels. The vehicle's chassis includes distinct front and rear axle assemblies, wheels, and a body assembly that incorporates safety features like bumpers, seat belts, and airbags, as well as security systems like an alarm and keyless entry.

A central software-based vehicle controller manages the car's operations. This includes a cruise control system that uses a speed sensor to maintain a set velocity. The vehicle operates in several states: it is `off` when parked, transitions to a `starting` state when the driver presses the brake and turns the ignition, and enters an `on` state for driving. While running, it continuously monitors its health, for example, by sensing its temperature, and can enter a `degraded` state if it overheats or a `maintenance` state when service is due. The model also defines the vehicle's mission, which involves a driver and passengers getting into the car, driving to a destination, and exiting.
