This model represents a foundational, standardized system of unit prefixes used for scaling measurements, as specified by the ISO/IEC 80000-1 international standard. This is not a physical object, but rather a formal library of definitions used in science, engineering, and computing.

The system is comprised of two distinct sets of prefixes:

1.  **Decimal Prefixes:** This is the common set of SI (International System of Units) prefixes based on powers of ten. It includes prefixes for very small quantities, such as `milli` (one-thousandth), `micro` (one-millionth), and `nano` (one-billionth), as well as prefixes for very large quantities, like `kilo` (one thousand), `mega` (one million), and `giga` (one billion).

2.  **Binary Prefixes:** This set is specifically designed for computing and data technology to represent multiples based on powers of two (specifically 1024). It includes prefixes like `kibi` (1024), `mebi` (1024 x 1024), and `gibi` (1024 x 1024 x 1024), which remove the ambiguity that arises when using decimal prefixes like "kilo" to describe digital information.

In essence, this system provides a universal language for concisely representing very large or very small numbers across various technical fields.
