This model describes a system of interconnected data nodes. Each node is a basic building block that has two key properties: a text label and a link to another node of the same type. This structure allows for the creation of chains or nested hierarchies of these nodes.

The system is configured with three specific nodes: 'a', 'b', and 'c'.
*   Node 'a' serves as a foundational element.
*   Node 'c' is a standalone node containing the text label "test2".
*   Node 'b' is explicitly linked to node 'a', forming a simple two-node chain. Node 'b' itself has an empty text label.

Additionally, the system defines a calculation process. This process takes any node and a numerical input to produce a specific numerical result. In this configuration, the process is used to analyze the foundational node 'a' with two different numerical inputs (2 and 1), generating two distinct results named 'f' and 'g'.
