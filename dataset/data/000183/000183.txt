This model describes a data processing and storage system, which is composed of a computer and a dedicated storage unit.

The computer subsystem is responsible for the primary processing and running the system's software. Its operation depends on the overall software design of the system.

The storage subsystem is specifically designed to handle and persist information according to predefined formats. It must conform to specific structures for how general data is organized (the DataSchema) and how communication messages are formatted (the MessageSchema). This ensures that any information stored or managed by this unit is consistent and well-structured.
