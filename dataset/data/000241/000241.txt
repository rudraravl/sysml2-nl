This system describes a physical control knob for adjusting the vertical tilt of a vehicle's headlights.

The knob allows a driver to change the angle of the headlight beams. A key feature of this system is that it has a built-in safety limitation. The tilt angle is strictly restricted to a predefined range, ensuring it can only be set between a minimum of 50 degrees and a maximum of 80 degrees. This prevents the driver from setting the headlights too low or, more importantly, too high, which could dazzle oncoming traffic.
