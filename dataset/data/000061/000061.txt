This model describes a family of configurable product components, such as different types of engine blocks.

The system defines a base template for a "Standard Component." This standard component has two key properties: a fixed characteristic (let's call it 'Property N') with a value of 20, and a configurable characteristic ('Property M') which has a default value of 10.

Based on this template, two specific components are created:

1.  A customized version of the "Standard Component." This specific part is modified so that its 'Property M' is explicitly set to 20, overriding the standard default value of 10.

2.  A new, specialized type of component called the "Advanced Component." This advanced version is based on the standard one but changes the design rule for its default values. For any "Advanced Component," its 'Property M' now defaults to whatever the value of 'Property N' is. A new, off-the-shelf instance of this "Advanced Component" is then created. Since it uses its new default rule, its 'Property M' is automatically set to 20 to match its 'Property N'.
