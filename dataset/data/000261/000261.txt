This model describes a vehicle performance timing system, such as one used for racing, lap timing, or vehicle testing on a track.

The system operates through several distinct states. Initially, it is in a "ready" mode, armed and waiting for a vehicle to begin its run. When it receives a specific "start" signal—perhaps from a sensor at a starting line or an operator's command—it transitions to a "running" state and begins actively timing.

While the timer is running, two things can happen. If the vehicle completes its run and triggers a "finish" signal (like crossing a finish line sensor), the timer stops, locking in the final time. Alternatively, an operator can use a separate control signal to "pause" the timer, for instance, during a caution period in a race.

From the "paused" state, the same control signal can be used to either "resume" the timing or to end the run completely, moving the system to the "stopped" state. Once the run is stopped and the time is recorded, that same control signal acts as a reset, preparing the system to time the next vehicle by returning it to the "ready" state.
