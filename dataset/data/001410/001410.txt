This is a mobile educational robot designed as a hands-on platform for teaching students STEM concepts like programming, robotics, and problem-solving. The robot is a self-contained, battery-powered unit intended for use in classroom environments.

The robot's core is a central microcontroller that acts as its brain, executing programs created by students. It moves using a two-wheeled differential drive system, with each wheel assembly powered by its own DC motor, allowing it to drive forward, backward, and turn.

For environmental interaction, the robot is equipped with a comprehensive sensor suite. It features three ultrasonic sensors—one facing forward and one on each side—to detect and measure distances to obstacles, enabling it to perform tasks like navigating a maze or avoiding collisions. It also includes a dedicated line-following sensor underneath, which allows it to detect and track a line on the floor.

A rechargeable battery pack powers all the electronic components, including the microcontroller, sensors, motors, and a display module. This display provides status updates and serves as an interface for loading student-written programs onto the robot.

The robot operates in several distinct modes. It can be in a standby state, a programming mode where it accepts new instructions, an active mission execution state, or a charging state. When executing a mission, it continuously cycles through sensing its environment, processing that data based on its program, and actuating its motors to move accordingly. This entire system is designed to be engaging, safe, and reliable for students of various skill levels, allowing them to see their code come to life in a physical, interactive way.
