This model describes a digital timer system designed to measure and track user-specified time intervals. Its core purpose is to count down from a set duration, provide real-time feedback on its progress, and signal when the time has expired.

The system is composed of three main functional components that work together: a User Interface, a Timer Core, and a Clock Source. The Clock Source acts as the system's heartbeat, generating a steady, periodic time pulse, or "tick," which is essential for accurate timekeeping. The Timer Core is the brain of the operation; it receives commands, processes the ticks from the clock, and manages the timer's internal state. The User Interface is the means by which a person interacts with the system, allowing them to issue commands and view the timer's status.

In a typical use case, a user sets a desired duration and sends a "start" command through the User Interface. This command is passed to the Timer Core, which transitions into a "running" state. The Core then begins counting the ticks it receives from the Clock Source to calculate the elapsed time. As it counts, it continuously sends progress updates, including elapsed and remaining time, back to the User Interface for display.

The system supports a full range of timer controls, allowing the user to not only start and stop the timer but also to pause and resume the countdown, or reset it back to its initial state. The timer operates through several distinct states: `idle` (waiting for a command), `running` (actively counting), `paused` (temporarily stopped), and `expired` once the countdown is complete. When the elapsed time reaches the target duration, the Timer Core sends an "expired" signal to the User Interface, which then alerts the user. The system is designed with a specific requirement for accuracy, ensuring the measured time remains within a defined tolerance.
