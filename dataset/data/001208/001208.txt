This model describes a high-performance **Push Broom Scanner**, a sophisticated imaging instrument designed to be mounted on a fast-moving platform, such as an Earth-observation satellite. Its primary function is to capture continuous, high-resolution imagery of the ground below as the satellite orbits. Instead of taking a single snapshot like a camera, it builds a large image by capturing one single line of pixels at a time, using the satellite's forward motion to "sweep" this line across the terrain—much like a push broom sweeps a floor.

The system is composed of several key, interconnected components that work in a precise sequence:

*   An **Optical Assembly** acts as the system's "eye." It's a telescope that gathers light from the Earth's surface and focuses it sharply onto the detector.

*   At the heart of the instrument is a **Linear Detector Array**, which is a single, long row of thousands of highly sensitive light-detecting pixels. As the satellite moves, this array captures a narrow strip of the ground perpendicular to the direction of travel, converting the focused light into a raw electrical signal.

*   This raw, imperfect signal is immediately sent to a **Signal Processing Unit**. This is the system's brain, which performs real-time corrections. It uses data from a dedicated **Calibration Unit** to adjust for imperfections in the detector, removing noise and ensuring that the brightness values are scientifically accurate.

*   The corrected image line is then passed to a high-speed **Data Storage Unit**. This component acts as a buffer, assembling the continuous stream of individual image lines into a complete, two-dimensional image block, referred to as a "swath."

*   A **Platform Interface** provides the system with crucial information about the satellite's speed and altitude. This data is essential for timing the captures perfectly to create a seamless, non-distorted image of the ground.

Operationally, the scanner functions through several distinct states. It starts in an **idle** mode, and before imaging, it enters a **calibrating** state to ensure data accuracy. When commanded, it begins **scanning**, continuously capturing, processing, and accumulating image lines. It can temporarily enter a **storing** state to manage the data flow and includes a **fault** state for safety. This entire process allows the system to generate vast, contiguous image swaths of the Earth with a specified ground resolution (e.g., 10 meters per pixel) and coverage width (e.g., 100 kilometers).
