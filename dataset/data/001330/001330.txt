This is an electronic access control system designed to manage and secure entry into various zones within a building or facility. The system authenticates user credentials to grant or deny access and maintains a detailed log of all attempts.

The system is composed of several key components that work together. Each secure area, or "zone," is equipped with a **Credential Scanner** (such as a card reader) and an **Electronic Door Lock**. These zones can be configured with different security levels, for example, a general entrance, a restricted area, and a high-security zone.

When a person presents their credential to a scanner, the information is sent to a central **Access Control Processor**. This processor is the brain of the system; it validates the credential against a list of authorized users and then checks if that user has the required access level for the specific zone they are trying to enter.

Based on this check, the processor makes a decision. If access is granted, it sends an "unlock" command to the electronic lock on the door. If access is denied, the door remains locked. A key safety feature is that the electronic locks are designed to automatically re-lock after a configurable delay to prevent them from being left open.

Crucially, every access attempt—whether successful or not—is recorded. The processor generates a detailed audit entry including the user's name, the specific zone, the time, and the decision (granted or denied). This information is sent to an **Audit Database** for permanent storage, providing a comprehensive security log.
