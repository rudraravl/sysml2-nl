This model represents a therapeutic Hug Machine, a system designed to provide controlled and adjustable physical embraces for stress relief and emotional support.

The machine consists of two primary robotic arms, each driven by an actuator assembly. These arms are designed to extend, make contact with a user, and apply a calibrated amount of force to simulate a hug. The system is equipped with multiple pressure sensors—on the left, right, and back contact surfaces—to detect when a user is present and to continuously monitor the pressure being applied during a session.

A central control processor acts as the brain of the machine. It takes input from a user interface, where a person can select their desired session mode (such as gentle, moderate, or firm), set the intensity, and define the duration of the hug. The system also supports user profiles, allowing individuals to save their preferred settings for future use.

A dedicated safety controller is a crucial component, constantly monitoring the force from the actuators and the pressure from the sensors. If these readings exceed pre-set maximum safety limits, the controller can trigger an immediate emergency stop, causing the arms to release and retract to ensure user safety.

In operation, a user first sets their preferences. The machine then detects the user's presence and position using its pressure sensors. Once the user is in place, the control processor calculates the appropriate force and commands the arms to gently close and apply pressure. During the hug, the system creates a feedback loop, using real-time sensor data to adjust the actuators and maintain a consistent, comfortable pressure. The session proceeds for the set duration, after which the arms execute a controlled release. The user can also pause, resume, or stop the session at any time through the interface.
