This is a sensing unit designed to measure moisture content on the surface of a leaf, used for applications like monitoring plant health in agriculture or environmental science. The system's core component is a capacitive leaf moisture sensor that directly measures changes in capacitance to determine how wet the leaf is.

The unit is composed of several interconnected modules that work together to produce an accurate measurement. The process begins with the **Leaf Sensor**, which takes a raw reading of capacitance and ambient temperature. This raw, unfiltered data is then sent to a **Signal Conditioner**. This module cleans up the signal by filtering out noise, amplifying it for clarity, and compensating for any variations caused by temperature changes.

Once the signal is conditioned, it is passed to a **Data Processor**. Using stored calibration parameters, this processor converts the cleaned capacitance value into a final, easy-to-understand moisture percentage. The processor also assesses the quality of the measurement.

To ensure accuracy over time, the system includes a **Calibration Manager**. This component stores calibration data, such as reference values for completely dry and wet conditions, and can initiate a recalibration process when needed. The system is designed to maintain its calibration for at least 30 days and supports being recalibrated in the field.

Finally, a dedicated **Output Interface** takes the processed moisture percentage, formats it into a standard format like JSON, and transmits it to an external monitoring system.

The entire unit operates through various states, including initialization on startup, a ready state, an active measuring state, a calibration mode, and an error state if a fault is detected. It is engineered to be highly accurate (within ±2%), fast-responding (under 500ms), and robust enough to operate reliably in a wide temperature range from -20°C to +85°C. The system is low-power, designed to run on a 3.3V to 5.0V DC supply.
