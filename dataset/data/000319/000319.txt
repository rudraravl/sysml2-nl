This model represents a foundational, standardized library of prefixes used for units of measurement, based on the international standard ISO/IEC 80000-1. It's not a physical object but a formal reference system used in science, engineering, and computing to ensure measurements are clear and universally understood.

The library is organized into two distinct categories:

1.  **Decimal Prefixes:** This is the familiar set of SI prefixes based on powers of ten. It includes prefixes like "kilo" (a thousand), "mega" (a million), and "giga" (a billion), as well as smaller ones like "milli" (a thousandth), "micro" (a millionth), and "nano" (a billionth). These are the standard prefixes used for nearly all scientific and everyday measurements, such as kilometers, milligrams, or gigawatts.

2.  **Binary Prefixes:** This group includes prefixes like "kibi," "mebi," and "gibi," which are based on powers of two (e.g., 1024, 1024², 1024³). These were specifically created for computer science and data storage to eliminate ambiguity. For example, a "kibibyte" (KiB) is precisely 1,024 bytes, which is how computer memory is actually structured, distinguishing it from a "kilobyte" (kB) that often means 1,000 bytes.

In essence, this is a definitive dictionary of multipliers that provides the building blocks for expressing very large or very small quantities in a consistent and standardized way across different technical fields.
