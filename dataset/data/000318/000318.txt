This model represents the International System of Units (SI), the globally recognized standard for measurement used in science, technology, and commerce. It's not a physical object but a comprehensive and logical framework for quantifying the physical world.

The system is built upon a foundation of seven base units: the metre (for length), the kilogram (for mass), the second (for time), the ampere (for electric current), the kelvin (for temperature), the mole (for amount of substance), and the candela (for luminous intensity).

From these seven fundamental building blocks, the system defines a vast array of derived units through mathematical relationships. For example, the unit for force, the newton (N), is derived from mass, length, and time (kg·m/s²). Similarly, the unit for energy, the joule (J), is derived from force and distance (N·m). Many of these common derived units are given special names like watt (for power), volt (for electric potential), and pascal (for pressure) for convenience.

To handle measurements of vastly different scales, the system incorporates a standard set of prefixes, such as kilo-, milli-, mega-, and nano-, which can be applied to any unit. This allows for clear expression of everything from the diameter of an atom (in nanometres) to the power output of a power station (in megawatts).

The system is also practical, officially recognizing certain non-SI units that are in widespread use, such as the hour, the day, the litre, and the degree (for angles). For these, it provides precise conversion factors to their corresponding SI units. Furthermore, it defines how different measurement scales relate, such as establishing the exact relationship and zero-point offset between the kelvin and Celsius temperature scales.
