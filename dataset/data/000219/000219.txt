This model represents a vehicle system that is designed around a configurable engine. The main purpose is to perform a trade-off analysis to select the best engine configuration from a set of alternatives.

The system defines two primary engine options: a 4-cylinder engine and a 6-cylinder engine. Both are standard internal combustion engines, composed of a specific number of cylinders, each containing a piston and a connecting rod, all linked to a central crankshaft. The 4-cylinder variant uses a crankshaft designed for four cylinders, while the 6-cylinder variant uses one designed for six.

A formal engineering trade study is set up to compare these two engine options. This analysis evaluates each engine configuration against a set of key criteria, including its power output, mass, fuel efficiency, and overall cost. The goal is to calculate an overall evaluation score for each alternative and select the one that maximizes this score.

Ultimately, the vehicle is designed to be equipped with the single engine configuration that is proven to be the best by this analytical study, ensuring the final design choice is based on a rational evaluation of its performance and cost characteristics.
