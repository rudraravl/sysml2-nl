This model describes a Bhangmeter, a space-based system designed for the detection and characterization of nuclear detonations from orbit. Its primary mission is to continuously monitor the Earth's atmosphere for the unique double-flash optical signature produced by a nuclear explosion.

The system is comprised of several key components working in unison. A high-sensitivity optical sensor, operating in the visible light spectrum, constantly scans a wide field of view. This sensor is capable of sampling light intensity at a very high rate to capture extremely fast events. The raw light data is sent to a high-speed signal processor.

When a potential event (a bright flash) is detected, the processor analyzes the light curve. It specifically looks for the characteristic double-flash pattern: a short, intense first peak followed by a second, broader, and more intense peak. If this signature is confirmed, the system identifies it as a nuclear event. It then uses the timing between the peaks and their intensities to estimate the explosive yield of the detonation. Simultaneously, it calculates the precise geographical location (latitude, longitude, and altitude) of the event.

Once a nuclear event is confirmed and characterized, the system generates a full event signature report. This report is then securely encrypted and transmitted via a communication module to a ground station. The system operates through distinct states: it remains in an "active monitoring" state until a flash is detected, at which point it enters an "analyzing" state. If the event is confirmed as nuclear, it transitions to "transmitting" to send the data before returning to monitoring. This allows for autonomous, real-time detection and reporting, crucial for monitoring nuclear test-ban treaties.
