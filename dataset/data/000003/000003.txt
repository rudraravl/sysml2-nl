This SysML model describes the use cases of an Electrical Impedance Tomography (EIT) system.  The system involves four actors: a Doctor, an EngineerTechnician, a Patient, and the EITSystem itself.

The EIT system's functionality is broken down into six use cases:

* **ApplyElectrodeBelt:**  The EngineerTechnician applies the electrode belt to the Patient.
* **StartMonitoring:** The Doctor initiates the monitoring process.
* **CollectImpedanceData:** The EITSystem collects impedance data.
* **GenerateEITImages:** The EITSystem generates images based on the collected data.
* **AnalyzeEITImages:** The Doctor analyzes the generated EIT images.
* **CalibrateSystem:** The EngineerTechnician calibrates the EIT system.

The model explicitly defines the relationships between actors and use cases.  For example, only the EngineerTechnician can `ApplyElectrodeBelt` and calibrate the system.  The Doctor starts the monitoring and analyzes the images, while the EITSystem is responsible for collecting data and generating images.

Finally, a system boundary, `EITSystemBoundary`, clearly delineates all six use cases as being within the scope of the EIT system.
