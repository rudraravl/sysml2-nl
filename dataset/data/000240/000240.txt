This model describes a foundational framework for defining and managing systems of measurement units and scales, similar to a universal rulebook for physical quantities. It is designed to ensure that values like length, mass, and temperature are handled consistently and accurately within a larger system, such as an engineering or scientific application.

The core function of this framework is to understand and automatically convert values between different but compatible units. For example, it can recognize that "1 foot" and "0.3048 meters" represent the same physical length and can translate between them. It is built upon a set of fundamental "base units" for core quantities (like meters for length, kilograms for mass, and seconds for time). From these, more complex "derived units" (like meters per second for velocity or Newtons for force) are constructed.

A key feature is its ability to support multiple, complete systems of measurement, such as the International System of Units (SI) and the US Customary system, which come pre-defined.

Beyond simple ratio-based units, the framework also handles more complex measurement scales:
*   **Interval scales**, where zero is arbitrary, like temperature in Celsius or Fahrenheit.
*   **Ordinal scales**, which represent ordered rankings rather than precise values, such as the Richter scale for earthquakes or the Beaufort scale for wind force.
*   **Logarithmic scales**, used for quantities that span many orders of magnitude, like decibels for sound.
*   **Cyclic scales**, which wrap around, such as angles measured in degrees from 0 to 360.

Essentially, this is a comprehensive digital library that provides the logic and definitions needed for any system to correctly interpret, compare, and calculate with physical measurements, regardless of the specific unit or scale being used.
