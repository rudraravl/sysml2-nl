This describes a traffic light, a signaling device used to control the flow of traffic. The system defines a standard traffic light by its primary characteristic: its current color, which can be green, yellow, or red.

The model also defines a specialized version of this device, which can be thought of as a dedicated "Go" signal. This specific type of light is permanently fixed in the green state, representing a signal whose only purpose is to indicate that it is always permissible to proceed.
