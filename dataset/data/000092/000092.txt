This model describes a generic, configurable vehicle built from a chassis and an engine. The design allows for different vehicle models to be created by varying these core components.

The fundamental structure of any vehicle consists of a single chassis assembly and a single engine. The chassis is the main frame, which holds exactly four wheels and has the option to include a roll bar for safety. Each wheel is attached with six to ten lug bolts. The vehicle's engine is a cylinder-based design, which can have between four and eight cylinders, allowing for a range of power outputs.

Based on this general design, two specific vehicle models are defined:

*   **Vehicle Model 1** is a lighter-duty configuration. It is equipped with a smaller, 4-cylinder engine. For safety, it can be fitted with an optional light-duty roll bar. This model has a very precise wheel configuration, using exactly 24 lug bolts in total, which means each of its four wheels is secured by 6 bolts.

*   **Vehicle Model 2** represents a more powerful or specialized configuration. It features a larger engine with six to eight cylinders. This model is designed without a roll bar and uses a slightly more flexible wheel attachment system, with each wheel secured by either six or seven lug bolts.
