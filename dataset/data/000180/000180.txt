This model represents a family of vehicles built on a common platform but offered with different powertrain configurations. The core idea is a single vehicle design that can be customized with different engines to create distinct models for the market.

Specifically, the model details two variations:

*   A vehicle equipped with a 4-cylinder engine.
*   A vehicle equipped with a 6-cylinder engine.

In both of these configurations, the engine is connected to a manual transmission. This system allows a manufacturer to produce a base model (perhaps focused on fuel economy with the 4-cylinder engine) and a higher-performance model (with the 6-cylinder engine) while sharing many of the same underlying parts from the parent vehicle family.
