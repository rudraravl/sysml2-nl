This is an IoT-based smart home automation system designed to monitor environmental conditions and intelligently control household devices. The system is built on the IoTivity framework, which allows different types of smart devices to discover, connect, and communicate with each other seamlessly.

The core of the system consists of a central server and a network gateway. The server acts as the brain, managing up to 100 connected devices and orchestrating their interactions. The gateway functions as a communication hub, using the lightweight CoAP protocol to relay information between the server and the various sensors and actuators throughout the home.

The system includes a variety of connected devices:
*   **Temperature and Humidity Sensors:** These devices, placed in areas like the living room and bedroom, periodically sample and report on the ambient temperature and humidity.
*   **Motion Sensors:** Positioned near entrances, these detect movement within a five-meter range.
*   **Smart Light Actuators:** These are controllable smart lights that can be turned on or off and have their brightness adjusted remotely.

When a new device is powered on, it goes through a lifecycle of initializing, discovering the network, and registering with the central server. Once operational, the system enters a continuous monitoring and control loop. For example, it can observe the data from a temperature sensor, and if the data meets certain criteria, it can automatically send a command to an actuator, such as turning on a smart light. The entire system is designed to be highly responsive, with network communication delays kept under 200 milliseconds, and also power-efficient, with a total operational consumption of less than 50 watts.
