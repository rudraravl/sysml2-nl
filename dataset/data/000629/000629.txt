This model describes an automated Hot Air Oven system, typically used in laboratory or industrial settings for thermal processing applications like sterilization, drying, or curing materials.

The system is built around an insulated **Oven Chamber** where items are placed for heating. The core function is to heat this chamber to a precise temperature and maintain it for a user-specified duration. This is achieved by a powerful **Heating Element** which generates heat, and a **Circulation Fan** which distributes the hot air evenly throughout the chamber to ensure temperature uniformity.

A central **Control Unit** serves as the brain of the oven. It continuously receives temperature readings from a **Temperature Sensor** inside the chamber. Based on the user's settings, the controller intelligently switches the heater on and off to reach and maintain the target temperature. It also controls the fan's speed, which can be set to low or high. A **Door Latch** sensor ensures safety by preventing the heating element from operating when the oven door is open.

An operator interacts with the system through a **User Interface**. This interface allows the user to set the desired temperature and the duration of the heating cycle, and to start or stop the operation. The UI also provides real-time feedback, displaying the current chamber temperature, the elapsed time, and the current operational phase.

The oven operates through a defined cycle with several distinct phases:
1.  **Idle**: The system is on but waiting for a command.
2.  **Preheating**: The heater runs at full power to bring the chamber up to the target temperature as quickly as possible.
3.  **Maintaining**: Once the target temperature is reached, the controller cycles the heater to keep the temperature stable for the set duration.
4.  **Cooling**: After the time is up, the heater is turned off, and the fan may continue to run to help cool the chamber down.
5.  **Complete**: The cycle is finished, and the system returns to an idle state.

The system is designed with critical safety features, including an automatic shutdown if the temperature exceeds a maximum safe limit and a door interlock that immediately cuts power to the heater if the door is opened during a cycle.
