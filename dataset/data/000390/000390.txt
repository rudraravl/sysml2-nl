This model describes a versatile, autonomous, four-wheeled ground robot designed to perform tasks at specific locations. It is a self-contained system built on a sturdy chassis that is 80cm long and weighs 45kg.

The robot navigates its environment using a sophisticated sensor suite, which includes a Lidar for 3D environmental mapping and obstacle detection, and a camera for visual data. Propulsion is handled by four individual wheel assemblies, each powered by its own motor controller, allowing for precise movement and maneuvering. The entire system is powered by a high-capacity rechargeable battery pack.

At its core is a central processing unit that acts as the robot's brain. This processor receives task commands, which specify a type of task and a target location. The robot operates through a series of states: it starts in a standby mode, waiting for instructions. Upon receiving a task, it enters an active mode. In this mode, it first plans a safe path to the target location, using its sensor data to identify and avoid obstacles. It then navigates to the destination by controlling its four-wheel drive system. Once it arrives, it executes the assigned task.

A key feature of its autonomous operation is its intelligent power management. The robot constantly monitors its battery level. If the charge drops below 20%, it will automatically pause its current mission and navigate to a charging station. After charging, or upon completing a task, it returns to a standby state, ready for its next command. The system also includes an emergency state to handle critical failures safely.
