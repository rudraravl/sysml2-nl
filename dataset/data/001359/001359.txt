This model describes a fully automated air defense system designed to protect a specific area by autonomously detecting, tracking, and neutralizing airborne threats.

The system is equipped with a multi-layered sensor suite consisting of a long-range radar (up to 50 km) and a high-sensitivity infrared sensor. These sensors continuously scan the environment, with the radar providing broad, all-weather coverage and the infrared sensor offering complementary thermal signature detection to improve identification.

Data from both sensors is fused and processed by a central tracking processor. This processor can simultaneously manage up to 50 distinct target tracks, calculating each object's position, velocity, and trajectory with high accuracy.

Once a stable track is established, it is passed to a threat assessment engine. This engine uses a sophisticated ruleset to analyze the track's characteristics and behavior to determine if it is hostile. If a target is classified as a high-level threat, the engine automatically generates a threat alert.

The alert is then sent to a weapon controller, which manages the system's defensive countermeasures. The controller verifies engagement parameters and, if authorized, issues a fire command to one of two independent missile systems. Each of these systems is armed with multiple interceptor missiles capable of engaging targets up to 45 km away.

The entire process, from initial detection to engagement, is designed to be fully autonomous. The system operates through a sequence of states: it begins by **monitoring** the environment, transitions to **tracking** a potential target, moves to **assessing** the level of threat, and finally enters an **engaging** state to launch a countermeasure. If an intercept is successful, it returns to monitoring; if not, it can re-engage the target.
