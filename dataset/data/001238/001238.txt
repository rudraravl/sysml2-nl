This is a Selsyn Angle Transmission System, an electromechanical device designed to transmit the angular position of a mechanical shaft to a remote location and replicate it precisely without any direct mechanical linkage. It's essentially an "electrical gearbox" used for remote control and position indication, such as showing a ship's rudder position on the bridge or synchronizing the movement of two separate machines.

The system is composed of two main units: a transmitter and a receiver, which are structurally very similar.

The process begins at an **Input Shaft**, which is mechanically turned. This shaft is connected to the **Selsyn Transmitter Unit**. As the input shaft rotates, the transmitter converts this mechanical angle into a unique set of three-phase electrical voltage signals. To do this, both the transmitter and receiver are energized by a common **AC Power Source**, which excites a rotor winding inside each unit.

These three electrical signals are sent over wires to the remote **Selsyn Receiver Unit**. The receiver interprets these signals, which create a specific magnetic field inside it. If the receiver's own shaft is not aligned with the angle dictated by this magnetic field (i.e., not synchronized with the transmitter), an internal force, or **Corrective Torque**, is generated. This torque physically rotates the receiver's shaft, driving it to match the transmitter's position.

Once the receiver's angle matches the transmitter's, the corrective torque disappears, and the system becomes stable. The receiver's shaft is connected to an **Output Shaft**, which now perfectly mirrors the rotation of the remote input shaft. This process is continuous, creating a robust, self-synchronizing system that ensures the output shaft constantly and automatically follows the input.
