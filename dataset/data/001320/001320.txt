This is a wireless environmental temperature monitoring system. It uses a distributed network of sensors to collect temperature data and send it to a central hub for analysis.

The system is composed of two main types of components: multiple Sensor Nodes and a single Coordinator Node.

The Sensor Nodes are small, self-contained, and battery-powered devices intended to be placed in various locations to measure local temperature. Each node is equipped with a thermistor for taking measurements, a microcontroller to process the data, a radio transceiver for wireless communication, and a long-life coin cell battery for power. Periodically, each sensor node wakes up from a low-power state, measures the current temperature, and checks its own battery level. It then packages this information—including the temperature reading, its unique ID, and its battery status—into a data packet and transmits it wirelessly. The nodes are designed to be power-efficient, cycling through states like sleeping, sensing, processing, and transmitting to conserve energy.

The Coordinator Node acts as the central data collection and processing hub for the entire network. It is equipped with a more sensitive radio receiver to listen for transmissions from all the sensor nodes, a more powerful processing unit, and a larger, rechargeable battery. As it receives data packets from the various sensor nodes, the coordinator extracts the individual temperature measurements. It then aggregates this data over a set period to calculate summary statistics, such as the average, minimum, and maximum temperature across the entire monitored area, providing a comprehensive overview of the thermal environment.
