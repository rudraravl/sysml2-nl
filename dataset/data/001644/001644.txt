This model represents a Clipsal C-Bus building automation system, designed for the intelligent control of lighting and other electrical loads in residential and commercial buildings. The system's core principle is distributed intelligence, meaning that control is handled by individual devices communicating over a shared network rather than by a central computer.

The backbone of the system is a two-wire network that carries both power and data. A dedicated C-Bus Power Supply provides regulated low-voltage DC power to all the devices connected to this network.

Interaction with the system is managed through various input devices. These include programmable wall switches that send commands when a button is pressed, and automated sensors like infrared motion detectors. The motion sensors can trigger lighting commands when they detect occupancy and turn them off after a set period of inactivity. The system also includes a schedule controller, which acts like a time clock to execute pre-programmed lighting scenes or events automatically at certain times of the day.

These input devices send command signals over the network to control various output units. These output units are the components that physically manage the electrical power to the lights and appliances. They include dimmers, which can smoothly ramp the brightness of lights up or down, and relays, which simply switch circuits on or off. Each output unit is programmed to listen for commands addressed to specific "groups," allowing a single button press or sensor event to control multiple lights simultaneously.

For more advanced management, a Network Interface allows a computer to connect to the C-Bus network. This enables sophisticated programming, system monitoring, and centralized control if desired. In a typical operation, a user pressing a wall switch sends a command to a specific group, and all dimmers or relays assigned to that group respond accordingly, creating a flexible and highly configurable smart building environment.
