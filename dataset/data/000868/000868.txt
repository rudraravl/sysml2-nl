This is a dry-running protection system designed to safeguard a liquid pump from damage caused by operating without sufficient fluid. The system is built around a central pump and includes a suite of sensors, a controller, an isolation valve, and an alarm unit.

The core function is to continuously monitor the liquid's condition using a flow sensor, a pressure sensor, and a temperature sensor. These sensors feed real-time data to a protection controller, which acts as the system's brain.

Under normal operation, the controller simply monitors the incoming data. If the flow rate drops below 5.0 L/min or the pressure falls below 1.0 bar, the system enters a warning state. If these conditions persist for a few seconds, the controller initiates a protective shutdown. In a more critical scenario, such as the liquid temperature exceeding 80°C, the controller triggers an immediate shutdown to prevent catastrophic failure.

The shutdown sequence is a coordinated action: the controller commands the pump to stop, directs the isolation valve to close (likely to prevent backflow), and activates an alarm unit, which provides both visual and audible alerts to notify operators of the fault condition. The system has distinct operational states, including normal, warning, and shutdown, to manage its response to changing conditions.
