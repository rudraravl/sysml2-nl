This model describes a set of standard data definitions used for classification in two separate domains: information security and academic grading.

The first system is a security classification scheme for labeling documents or data. It defines three distinct levels of sensitivity: unclassified, confidential, and secret. Each level is assigned a specific short code (e.g., "uncl" for unclassified) and a corresponding traffic light color (green, yellow, or red) to provide a clear and immediate visual indicator of the information's sensitivity.

The second system defines a standard set of academic grade points. It maps traditional letter grades—A, B, C, D, and F—to their corresponding numerical values on a 4.0 scale. This system is typically used to calculate a student's Grade Point Average (GPA).
