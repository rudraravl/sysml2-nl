This model describes a basic digital counter system. Its primary function is to maintain a numerical count that can be increased or decreased based on external signals.

The core of the system is a counter component that holds a single integer value. This component has two built-in functions: one to increment its value by one, and another to decrement it by one.

The system operates in a defined behavioral cycle. When activated, it first resets its internal counter to zero. It then enters a passive "wait" state. While waiting, it listens for one of two commands: an "increment" signal or a "decrement" signal.

If the system receives an "increment" signal, it performs the action of adding one to its stored count and then immediately returns to the "wait" state to await the next command. Conversely, if it receives a "decrement" signal, it subtracts one from the count and also returns to the "wait" state. This creates a simple, event-driven system for tracking a value over time.
