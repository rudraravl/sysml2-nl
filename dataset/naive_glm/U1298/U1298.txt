This model describes a complete gas-powered residential lawn mower system, designed to cut a lawn area to a user-specified height. It is composed of several key mechanical and safety components that work together to perform the mowing operation.

The core of the system is a fuel-powered **Engine**, which generates the mechanical power needed for operation. This engine provides rotational torque to drive the cutting mechanism.

The power from the engine is transferred to the **Cutting Deck**, which is the primary grass-cutting component. This deck houses the blades, and its width determines the cutting path of the mower (e.g., 53 cm). The deck is responsible for spinning the blades at a high speed to slice the grass and then discharging the resulting grass clippings.

An adjustable **Height Adjuster** mechanism allows the user to set the desired cutting height for the lawn, typically within a specific range (e.g., 25mm to 100mm). This component physically alters the position of the Cutting Deck relative to the ground.

A critical **Safety Interlock** system ensures the mower can only operate under safe conditions. It verifies that an operator is present (for instance, holding down a safety bar) before allowing the cutting blades to be engaged. The blades will not spin unless these safety conditions are met.

As the mower cuts, the grass clippings are funneled from the Cutting Deck into a **Collection Bag**. This bag has a defined capacity (e.g., 60 liters) and includes a mechanism to detect when it is full.

The overall operation of the lawn mower follows a clear sequence. First, the user sets the desired cutting height. The system then runs a safety check. If the safety conditions are met, the user can start the engine and then engage the blades. The mower proceeds to cut the lawn, and the system is designed to monitor when the collection bag becomes full, pausing the operation so it can be emptied. Once the entire lawn area has been mowed, the operator disengages the blades and shuts down the engine to complete the task. The system is designed to meet key requirements, including cutting grass accurately to the set height and strictly enforcing safety protocols.
