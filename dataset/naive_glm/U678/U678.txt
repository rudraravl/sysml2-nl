This is a multi-sensor flame detector system designed to continuously monitor an environment for the presence of a fire and automatically trigger an alarm. To ensure high accuracy and prevent false alarms, the system relies on a combination of three different sensing technologies.

The system is composed of several key components that work in unison. An infrared (IR) sensor measures heat radiation, a temperature sensor detects significant rises in ambient temperature, and a flicker detector analyzes light patterns to identify the unique frequency at which flames flicker.

Data from all three of these sensors is constantly sent to a central analysis module. This module acts as the system's brain, comparing the incoming sensor readings against pre-set safety thresholds. A flame is only confirmed when the measured IR intensity, temperature, and flicker rate all exceed their specified limits at the same time. This multi-factor confirmation is a critical feature designed to minimize the chance of a false alarm.

Once the analysis module confirms a genuine flame signature, it immediately sends an activation command to a high-output alarm unit. This unit generates both a loud audible siren and a bright, flashing visual strobe light to alert anyone in the vicinity of the danger. The entire system is powered by a dedicated power module that ensures a stable and reliable electrical supply to all components.

Operationally, the system transitions through several states. It begins in a standby mode, moving into active monitoring when engaged. If potential flame characteristics are detected, it enters an analysis state to confirm the threat. If a flame is verified, it triggers the alarm state, which persists until the system is reset, at which point it returns to active monitoring.
