This is a portable Geiger counter, a system designed to detect and measure ionizing radiation in the environment. Its primary function is to provide real-time feedback to the user about the radiation level and issue warnings if it becomes unsafe.

The core of the system is a Geiger-Muller tube, a specialized sensor filled with Neon-Halogen gas. A dedicated high-voltage power supply provides the necessary 450 volts to make the tube operational. When an ionizing particle from the environment passes through the tube, it creates a small electrical pulse.

This pulse is used in several ways. It is sent to an audio indicator, which produces the characteristic "click" sound, providing immediate, real-time audible feedback for each particle detected. Simultaneously, the pulse is sent to a central processing unit. This processor counts the incoming pulses over a 60-second period to calculate the radiation level in Counts Per Minute (CPM). It then converts this CPM value into a more meaningful radiation dose rate.

The calculated measurement is then relayed to both a visual display and an alarm unit. The display provides the user with a clear reading of the current radiation level in CPM. The alarm unit continuously compares this reading against a preset safety threshold (120 CPM). If the radiation level exceeds this threshold, the unit activates an audible alarm to alert the user of potentially dangerous conditions.

The system operates by constantly classifying the measured radiation into different safety levels: background, elevated, warning, and danger, ensuring the user is always aware of their environmental conditions.
