This model describes a hot-cathode ionization gauge system, a scientific instrument used for measuring extremely low pressures in ultra-high vacuum (UHV) environments. The system determines pressure by ionizing the sparse gas molecules within a vacuum chamber and then measuring the resulting electrical current.

The core of the system operates through a sequence of coordinated actions. It begins with a **Filament**, which is heated to a very high temperature, causing it to release a steady stream of electrons. These electrons are then accelerated to high speeds by a positively charged **Accelerating Grid**.

The high-energy electrons pass through an **Ionization Region**, which is directly connected to the vacuum chamber being measured. Here, the electrons collide with the few gas molecules present, knocking electrons off them and creating positively charged ions.

A negatively charged **Ion Collector** electrode attracts these newly created positive ions. As the ions strike the collector, they generate an extremely small electrical current. Because the number of ions created is directly proportional to the density of the gas molecules, this tiny current is a precise indicator of the vacuum pressure.

This faint ion current is far too weak to be measured directly, so it is fed into an **Electrometer**, which is an ultra-sensitive amplifier that boosts the signal to a measurable level. A central **Controller Unit** then reads this amplified signal, converts it into a pressure value using a known calibration constant, and reports the final pressure reading.

The entire system is powered by a dedicated **Power Supply** that provides the specific, stable voltages required for the filament, grid, and collector. The Controller Unit also manages the gauge's operational states, including a `warmup` period for the filament to stabilize, a `measuring` state for active operation, an `off` state, and a `fault` state if an error is detected.
