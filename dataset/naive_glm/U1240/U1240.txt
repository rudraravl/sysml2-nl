This model describes a Universal Mobile Telecommunications System (UMTS), which is a complete 3rd generation (3G) cellular network. Its purpose is to provide mobile users with both voice calling and internet data services over a wide area.

The system consists of three main parts:

1.  **User Equipment (UE):** This represents the mobile devices, like cell phones, used by subscribers. Each device has a unique identity (IMSI) and communicates wirelessly with the network's cell towers.

2.  **Radio Access Network (UTRAN):** This is the network infrastructure that manages the wireless connection to the user devices. It is composed of:
    *   **NodeB:** These are the base stations or cell towers that directly communicate with the mobile phones over a radio air interface. They transmit and receive signals within a specific geographic area or "cell".
    *   **Radio Network Controller (RNC):** This component acts as the "brain" of the radio network, managing a group of NodeB cell towers. It is responsible for critical functions like managing radio resources, controlling handset power levels, and handling "handovers."

3.  **Core Network:** This is the central part of the mobile operator's network that connects the radio network to the wider world. It manages user authentication, call routing, and data connections. It is split into two domains:
    *   **Circuit-Switched Domain:** This handles traditional voice calls, establishing a dedicated connection for the duration of a call.
    *   **Packet-Switched Domain:** This manages all internet data traffic, breaking it down into packets for efficient transmission.

The system's operation involves several key processes. When a user turns on their phone, it goes through a sequence of states: it searches for a cell, registers with the network to get authorized, and then remains connected in a standby mode. To make a call or use data, the system establishes an active session.

During an active session, the RNC continuously performs crucial management tasks. It implements **power control**, instructing the user's phone to increase or decrease its transmission power to maintain a clear signal without wasting battery or causing interference. If a user moves from one cell coverage area to another, the RNC executes a **handover**, seamlessly switching the phone's connection from the old cell tower to the new one without interrupting the call or data session.

The entire system is designed to meet specific performance requirements for coverage radius, the number of simultaneous users a cell can support, and defined data rates for downloads and uploads. It also supports different Quality of Service (QoS) levels, allowing it to prioritize real-time traffic like voice calls over less time-sensitive data like background downloads.
