This is a comprehensive smart lock system designed for secure, keyless entry. It provides access control for a door through multiple authentication methods, including a numeric keypad for access codes, a high-resolution biometric scanner for fingerprints, and a wireless module for remote commands from a device like a smartphone.

The system is a self-contained unit powered by an internal battery. Its core is a central control processor that manages all operations. This processor validates user credentials, whether it's a code entered on the backlit keypad, a fingerprint from the biometric scanner, or a lock/unlock command received over its Bluetooth connection. It stores authorized access codes and fingerprint data internally for verification.

A key safety feature is a magnetic door sensor that ensures the door is fully closed before allowing the motorized lock mechanism to engage its bolt. This prevents the lock from jamming or damaging the door frame.

Operationally, the system transitions through several states. After a successful authentication, it moves to an unlocking state, retracting the lock bolt. Once unlocked, it can automatically re-lock after a 30-second timeout or upon receiving a direct command. The wireless module not only receives commands but can also transmit the lock's current status (e.g., locked, unlocked, jammed, or error) back to a user's device. The entire system is designed to be fail-secure, meaning it remains in the locked state in case of a power failure or system error, ensuring the door remains secure.
