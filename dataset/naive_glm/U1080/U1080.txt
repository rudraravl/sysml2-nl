This model describes a Home Energy Monitor, a device designed to track and display a household's real-time electricity consumption.

The system is composed of several integrated components working together. It features a voltage sensor and a current sensor that continuously measure the electrical parameters directly from the home's main power supply. These measurements are then sent to a central processing unit.

The processing unit is the core of the system, responsible for several key tasks. It calculates the instantaneous power usage from the sensor data and aggregates this information over time. This allows it to compute important metrics such as the total energy consumed, average power, peak power, and the estimated electricity cost. The processor also constantly compares the current power consumption against user-defined thresholds for maximum power or daily cost.

A dedicated user display, such as a 7-inch screen, presents this energy information to the homeowner in an easy-to-understand format. If the processing unit detects that power consumption has exceeded the set limits, it triggers a notification module. This module then issues a visual and audio alert to warn the user about the high energy usage. The entire system is designed to provide homeowners with immediate feedback on their electricity habits, helping them manage costs and make more informed decisions about their energy use.
