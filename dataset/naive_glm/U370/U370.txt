This model describes a Remotely Operated Thermal Imaging Gun Sight (ROTIGS), a system designed for remote surveillance, target acquisition, and engagement. It allows a person to control a weaponized camera from a safe, distant location.

The system is composed of three primary parts: an Operator Station, a Thermal Sight, and a Weapon System.

The **Operator Station** is the user's control center. It includes a display to view the live video feed, a control interface for commanding the system, and a communication link to connect with the other components. From here, the operator sends commands and receives video, targeting information, and system status updates.

The **Thermal Sight** is the "eyes" of the system. It consists of a thermal imager mounted on a movable gimbal, allowing it to pan and tilt. An image processor and tracking computer analyze the thermal feed to help identify and automatically track targets. This unit sends the live thermal video and precise targeting data (including coordinates and whether a target is "locked") back to the operator.

The **Weapon System** is the "gun" part of the assembly. It includes the gun itself, ammunition, a firing mechanism, and a critical safety interlock. This system only receives a command to fire; it doesn't aim itself, as it is physically integrated with the Thermal Sight.

In a typical mission, an operator uses the station to command the Thermal Sight to scan an area. When a potential target is found in the thermal video, the operator can command the system to track it. The sight's computer will then maintain a lock on the target. Only when the system has a confirmed lock and the operator explicitly authorizes it, will a fire command be sent to the Weapon System to engage the target. The system operates through a clear sequence of states, moving from standby to searching, then tracking a target, achieving a lock, and finally engaging, before returning to a searching state.
