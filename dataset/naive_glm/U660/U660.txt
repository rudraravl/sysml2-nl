This is an Electrolyte-Insulator-Semiconductor (EIS) based sensing unit designed for the precise measurement of the pH level in chemical solutions. The system is engineered to provide accurate pH and temperature readings for scientific or industrial analysis.

The core of the unit is a sophisticated EIS sensor element. This element works by detecting changes in electrical capacitance that occur when it comes into contact with a liquid sample. It is constructed from several key components: a p-type silicon semiconductor substrate, a very thin silicon dioxide insulator layer, and a silver/silver chloride reference electrode. The pH of the solution alters the surface potential at the interface between the liquid and the insulator, which in turn changes the capacitance of the structure.

This primary sensor is integrated with a dedicated temperature sensor, as temperature is a critical factor for accurate pH calculation. The raw electrical signal from the EIS sensor, which represents a capacitance value, is fed into a signal conditioner. This component amplifies, filters, and digitizes the weak sensor signal to make it usable for processing. An internal power supply provides the necessary voltage for all components to operate.

The unit operates through a well-defined sequence of states. After being powered on, it enters a warm-up phase to ensure its components are stable. It then transitions to a ready state, waiting for a liquid sample. Once a sample is introduced, it begins measuring, capturing the raw capacitance and temperature data. This data is then processed to calculate the final pH value, which is timestamped and output as a complete measurement result. After processing, the unit returns to the ready state, prepared for the next sample. The system also includes an error state to handle any sensor faults, with the ability to be reset.
