This is a home automation system that uses Universal Powerline Bus (UPB) technology to control electrical devices. The system's primary function is to send digital control signals over a building's existing AC power lines, eliminating the need for dedicated control wiring. This allows for centralized control of lighting, outlets, and other connected appliances.

The system consists of a central controller and multiple smart devices, all connected to the standard electrical wiring, which acts as the communication bus. The controller is the command center, creating and transmitting instructions. The devices, such as dimmable lights and switched outlets, are the endpoints that receive and execute these instructions. Each device has a unique network address.

Communication works by modulating digital command packets onto a high-frequency carrier signal, which is then superimposed onto the standard 120V/60Hz power flowing through the wires. When the controller sends a command—like "turn on the living room light" or "dim the bedroom light to 50%"—it creates a data packet with the target device's address and the specific instruction. This packet is broadcast over the powerline.

All connected UPB devices "hear" this signal, but only the device whose address matches the one in the packet will respond. Upon receiving a valid command, a device will execute it, changing its state (e.g., from off to on) and adjusting its power consumption accordingly. Devices can also report their status back to the controller using the same powerline communication method.
