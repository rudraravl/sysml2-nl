This is an automated lighting control system for an indoor space, designed to provide adequate illumination while maximizing energy efficiency.

The system is composed of several key components that work together. A central **Lighting Controller** acts as the brain of the operation. It receives continuous input from two types of sensors: an **Occupancy Sensor** that detects if people are present in the room, and a **Light Sensor** that measures the amount of ambient or natural light available.

Users can interact with the system through a **User Panel**, which allows them to manually turn the lights on or off, set a specific brightness level, or switch the system to its automatic mode.

The system controls two separate **Lighting Fixtures**, which are dimmable and receive both power and control commands. The entire system is powered by a dedicated **Power Supply** that converts standard voltage to the level required by the fixtures.

In its primary **automatic mode**, the controller's logic is designed for efficiency. If the Occupancy Sensor detects that the room is empty, the controller turns the lights off after a set timeout period. When someone enters the room, the controller checks the reading from the Light Sensor. If there is already sufficient daylight, the lights will remain off or be dimmed to a low level. If the room is dark, the controller will turn the lights on to an appropriate brightness to ensure the space is well-lit.

At any time, a user can override the automatic settings using the User Panel, giving them complete manual control over the lighting. The system is designed to meet requirements for energy efficiency, user comfort, and responsiveness.
