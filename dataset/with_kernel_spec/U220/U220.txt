This model describes a motorized medical examination table designed to safely and precisely position patients for clinical examinations and procedures.

The system is built around a main padded table surface which can support patients weighing up to 250 kg. This surface is mounted on a mechanical base that allows for automated adjustments. The table's movement is handled by two independent motorized systems: a height actuator that raises and lowers the entire table, and a tilt actuator that adjusts the angle of the patient surface. These actuators allow the table to move between various positions, including completely flat, a seated position, and specialized Trendelenburg (tilted head-down) and reverse-Trendelenburg (tilted head-up) configurations.

A central motion controller serves as the brain of the system, receiving commands from an operator panel. This panel allows a healthcare provider to manually adjust the height and angle or select from predefined position presets. The motion controller uses feedback from position sensors to move the table accurately to the commanded location.

Safety is a critical aspect of the design. A dedicated safety controller continuously monitors the patient's weight using a built-in load cell. If the weight exceeds the safe operating limit, or if an operator activates an emergency stop button, the safety controller immediately cuts power to the motors and halts all movement. The entire system is powered by a central power supply that converts standard wall voltage to a safer, low-voltage supply for the motors.

The table operates through a series of states. It remains in an idle state until a command is given. Before any movement, it checks the patient's weight for safety. If the weight is within limits, it proceeds to the adjusting state, moving to the target position. Once the position is reached, it becomes locked until a new command is issued. If an overload or emergency stop is detected at any point, it immediately enters a safe, non-operational emergency state.
