This model describes a Crankshaft Position Sensing Unit, an electronic component essential for modern internal combustion engines. Its primary function is to precisely track the rotational angle and speed of the engine's crankshaft, providing critical data for engine management systems to control ignition timing and fuel injection.

The system works by monitoring a specially designed toothed wheel (a reluctor wheel) attached to the crankshaft. This wheel features a specific pattern of 60 teeth, but with a gap where two teeth are intentionally missing. This gap acts as a unique reference point that the system uses to determine the absolute position of the crankshaft once per revolution.

At the core of the unit is a Hall Effect sensor. As the crankshaft rotates, each metal tooth on the wheel passes by the sensor, generating a small raw voltage pulse. This analog signal is then processed internally. First, it is amplified to a stronger, more usable level. Next, it passes through a filter to remove any electrical noise from the engine environment, ensuring a clean and reliable signal.

The "brains" of the unit is a signal processor that analyzes this cleaned-up signal. It detects the transitions corresponding to each passing tooth and, by measuring the time between them, calculates the crankshaft's real-time angular velocity (RPM). The processor's most important task is to identify the longer-than-usual pause in the signal that indicates the missing-tooth gap has passed the sensor.

The unit operates in several states. When first powered on, it initializes and begins a "synchronizing" phase, searching for this reference gap. Once the gap is detected, the unit is fully "operational" and synchronized, able to report not just the speed but also the precise angular position of the crankshaft. The system is designed to be robust, capable of entering a fault state if an error is detected and attempting to recover. Finally, this processed position and velocity data is sent out to the main engine control unit.
