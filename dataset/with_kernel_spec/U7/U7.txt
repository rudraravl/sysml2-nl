This model represents an autonomous robotic delivery system designed to transport packages from a pickup point to a destination without human intervention. The system consists of a primary delivery robot and an associated charging station.

The core of the system is the wheeled delivery robot, which is capable of carrying packages up to 25 kg. Its operation is managed by a central control subsystem that directs the robot through various states, including being idle, navigating, loading or unloading cargo, returning to base, and charging. If a fault occurs, the robot can enter an error state and notify an operator.

For navigation, the robot is equipped with a sophisticated sensor suite. This includes a LiDAR sensor for 360-degree environmental scanning and obstacle detection up to 5 meters away, front and rear cameras for visual guidance, a high-accuracy GPS module for precise positioning (within 0.3 meters), and an Inertial Measurement Unit (IMU) to track its orientation and motion. A dedicated navigation processor fuses data from these sensors to plan paths, travel to destinations, and avoid obstacles in real-time.

Propulsion is provided by a drive subsystem consisting of two independently controlled electric motors, each connected to a durable rubber wheel. This differential drive setup allows for precise maneuverability. The robot features a secure cargo compartment with a locking mechanism and a sensor to confirm when a package has been loaded or unloaded.

A central power subsystem provides electricity to all components. It is built around a high-capacity 48V main battery that enables the robot to operate for up to 10 hours on a single charge. A power distribution unit routes electricity to the motors, sensors, and control computers. When the battery runs low, the robot can autonomously navigate to a dedicated charging station to recharge.
