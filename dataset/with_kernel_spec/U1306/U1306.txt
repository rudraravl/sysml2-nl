This is a NodeMCU-based weather monitoring system designed to autonomously collect environmental data and transmit it wirelessly to a remote server.

The core of the system is an ESP8266 microcontroller, which serves as the central brain, handling all operations and providing WiFi connectivity. For sensing the environment, it uses a DHT22 sensor to measure both ambient temperature and humidity. The entire device is powered by a standard USB power supply, with an onboard voltage regulator stepping the voltage down to the appropriate level for the sensitive electronics. A simple blue LED acts as a status indicator, providing visual feedback on the system's operations.

In operation, the system first powers on and connects to a specified WiFi network. Once connected, it enters a continuous monitoring loop. At regular intervals, it reads the current temperature and humidity from the sensor. This data is then packaged with a timestamp and transmitted over the WiFi network to a pre-configured server. The system transitions through distinct states, such as initializing, measuring, processing, and transmitting, and includes logic to handle errors like a failed WiFi connection or sensor reading, allowing it to attempt recovery and continue its monitoring task.
