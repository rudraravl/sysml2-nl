Example 3 NL:
This model describes a fuel delivery system, likely for a vehicle or machine, composed of a Fuel Tank Assembly and an Engine.

The system's primary function is to supply fuel from the tank to the engine. The connection between these two components is designed for a circulating fuel flow. A supply line moves fuel from the tank assembly to the engine, and a return line carries any unused fuel back from the engine to the tank. This two-way flow is common in fuel-injected systems to maintain constant pressure and help cool the fuel.

A key feature of this system is that the temperature is monitored at the fuel connection points on both the engine and the tank assembly, indicating that fuel temperature is a critical operational parameter.

A fundamental principle of this system is that the vehicle's total mass is directly calculated by adding together the individual masses of its key parts—the engine and the transmission. The model also demonstrates its ability to handle a collection or fleet of these vehicles, allowing for the tracking and management of the mass for each individual vehicle in the group.

package CalculationExample {
	import ISQ::*;
	import NumericalFunctions::*;
	part def VehiclePart {
		attribute m : MassValue;
	}
	part def Vehicle :> VehiclePart;
	part vehicle : Vehicle {		
		part eng : VehiclePart;		
		part trans : VehiclePart;
	}
	calc def MassSum {
		in partMasses : MassValue[0..*];
		return totalMass : MassValue = sum(partMasses);
	}
	calc ms: MassSum {
		in partMasses = (vehicle.eng.m, vehicle.trans.m);
		return totalMass = vehicle.m;
	}
	part vehicles[*] = (vehicle, vehicle);
	attribute masses1[*] = (vehicles as VehiclePart).m;
	attribute masses2[*] = (vehicles as vehicle).m;
