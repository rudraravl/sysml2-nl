Example 1 NL:
This model describes a specialized quadcopter drone designed for forest fire observation and surveillance.

The drone is built with a standard quad-rotor airframe, consisting of a central body, four arms, and landing gear. It is propelled by four engines, with two propellers rotating clockwise and two counter-clockwise to provide lift and stable, maneuverable flight.

Engineered for extended missions, the drone is equipped with a high-capacity, long-distance battery. A central power management module is responsible for monitoring the battery's charge status and distributing electricity to the four engines and other electronic components.

The drone's "brain" is a flight control unit that manages all aspects of its operation. It relies on a suite of sensors for navigation and stability: a GPS module for determining its location, an Inertial Measurement Unit (IMU) for sensing orientation and movement, and a barometer for precise altitude control. Crucially, the flight control unit constantly receives battery status updates from the power management module, allowing it to manage flight time and execute return-to-base procedures when power is low.

For its primary observation role, the drone is fitted with a camera. It also includes an obstacle avoidance sensor to enhance safety during flight. A complete communication system, with a radio transmitter, receiver, and antenna, enables it to be controlled remotely and transmit data, such as a live video feed, back to an operator.

The system is also designed to support autonomous flight and has dedicated safety modules. For its surveillance role, it carries a camera and an obstacle avoidance sensor to navigate complex environments safely. Communication with a ground station is handled by an onboard radio transmitter, receiver, and antenna.

The power system is a critical component, featuring a rechargeable battery managed by a dedicated power management module. The battery itself is a complex subsystem with its own cells, management system, and safety circuits. It can notify the flight controller when the charge is low. The system supports different battery types, such as a standard version and a heavier, higher-capacity version for long-distance flights.

The drone operates through several distinct modes. It starts in an "off" state, can be switched to "standby," and from there can either enter a "charging" state or be activated to a "ready" state for a mission. Once ready, it can begin "flying," after which it returns to the ready state, prepared for deactivation or another flight.

The specific "Forest Fire Observation Drone" is a high-endurance version of this platform. It is configured as a hexacopter with six engines for increased power and redundancy. To support long surveillance missions, it is equipped with the high-capacity, long-distance battery. For high visibility during operations, its body is specified to be red.

This model describes the system and process for providing transportation with a vehicle. The system involves the vehicle itself, a driver, passengers, and external entities like a fuel station and the general environment.

The primary function is to complete a trip. This process begins with the driver and passengers entering the vehicle. The core part of the operation is the driver actively operating the vehicle to travel to a destination. During this journey, the vehicle may need to be refueled. This is an optional step where the driver takes the vehicle to a fuel station to add fuel before continuing. Once the destination is reached, the trip concludes with the driver and passengers exiting the vehicle.

Example 3 SysML:
package 'Use Case Usage Example' {
	private import 'Use Case Definition Example'::*;
	part def 'Fuel Station';
	use case 'provide transportation' : 'Provide Transportation' {
	    subject vehicle;
		first start;
		then include use case 'enter vehicle' : 'Enter Vehicle' {
		    subject vehicle;
			actor :>> driver = 'provide transportation'::driver;
			actor :>> passengers = 'provide transportation'::passengers;
		}
		then use case 'drive vehicle' {
            subject vehicle;
			actor driver = 'provide transportation'::driver;
			actor environment = 'provide transportation'::environment;
			include 'add fuel'[0..*] { 
                subject vehicle;
				actor :>> fueler = driver;
			}
		}
		then include use case 'exit vehicle' : 'Exit Vehicle' {
            subject vehicle;
			actor :>> driver = 'provide transportation'::driver;
			actor :>> passengers = 'provide transportation'::passengers;
		}
		then done;		
	}
	use case 'add fuel' {
		subject vehicle : Vehicle;
		actor fueler : Person;
		actor 'fuel station' : 'Fuel Station';

This model describes a digital camera system built from distinct functional components. Its main purpose is to capture a photograph through an ordered sequence of internal actions.

The camera system is composed of two primary sub-components: an **AutoFocus** module and an **Imager** (the image sensor). When the camera is instructed to take a photo, these components work together in a specific order. First, the AutoFocus module performs its function to adjust the lens and achieve a sharp focus on the subject. Once focusing is complete, the Imager then executes its action to capture the light and record the final digital image. This demonstrates a collaborative process where specialized parts are responsible for different steps of a single, high-level operation.
