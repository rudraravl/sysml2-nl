This contract is a liquid staking protocol for a base asset, custodying deposited base assets and issuing a liquid receipt token in return. It maintains individual user balances for the receipt token, a total supply for the receipt token, and a global exchange rate between the base asset and the receipt token. Callers can deposit base assets to receive receipt tokens, and redeem receipt tokens for base assets. A designated operator can rebase the exchange rate to reflect staking rewards, and the owner can set the operator address. The minimum deposit amount for base assets is 0.001 units. A 0.1% fee is applied to all redemptions, deducted from the base asset amount. The contract announces deposit events, redemption events, and rebase events, including the affected addresses and amounts.
