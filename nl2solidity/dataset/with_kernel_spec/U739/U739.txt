This contract is a collateralized debt position manager, holding deposited collateral tokens and issuing synthetic debt tokens. It maintains individual user positions, tracking deposited collateral, outstanding debt, and liquidation thresholds for each account, along with global configuration parameters for each supported collateral and debt token pair. Callers can deposit collateral, borrow debt tokens against their collateral, repay debt, withdraw excess collateral, and liquidate undercollateralized positions. Only a designated operator can add new collateral or debt token types, adjust collateralization ratios, or pause borrowing. The minimum collateralization ratio for any position is 150%, and a 0.5% liquidation fee is applied to the liquidated amount. The contract announces deposit events, borrow events, repayment events, and liquidation events, including the affected user, token amounts, and new position state.
