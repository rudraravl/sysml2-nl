This contract facilitates decentralized validator operation by distributing duties across multiple operators, and it custodies deposited Ether. It maintains a registry of registered operators, a mapping of validator keys to their assigned operator sets, and a record of each operator's performance metrics and associated stake. Callers can register as an operator, deposit Ether to fund a validator, propose a new validator key for operation, and withdraw their deposited Ether if their validator is no longer active. A designated administrator can set the minimum stake required for an operator, pause all new validator registrations, and remove a non-performing operator from the registry. The minimum operator stake is 32 Ether, and a 0.5% fee is applied to all Ether withdrawals. The contract announces when a new operator registers, when a validator key is assigned to an operator set, and when an operator's performance metrics are updated.
