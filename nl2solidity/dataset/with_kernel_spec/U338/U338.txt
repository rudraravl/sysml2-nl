This contract facilitates the creation and management of non-fungible token collections, holding no custodied assets itself. It maintains a registry of deployed collection contracts, each with its associated creator, a royalty percentage, and a maximum supply. Callers can deploy a new collection contract, mint tokens within an existing collection if they are the creator, and transfer ownership of a collection to another address. A designated operator can pause all minting activity across all collections and update the royalty percentage for any collection. Each collection must specify a royalty percentage between 0 and 10 percent, inclusive, and a collection's maximum supply cannot exceed 10,000 tokens. The contract announces when a new collection is deployed, when a token is minted, and when a collection's royalty percentage is updated.
