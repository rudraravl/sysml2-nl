This contract facilitates the launch of new tokens through a bonding curve mechanism, holding deposited base currency and newly minted project tokens. It maintains a record of each participant's purchased token balance, their deposited base currency, and the current price and supply of the project token on the bonding curve. Callers can deposit base currency to purchase project tokens, withdraw their project tokens, and claim any remaining base currency after a project concludes. A designated operator can set the initial project token supply, define the bonding curve parameters, and initiate the project launch. The bonding curve will have a maximum price increase of 10x from its starting price. A 2% fee on all purchases is directed to a treasury wallet. The contract emits an event when a new project token is launched and when a purchase or withdrawal occurs.
