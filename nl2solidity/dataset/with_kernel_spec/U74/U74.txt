This contract manages a decentralized gaming platform, holding deposited funds for players to use in various games. It maintains individual player balances, a global treasury balance, and configuration settings for each game type. Callers can deposit funds, withdraw their available balance, and initiate game plays by specifying a game type and a bet amount. A designated operator can add new game types, update game parameters like minimum and maximum bets, and set the platform's house edge. The minimum bet for any game is 100 units of the deposited currency, and the maximum house edge across all games is 5%. The contract announces when a player deposits funds, when a player withdraws funds, and the outcome of each game played, including the player's win or loss.
