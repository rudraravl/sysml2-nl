This contract creates and manages liquidity pools for exchanging stable-value tokens, holding deposited tokens as reserves. It maintains a record of each pool's deposited token balances, a global list of available pools, and configuration parameters for each pool. Callers can deposit stable-value tokens into a pool, withdraw their share of tokens from a pool, and exchange one stable-value token for another within a pool. A designated owner can create new pools, set pool parameters such as the amplification factor, and update the contract's fee recipient. The maximum number of tokens in any pool is 8, and the default swap fee is 0.04%. The contract emits an event whenever tokens are deposited, withdrawn, or exchanged, including the pool identifier, the tokens involved, and the amounts.
