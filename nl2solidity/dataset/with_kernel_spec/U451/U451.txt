This contract facilitates cross-chain asset transfers between an Ethereum-based network and a zero-knowledge rollup network, holding transferred tokens in escrow on the source chain. It maintains a mapping of asset addresses to their corresponding rollup network addresses, a record of each pending deposit including the recipient and amount, and a configurable withdrawal delay for each asset. Callers can initiate a deposit of supported tokens from the Ethereum-based network to a specified address on the rollup network, and can claim a withdrawal on the Ethereum-based network after a corresponding burn on the rollup network. A designated operator can add new supported tokens, update the rollup network address for an existing token, and set the withdrawal delay for any token. The maximum withdrawal delay for any asset is 7 days, and a deposit must be at least 100 units of the deposited token. The contract emits an event upon each successful deposit, indicating the sender, recipient on the rollup network, token, and amount.
