This contract facilitates decentralized token swaps and provides liquidity for trading pairs, custodying deposited tokens within its pools. It maintains state for each trading pair, including token reserves, accumulated fees, and liquidity provider token balances for each user. Callers can add liquidity to a pool, remove liquidity from a pool, and swap tokens between pairs. Only the owner can create new trading pairs and adjust the swap fee, which is initially set to 0.3% and can be changed in increments of 0.01% up to a maximum of 1%. The contract announces events for liquidity additions, liquidity removals, and token swaps, including the amounts involved and the users performing the actions.
