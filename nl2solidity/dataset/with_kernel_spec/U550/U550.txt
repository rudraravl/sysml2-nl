This contract is a token launchpad that custodies newly minted tokens and a reserve of a base currency. It maintains a record of each launched token's supply, its current price in the base currency, and the base currency balance held for each token. Callers can launch a new token by providing an initial amount of the base currency and specifying the total supply of the new token, and they can swap the base currency for any launched token or swap any launched token back to the base currency. The contract owner can pause all token launches and swaps, and can set the launch fee. A launch fee of 0.5% of the initial base currency provided is charged for each new token launch, and a minimum of 100 base currency units must be provided to launch a token. The contract emits an event when a new token is launched, when a swap occurs, and when the owner updates the launch fee.
