This contract establishes a decentralized domain name service, holding ownership records for unique, human-readable names and their associated subdomains. It maintains a registry of owned top-level domains, each mapping to an owner and a list of subdomains, and also stores configuration parameters like registration fees. Callers can register a new top-level domain, transfer ownership of a domain, create a subdomain under a domain they own, and set resolution data for any domain they control. Only the designated administrator can set the base registration fee and withdraw collected fees. New top-level domain registrations cost 0.01 ETH, and a domain name must be at least 3 characters long. The contract emits an event whenever a new domain is registered or its ownership is transferred.
