This contract is a decentralized exchange order book for a single token pair, custodying deposits of both tokens. It maintains individual account balances for each token, a list of open buy orders, and a list of open sell orders, each with a price and quantity. Callers can deposit tokens, withdraw tokens, place a buy order, place a sell order, and cancel an open order. A designated operator can pause all trading operations. Order prices must be positive and divisible by 0.0001, and order quantities must be positive and divisible by 1. The contract emits an event when an order is placed, an order is canceled, or an order is filled.
