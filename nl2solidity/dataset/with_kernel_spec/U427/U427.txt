This contract is a liquid staking mechanism for a base network asset, holding deposited base network assets and issuing a corresponding liquid staking token. It maintains a total supply of the liquid staking token, a total amount of deposited base network assets, and a per-account balance of the liquid staking token. Callers can deposit base network assets to receive liquid staking tokens, and they can redeem liquid staking tokens to withdraw base network assets. A designated operator can adjust the staking yield rate, and the owner can pause all deposit and withdrawal operations. A minimum deposit amount of 0.1 base network assets is enforced for all deposits, and a 0.5% protocol fee is applied to all withdrawals, deducted from the base network assets returned to the user. The contract announces deposit events, withdrawal events, and staking yield rate updates to observers.
