This contract facilitates perpetual squared exposure to a base asset, holding deposited collateral to back these positions. It maintains individual user positions, a global funding rate, and configuration parameters like the base asset and oracle addresses. Callers can deposit collateral, open new positions, close existing positions, withdraw excess collateral, and claim funding payments. A designated operator can update the oracle address and adjust the funding rate calculation parameters. The contract imposes a minimum collateralization ratio of 150% for all open positions and charges a 0.1% fee on all collateral withdrawals. The contract emits events for all deposits, withdrawals, position openings, and position closings, along with the updated global funding rate.
