This contract manages the core game logic and custody of non-fungible tokens representing unique game pieces. It maintains a record of each player's owned game pieces, their current in-game state (e.g., health, upgrades), and a global registry of available piece types and their base attributes. Callers can register new game pieces, initiate game matches by burning specific pieces, and upgrade their existing game pieces. Only a designated operator can define new game piece types and set their initial attributes. A maximum of 10,000 unique game piece types can be registered, and initiating a game match always requires burning at least two game pieces. The contract announces when new game piece types are registered and when game pieces are burned.
