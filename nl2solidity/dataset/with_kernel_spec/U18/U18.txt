This contract is a token locker, designed to custody arbitrary ERC-20 tokens for a specified duration. It maintains records of locked token amounts, the designated unlock time for each lock, and the recipient address for each lock. Callers can deposit tokens into a new lock, extend the unlock time of an existing lock, and withdraw tokens from an expired lock. A designated owner can set the fee percentage for new locks and designate a fee recipient address. The fee for creating a new lock is 1% of the deposited amount, paid in the locked token. The minimum lock duration for any deposit is 30 days. The contract announces when new tokens are locked, when a lock's duration is extended, and when tokens are withdrawn.
