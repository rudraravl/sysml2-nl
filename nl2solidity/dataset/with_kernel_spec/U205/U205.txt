This contract manages a gamified token exchange and farming system, holding deposited fungible tokens and non-fungible game items. It maintains individual player balances for fungible tokens, ownership records for non-fungible items, and a global configuration for exchange rates and farming rewards. Callers can deposit fungible tokens, exchange fungible tokens for other fungible tokens, purchase non-fungible items using fungible tokens, stake fungible tokens to earn rewards, claim earned rewards, and withdraw unstaked fungible tokens or sold non-fungible items. A designated operator can set exchange rates, configure farming reward rates, and mint new non-fungible items. The maximum exchange fee is 0.5% of the swapped amount, and the minimum staking period for rewards is 24 hours. The contract emits events for token deposits, token withdrawals, item purchases, item sales, token exchanges, and reward claims.
