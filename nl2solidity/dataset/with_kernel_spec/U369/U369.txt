This contract facilitates a simple on-chain greeting service with a referral mechanism, holding only the native blockchain token collected as fees. It maintains a record of each user's referral count and a global configuration for the greeting fee and the referral reward percentage. Callers can initiate a greeting, optionally providing a referrer, and claim their accumulated referral rewards. Only the contract owner can set the greeting fee, set the referral reward percentage, or withdraw accumulated fees. The greeting fee is fixed at 0.001 native tokens per greeting, and the referral reward percentage is fixed at 20% of the greeting fee. The contract announces a greeting event when a greeting is successfully performed, including the greeter's address, the referrer's address if any, and the fee paid.
