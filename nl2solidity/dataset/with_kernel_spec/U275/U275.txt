This contract manages a social key exchange, holding fungible tokens deposited by users. It maintains a record of each user's purchased keys, the current price of each key, and a global fee percentage. Callers can purchase keys for a specific user, sell keys they own, and withdraw their share of the collected fees. The contract owner can update the global fee percentage and designate an operator who can pause all key trading. A purchase or sale of keys incurs a 5% fee on the transaction value. The maximum number of keys a single user can own for any other user is 100. The contract announces an event when keys are bought, sold, or when the fee percentage is updated.
