This contract orchestrates permissionless token launches, holding deposited base tokens and newly minted project tokens. It maintains a record of each launch's configuration, including its bonding curve parameters, collected fees, and participant balances. Callers can initiate a new launch, deposit base tokens to purchase project tokens along the curve, withdraw their purchased project tokens, and claim their share of collected fees. The launch creator can set the initial bonding curve parameters and withdraw unsold project tokens after the launch concludes. A designated operator can adjust the global fee percentage, which is capped at 5%, and pause all new launch creations. Each launch must run for a minimum duration of 24 hours. The contract emits an event upon every new launch creation, every token purchase, and every fee withdrawal.
