This contract manages a token launchpad, holding deposited tokens from participants and distributed tokens from projects. It maintains individual participant balances for each project's token allocation, along with global configuration settings for fees and project details. Callers can deposit tokens into a project's launch, commit to a project's token allocation, claim their allocated tokens after a successful launch, and withdraw any unspent deposited tokens. A designated operator can create new projects, set project parameters, and finalize project launches. The maximum number of tokens a single participant can commit to a project is capped at 1000 base units. A 2% fee is applied to all successfully claimed token allocations, payable in the project's token. The contract announces project creation, commitment events, and token claims.
