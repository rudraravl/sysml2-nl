This contract is a token launchpad, holding newly minted tokens and collected funds from participants. It maintains a record of each participant's committed funds, the total funds raised for each launch, and the configuration parameters for each token launch. Callers can commit funds to a specific token launch, claim their allocated tokens after a successful launch, and withdraw their unspent funds if a launch fails. The owner can initiate new token launches, set the token allocation ratio, and finalize successful launches. A token launch must raise at least 100 units of the funding currency to be considered successful, and the owner can set a maximum individual commitment of 500 units for any launch. The contract announces when a new token launch is initiated, when funds are committed, and when tokens are claimed.
