This contract facilitates private transfers of a single specified fungible token by acting as a temporary escrow. It maintains a record of each user's deposit balance, a global total deposit, and a configuration for the current deposit fee. Callers can deposit tokens into the contract, initiate a private transfer by providing a zero-knowledge proof, and withdraw their tokens. Only the contract owner can set the deposit fee, which must be between 0 and 100 basis points, and designate an operator address allowed to pause all transfer operations. The contract announces successful deposits, successful withdrawals, and the initiation of private transfers.
