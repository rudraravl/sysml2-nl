This contract facilitates community-funded projects by accepting contributions of a designated base currency and managing a corresponding project token supply. It maintains a record of each contributor's base currency balance and their proportional share of the project's total token supply, along with a global configuration for the project. Callers can contribute base currency to the project, claim their accrued project tokens, and redeem project tokens for a pro-rata share of the remaining base currency. A designated project owner can configure the project's funding cycle parameters, withdraw accumulated base currency, and mint additional project tokens. The project owner can set a maximum funding duration of 90 days for any single funding cycle. A 5% fee is applied to all contributions, directed to a treasury address. The contract announces when a new funding cycle begins, when contributions are made, and when project tokens are claimed or redeemed.
