This contract is a liquid restaking token that custodies deposited base tokens and issues a corresponding liquid restaking token. It maintains a total supply of the liquid restaking token, a mapping of base token deposits to each user, and a current exchange rate between the base token and the liquid restaking token. Callers can deposit base tokens to receive liquid restaking tokens, withdraw their base tokens by burning liquid restaking tokens, and transfer liquid restaking tokens to other addresses. The owner can pause all deposit and withdrawal operations, set the exchange rate, and update the designated operator. A designated operator can initiate withdrawals of base tokens to external restaking protocols. The exchange rate can only be updated once every 24 hours, and a 0.5% fee is applied to all withdrawals. The contract announces deposit events, withdrawal events, and exchange rate updates.
