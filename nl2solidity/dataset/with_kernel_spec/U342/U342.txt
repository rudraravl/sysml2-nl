This contract creates and manages tokenized portfolios, holding various ERC-20 tokens as collateral for each portfolio token issued. It maintains a registry of all created portfolio tokens, their underlying component tokens and quantities, and the total supply of each portfolio token. Callers can create new portfolio tokens by defining their composition, mint new portfolio tokens by depositing the required underlying assets, redeem portfolio tokens to receive their proportional share of underlying assets, and rebalance an existing portfolio's composition. Only a designated operator can adjust the composition of an existing portfolio token, and only the contract owner can set the creation fee for new portfolio tokens, which is fixed at 0.1% of the total value of assets deposited. A maximum of 10 distinct component tokens are allowed per portfolio. The contract emits events upon portfolio creation, token minting, token redemption, and portfolio rebalancing.
