This contract is a provably fair on-chain game for a single fungible token, holding player deposits and game rewards. It maintains a record of each player's active game session, including their initial wager and their current multiplier, and a global configuration for game parameters. Callers can deposit tokens to initiate a game, make a decision within an active game that affects their multiplier, and withdraw their accumulated winnings or remaining wager. Only the owner can set the base game parameters, such as the initial multiplier range and the maximum number of game steps, and only a designated operator can trigger the random number generation process for each game step. Each game step increases the player's multiplier by a minimum of 5% and a maximum of 20%, and a player's total winnings are capped at 100 times their initial wager. The contract emits an event when a new game session begins, when a player makes a decision, and when a game session concludes, indicating the final multiplier and the amount won or lost.
