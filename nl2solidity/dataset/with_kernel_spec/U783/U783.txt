This contract manages a system for creators to receive recurring support from fans, holding no custodied assets itself. It maintains a record of each fan's active subscriptions to creators, including the amount and duration of each subscription, and a global configuration for system fees. Callers can subscribe to a creator, renew an existing subscription, or cancel a subscription. Only a designated operator can set the system-wide subscription fee percentage and add new creators to the platform. The maximum subscription duration is 12 months, and a 5% system fee is applied to all new subscription payments. The contract announces when a subscription is created, renewed, or canceled, and when the system fee percentage is updated.
