This contract facilitates decentralized token swaps and liquidity provision, holding deposited token pairs in liquidity pools. It maintains records of token balances for each liquidity pool and tracks each liquidity provider's share of those pools. Callers can add liquidity to existing pools, remove their liquidity, and swap one token for another within a pool. The owner can set the swap fee percentage and add new token pairs to be supported. The swap fee percentage is fixed at 0.3% of the swapped amount. A new token pair can only be added if both tokens are ERC-20 compliant and their combined initial liquidity exceeds 100 units of a designated base token. The contract emits an event whenever liquidity is added or removed, and when a swap occurs, including the tokens involved and the amounts transferred.
