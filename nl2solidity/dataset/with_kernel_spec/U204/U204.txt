This contract facilitates the creation and launch of new fungible tokens, holding deposited base tokens and newly minted project tokens. It maintains a record of each participant's base token contributions and their allocated share of project tokens, along with a global configuration for launch parameters. Callers can deposit base tokens to participate in a launch, claim their allocated project tokens after the launch concludes, and withdraw any unspent base tokens if the launch fails to meet its funding goal. Only the designated owner can initiate a new token launch, set the minimum funding goal for a launch, and finalize a successful launch to enable token claims. A launch must reach a minimum funding goal of 100 base tokens within 72 hours to be considered successful, otherwise all deposited base tokens are refundable. The contract announces events for deposits, claims, and launch finalization.
