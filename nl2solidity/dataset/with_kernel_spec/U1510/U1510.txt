This contract manages a decentralized exchange for token pairs, holding reserves of both tokens in each trading pair. It maintains individual liquidity provider balances, global token reserves for each pair, and configuration parameters for fees and minimum trade sizes. Callers can add liquidity, remove liquidity, swap tokens, and query token prices. A designated administrator can set trading fees, pause trading for specific pairs, and update the list of supported token pairs. Trading fees are fixed at 0.3% of the swapped amount, and a minimum trade size of 100 units of the input token is enforced for all swaps. The contract emits events for all liquidity additions, removals, and token swaps, including the amounts involved and the affected token pair.
