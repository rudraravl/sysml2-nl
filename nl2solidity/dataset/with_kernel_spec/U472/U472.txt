This contract is a decentralized exchange for stable value assets, holding reserves of various tokens. It maintains a registry of supported stable tokens, their corresponding reserve tokens, and per-pair exchange configurations including a target price and a deviation tolerance. Callers can exchange one supported token for another, deposit reserve tokens to increase liquidity, and withdraw reserve tokens. A designated operator can add new stable token pairs, update exchange parameters for existing pairs, and pause all exchange operations. The maximum deviation from the target price allowed for any exchange is 0.5%, and a 0.1% fee is applied to all exchange operations, directed to a treasury. The contract announces successful exchanges, liquidity additions, and liquidity withdrawals.
