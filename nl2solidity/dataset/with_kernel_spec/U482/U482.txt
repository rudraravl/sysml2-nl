This contract manages a vault for structured options, holding collateral tokens deposited by users. It maintains individual user balances, active option positions, and a global configuration for available option series. Callers can deposit collateral, open new option positions, exercise expiring options, and withdraw available collateral. A designated operator can create new option series and adjust risk parameters for existing series. The contract charges a 0.1% fee on all collateral withdrawals. New option positions can only be opened if the total collateral in the vault exceeds 100,000 units of the base collateral token. The contract emits events for all deposits, withdrawals, and option position changes.
