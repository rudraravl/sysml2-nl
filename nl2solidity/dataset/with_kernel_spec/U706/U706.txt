This contract facilitates the creation and initial trading of new fungible tokens, holding the initial supply of each launched token and the collected platform fees. It maintains a record for each launched token, including its total supply, current liquidity pool balance, and the creator's address. Callers can launch a new token by providing an initial amount of base currency, contribute additional base currency to an existing token's liquidity pool, or swap base currency for tokens and vice-versa. Only the contract owner can set the platform fee percentage, which is initially 1% and capped at 5%. The contract announces new token launches, liquidity pool additions, and all successful swaps.
