This contract implements an on-chain spot order book for a single trading pair, holding deposited collateral tokens for open orders. It maintains individual account balances for each user, a list of active buy orders sorted by price descending then time ascending, and a list of active sell orders sorted by price ascending then time ascending. Callers can place a limit order, cancel an existing order, or deposit and withdraw collateral tokens. A designated operator can execute a trade between matching orders, settling the tokens between the involved accounts. The minimum order size is 100 units of the base token. A 0.1% fee is charged on each trade, deducted from the received amount for both taker and maker. The contract announces new orders, order cancellations, and executed trades to observers.
