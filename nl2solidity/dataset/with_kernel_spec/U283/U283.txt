This contract manages a decentralized exchange for token swaps, holding deposited tokens within liquidity pools. It maintains records of individual liquidity positions, including token amounts and price ranges, and global pool configurations such as swap fees. Callers can deposit tokens to create new liquidity positions, withdraw tokens from existing positions, swap tokens between supported pairs, and collect accrued swap fees. Only a designated operator can adjust the base swap fee for a pool, which is initially set at 0.05% and cannot exceed 1%. The contract emits an event whenever a new liquidity position is created, and another event for every token swap, detailing the tokens involved and their quantities.
