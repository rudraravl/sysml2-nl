This contract is a liquid staking protocol for a base asset, custodying deposited base assets and issuing a liquid staking token representing staked value. It maintains a total supply of the liquid staking token, the total amount of base asset staked, and a per-user balance of the liquid staking token. Callers can deposit the base asset to receive liquid staking tokens, and they can redeem liquid staking tokens for the base asset. A designated operator can initiate staking of deposited base assets and unstaking operations, and they can update the exchange rate between the base asset and the liquid staking token. The owner can set the operator address and adjust the protocol fee, which is initially 0.1% of all base asset redemptions. The redemption of liquid staking tokens for base assets incurs a 7-day delay. The contract emits an event upon each deposit, redemption, and exchange rate update, including the affected user, amounts, and the new exchange rate.
