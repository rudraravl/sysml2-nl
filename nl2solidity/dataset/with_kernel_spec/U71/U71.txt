This contract is a token bridge for moving wrapped tokens between different blockchain networks, holding deposited native tokens in escrow. It maintains a record of registered token addresses for each supported network, a mapping of wrapped token addresses to their native counterparts, and a configurable fee for each bridge operation. Callers can initiate a transfer by depositing native tokens and specifying the destination network and recipient address, or redeem wrapped tokens by presenting a valid proof of transfer from the origin network. A designated operator can register new token addresses for bridging and update the transfer fee. The maximum transfer fee is 0.5% of the transferred amount, and the minimum transfer amount for any token is 1 unit of that token. The contract emits an event upon successful token deposit and another upon successful token redemption, including the amount, token address, and recipient.
