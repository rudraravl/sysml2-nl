This contract serves as a strategy vault for managing and allocating user deposits into various external yield-generating vaults, and it custodies deposited ERC-20 tokens. The contract maintains a record of each user's deposited amount for each supported ERC-20 token, as well as the current allocation strategy for each external vault. Callers can deposit supported ERC-20 tokens into the contract, withdraw their deposited tokens, and claim any accumulated yield. Only the owner can add new external vaults to the approved list, update the allocation strategy for existing vaults, or set the withdrawal fee. A withdrawal fee of 0.5% is applied to all withdrawals, and the maximum number of supported external vaults is capped at 10. The contract announces deposit events, withdrawal events, and changes to the allocation strategy.
