This contract is for managing interest rate swap agreements, holding deposited collateral tokens. It maintains individual user positions, including collateral amounts and notional values for each swap, and global configuration parameters like supported assets and fee rates. Callers can open new swap positions by depositing collateral, close existing positions to reclaim collateral and settle interest, and add or remove collateral from active swaps. A designated operator can pause all new swap openings and update the supported asset list, while the owner can adjust the base swap fee, which is fixed at 0.05% of the notional value. The minimum collateralization ratio for any swap must always be maintained at 120%, and new swaps can only be opened for a maximum duration of 90 days. The contract emits events upon opening a new swap position, closing a position, and any change to a user's collateral balance.
