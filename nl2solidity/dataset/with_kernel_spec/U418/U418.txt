This contract is a token launchpad, designed to facilitate the initial distribution of new tokens and custodies deposited base tokens and newly minted project tokens. It maintains a record of each participant's base token contributions and their allocated project token entitlements, along with a global configuration for each launch event including the project token address, the base token address, the total project tokens offered, and the target base token raise amount. Callers can contribute base tokens to a live launch, claim their allocated project tokens after a successful launch, and withdraw their base tokens if a launch fails. The owner can initiate new launch events, finalize successful launches, and cancel failed launches, while a designated operator can adjust the contribution period start and end times for an active launch. A launch event must have a minimum contribution period of 24 hours and a maximum of 7 days, and a 5% fee on all successfully raised base tokens is automatically transferred to a designated treasury address upon launch finalization. The contract announces events for new launch creations, contributions received, project tokens claimed, and launch status changes.
