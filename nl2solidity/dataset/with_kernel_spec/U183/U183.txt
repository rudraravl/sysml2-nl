This contract manages a gaming platform's in-game currency, holding a reserve of the primary game token. It maintains individual player balances for the in-game currency and a global configuration for conversion rates. Players can convert the primary game token into in-game currency, and convert in-game currency back into the primary game token. A designated operator can adjust the conversion rate and mint new in-game currency. The conversion rate from the primary game token to in-game currency is fixed at 1 primary game token to 100 in-game currency, and there is a 5% fee on all conversions from in-game currency back to the primary game token. The contract announces conversion events, including the player's address, the amount of primary game token involved, and the resulting in-game currency amount.
