This contract facilitates private, wallet-to-wallet transfers of Ether and approved fungible tokens using one-time redeemable codes, holding deposited assets until redemption. It maintains a record of each unique redeemable code, its associated asset type, deposit amount, and whether it has been redeemed. Callers can deposit assets to generate a new redeemable code, and recipients can redeem a valid code to claim the associated assets. A designated operator can add or remove approved fungible tokens for deposits. Each redeemable code is valid for a single redemption, and a deposit fee of 0.1% is applied to all deposits, with a minimum deposit amount of 0.001 Ether or its equivalent in approved tokens. The contract announces when a new redeemable code has been created and when a code has been successfully redeemed.
