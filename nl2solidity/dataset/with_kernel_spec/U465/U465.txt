This contract facilitates on-demand, verifiable data retrieval by acting as a payment gateway for external data providers. It custodies user deposits of a stablecoin, held in individual user balances. The contract maintains a mapping of user addresses to their deposited stablecoin amounts and a single, global data request fee. Callers can deposit stablecoins into their balance, withdraw any available balance, and request data by paying the current fee. A designated administrator is privileged to set the data request fee and to update the public key used for signature verification. The data request fee must be a positive integer, and the maximum deposit allowed per user is 10,000 stablecoins. The contract announces successful deposits, withdrawals, and data requests, along with the current data request fee whenever it is updated.
