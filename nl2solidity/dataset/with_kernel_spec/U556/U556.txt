This contract facilitates automated trading of non-fungible tokens (NFTs) and custodies deposited NFTs and fungible tokens. It maintains records of individual user positions, NFT liquidity pools, and global configuration parameters. Callers can deposit NFTs or fungible tokens into pools, withdraw their deposited assets, swap fungible tokens for NFTs from a pool, or swap NFTs for fungible tokens from a pool. A designated operator can adjust pool parameters like pricing curves, and the contract owner can set the global protocol fee. Each NFT pool must contain at least one NFT and at least 100 fungible tokens. The protocol charges a 0.5% fee on all fungible token swaps. The contract emits events for all deposits, withdrawals, swaps, and changes to pool parameters or global fees.
