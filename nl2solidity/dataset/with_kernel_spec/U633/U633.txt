This contract manages a token launchpad, holding deposited tokens from participants and the project tokens being distributed. It maintains a record of each participant's deposited amount and their allocated project tokens, along with the total project tokens available for distribution and the current sale phase. Callers can deposit tokens during an active sale phase, claim their allocated project tokens after the sale concludes, and withdraw any unspent deposited tokens if the sale fails to meet its minimum. The contract owner can start and end sale phases, set the project token allocation rate, and withdraw any remaining project tokens after the sale. A minimum deposit of 100 base tokens is required per participant. The project token allocation rate is fixed at 100 base tokens per 1 project token. The contract emits events when tokens are deposited, project tokens are claimed, and sale phases change.
