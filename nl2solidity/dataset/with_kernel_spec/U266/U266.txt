This contract is a launchpad for new tokens, custodying deposited base tokens and newly minted project tokens. It maintains a list of active token launch campaigns, each with its own target raise amount, current raised amount, and a mapping of participant addresses to their deposited base token contributions. Callers can deposit base tokens into an active campaign, claim their allocated project tokens after a successful launch, and withdraw their base tokens if a launch fails. The owner can create new launch campaigns, set their parameters, finalize successful campaigns to enable project token claims, and cancel failed campaigns to enable base token withdrawals. Each launch campaign has a minimum base token contribution of 0.01 base tokens and a maximum contribution of 100 base tokens per participant. The contract emits an event when a new launch campaign is created, when a deposit is made, and when project tokens are claimed or base tokens are withdrawn.
