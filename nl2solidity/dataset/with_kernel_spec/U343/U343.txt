This contract manages a decentralized autonomous organization's treasury of a governance token and a stablecoin, holding both assets in distinct pools. It maintains a record of each member's voting power derived from their staked governance tokens and their stablecoin contributions to various climate-focused initiatives. Callers can stake governance tokens, unstake governance tokens, contribute stablecoins to initiatives, propose new initiatives, and vote on active proposals. Only the owner can set the stablecoin contribution fee, which is initially 0.5% and capped at 2%, and only designated operators can approve new initiatives for voting. The contract emits an event when a new proposal is created and when a vote is cast.
