This contract is a yield-maximizing wrapper for a base staking token, holding deposited base tokens and their yield-bearing derivatives. It maintains a total supply of its own liquid staking token, a record of each user's liquid staking token balance, and a configuration for the looping strategy. Callers can deposit the base staking token to receive the liquid staking token, redeem the liquid staking token for the base staking token, and claim accumulated rewards. A designated operator can initiate and close looping positions, adjust the looping strategy parameters, and withdraw protocol fees. The owner can upgrade the contract logic and set the designated operator. Deposits and redemptions are subject to a 0.5% protocol fee, deducted from the base token amount. The maximum looping leverage allowed is 5x, meaning the total value of borrowed assets in looping positions cannot exceed five times the value of the initially staked base tokens. The contract announces deposit events, redemption events, reward claims, and changes to the looping strategy parameters.
