This contract facilitates the creation and trading of new fungible tokens along a bonding curve, and it custodies the base currency used for purchases and the newly created tokens. It maintains a record of each token's bonding curve parameters, the total supply of each token, and the base currency balance for each token's pool. Callers can create a new token, buy tokens from a curve, sell tokens back to a curve, and withdraw their base currency proceeds. Only an authorized operator, verified by a decentralized identity system, may create new tokens. New token creation requires a minimum initial deposit of 100 base currency units, and all token sales incur a 5% fee on the base currency proceeds, which is directed to the contract owner. The contract announces the creation of new tokens, all buy and sell orders, and any changes to bonding curve parameters.
