This liquid staking contract enables users to deposit a base token and receive a yield-bearing receipt token, which represents their share of the staked assets and any accumulated rewards. The contract maintains a global pool of staked base tokens, a total supply of the receipt token, and a conversion rate between the base token and the receipt token, which accrues value over time. Callers can deposit base tokens to mint receipt tokens, and redeem receipt tokens to withdraw base tokens. The owner can adjust the staking strategy, set the fee percentage for withdrawals, and pause deposits. A withdrawal fee of 0.1% of the base token amount will be applied to all redemptions. The contract emits events for all deposits, redemptions, and changes to the withdrawal fee.
