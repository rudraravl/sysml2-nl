This contract facilitates decentralized token swaps and custodies deposited token pairs. It maintains a separate liquidity pool for each unique pair of tokens, tracking the reserves of each token within the pool and the total supply of liquidity provider tokens for that pool. Callers can add liquidity to a pool, remove liquidity from a pool, and swap one token for another within a pool. The contract owner can set the swap fee percentage and pause all swapping operations. The swap fee is fixed at 0.3% of the input token amount for each trade. Adding liquidity to a pool requires depositing both tokens in the current ratio of the pool's reserves. The contract announces liquidity additions, liquidity removals, and token swaps, including the tokens involved and their amounts.
