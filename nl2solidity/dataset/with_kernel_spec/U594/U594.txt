This contract facilitates the creation and trading of new token pairs, holding deposited base tokens and newly minted project tokens. It maintains a record of each token pair's base token reserves, project token reserves, and a trading fee percentage. Callers can create a new token pair by depositing a minimum amount of base token and specifying a project token supply, add liquidity to an existing pair, remove liquidity from a pair, and swap base tokens for project tokens or vice-versa. The contract owner can set a global trading fee, which defaults to 0.5%, and pause all trading activity. New token pairs must be initialized with at least 100 base tokens. All swaps emit an event detailing the tokens swapped, amounts, and the account performing the swap.
