This contract provides a secure vault for locking fungible tokens, enabling time-based release. It maintains individual lock records for each user, including the locked amount, unlock date, and any associated beneficiary. Callers can deposit tokens into a new lock, extend an existing lock's duration, or withdraw unlocked tokens. A designated administrator can pause all deposits and withdrawals, and can set a global withdrawal fee. The minimum lock duration is 30 days, and the maximum withdrawal fee is 5% of the withdrawn amount. The contract emits an event upon each successful token deposit and each successful token withdrawal.
