This contract serves as a privacy-preserving deposit and withdrawal gateway, holding user-deposited Ether and a single designated ERC-20 token. It maintains a Merkle tree of encrypted notes representing private balances and a public record of each user's total deposited Ether and ERC-20 token. Callers can deposit Ether or the designated ERC-20 token, withdraw their private balances using a zero-knowledge proof, and register a new recipient for a private transfer. Only a designated operator can update the Merkle tree root and process withdrawal requests after verifying the associated zero-knowledge proof. The contract imposes a 0.1% fee on all withdrawals, and the maximum deposit for a single transaction is 100 Ether or 10,000 units of the designated ERC-20 token. The contract emits an event upon each successful deposit, withdrawal, and Merkle tree root update, including the relevant amounts and new state root.
