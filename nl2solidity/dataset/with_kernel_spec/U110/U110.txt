This contract manages a token launch, holding deposited base currency and newly minted project tokens. It maintains a record of each user's base currency contribution and their corresponding allocation of project tokens, along with the current bonding curve parameters and the total base currency raised. Callers can deposit base currency to acquire project tokens, claim their project tokens after the launch concludes, and withdraw their base currency if the launch fails to meet its minimum. A designated operator can set the bonding curve parameters, initiate the launch, finalize the launch, and transfer the raised base currency to a designated recipient. The minimum deposit amount is 100 units of the base currency, and a 5% fee is applied to all base currency withdrawals before the launch concludes. The contract announces when a deposit occurs, when project tokens are claimed, and when the launch state changes.
