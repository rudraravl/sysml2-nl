This contract facilitates a prediction game based on future block hashes, holding user wagers in an escrow pool. It maintains individual user balances, active game rounds with their associated wagers, and a global configuration for game parameters. Callers can place a wager on the parity of a future block hash, claim winnings from past rounds, and withdraw their available balance. Only the owner can set the wager amount, the game duration in blocks, and the commission percentage. The minimum wager is 0.01 ether and the commission on winnings is 5%. The contract emits an event when a new game round begins, when a wager is placed, and when winnings are claimed.
