This contract creates and manages a reserve-backed token, holding a basket of three distinct base tokens: a wrapped BTC, a wrapped ETH, and a stablecoin. It maintains the current balance of each base token held, the total supply of its own reserve-backed token, and a set of configuration parameters for its rebalancing mechanism. Callers can mint new reserve-backed tokens by depositing the required proportion of base tokens, and they can redeem existing reserve-backed tokens for the underlying base tokens. A designated administrator can adjust the rebalancing parameters, but these changes are subject to a 48-hour timelock before becoming active. A one-time minting fee of 0.10% of the value of the minted tokens is charged upon creation. The contract emits events for all minting and redemption operations, and for any changes to the rebalancing parameters.
