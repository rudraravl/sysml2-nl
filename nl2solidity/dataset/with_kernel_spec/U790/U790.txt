This contract manages a vault for creator-economy projects, holding wrapped native tokens and a project-specific fungible token. It maintains individual balances for each user's wrapped native token deposits and project token holdings, along with a global total supply of the project token and a configurable fee percentage. Callers can deposit wrapped native tokens, withdraw their wrapped native tokens, mint new project tokens by locking wrapped native tokens, burn project tokens to unlock wrapped native tokens, and transfer project tokens to other users. Only the owner can set the fee percentage, pause all minting and burning operations, or designate an operator who can also pause operations. A minimum deposit of 0.01 wrapped native tokens is required for minting, and the maximum fee percentage that can be set is 5%. The contract announces deposit, withdrawal, mint, burn, and transfer events, including the sender, recipient, and amount.
