This contract manages a launchpad for new token projects, holding deposited base currency and newly minted project tokens. It maintains a record of each user's deposited base currency, their allocated project tokens, and the total base currency raised for each project. Callers can deposit base currency to participate in a project launch, claim their allocated project tokens after a successful launch, and withdraw their unspent base currency if a launch fails or they choose to exit. The project creator, as a designated operator, can set the project's token allocation, define the launch period, and finalize the launch, transferring the raised base currency to a specified recipient. A project launch must raise a minimum of 100 base currency units to be considered successful, and the project creator must finalize the launch within 7 days of the launch period ending. The contract announces when a new project is created, when a deposit is made, and when a project launch is finalized.
