This contract is a token launchpad and liquidity manager, responsible for creating new token pools and holding the initial supply of launched tokens. It maintains a record of each launched token's associated liquidity pool address and the distribution percentages for swap fees. Callers can launch a new token, which creates a new trading pool and seeds it with the entire initial token supply, and can swap tokens within existing pools. The designated platform administrator can set the platform fee percentage and update the fee distribution percentages for creator, bid wall, and platform shares. A new token launch always deploys one billion units of the new token into the pool as single-sided liquidity, and the platform fee is fixed at 1% of the base asset side of every swap. The contract emits an event when a new token is launched, including its address and the associated pool address, and also emits an event whenever the fee distribution percentages are updated.
