This contract manages a cross-chain automation system, holding deposited tokens that users commit to specific actions on other chains. It maintains a record of each user's deposited balance, the target chain identifier, the specific action parameters, and a unique identifier for each pending cross-chain operation. Callers can deposit tokens, create new automation tasks specifying a target chain and action, cancel their own pending tasks, and claim tokens from successfully completed cross-chain operations. A designated operator can approve or reject cross-chain operation results, and can set the fee percentage for successful operations, which defaults to 0.1% and cannot exceed 1%. The contract emits an event when a new task is created, when a task is cancelled, and when a cross-chain operation's result is processed.
