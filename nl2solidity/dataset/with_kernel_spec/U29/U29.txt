This contract facilitates the launch and initial distribution of new tokens, holding deposited base currency and newly minted tokens. It maintains records of each participant's base currency contribution and their allocated token share, along with global configuration parameters for each launch. Callers can contribute base currency to an active launch, claim their allocated tokens after a launch concludes, and withdraw any unclaimed base currency if a launch fails to meet its minimum target. A designated operator can initiate new launches, set launch parameters, finalize successful launches, and cancel unsuccessful ones. Each launch must have a minimum base currency target of at least 100 base currency units, and a maximum contribution per participant is capped at 1000 base currency units. The contract emits an event when a new launch is started, when a contribution is made, and when tokens are claimed.
