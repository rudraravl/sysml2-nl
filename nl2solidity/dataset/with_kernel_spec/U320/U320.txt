This contract is a stablecoin minting and lending facility, which custodies a base token and issues a stablecoin. It maintains individual balances for the base token and stablecoin for each user, a global supply of the stablecoin, and a configurable collateralization ratio. Callers can deposit the base token, mint the stablecoin against their deposited base token, repay stablecoin to unlock base token, and withdraw their base token. A designated owner can set the collateralization ratio and pause minting. The initial collateralization ratio is 150%, meaning for every 1.5 units of base token deposited, 1 unit of stablecoin can be minted. A 0.5% fee is applied to all stablecoin minting operations, deducted from the minted amount. The contract announces successful deposits, stablecoin mints, repayments, and withdrawals, including the amounts involved and the user's address.
