This contract facilitates the launch of new fungible tokens via a bonding curve mechanism, holding deposited base tokens and newly minted project tokens. It maintains a record of each project's bonding curve state, including total base tokens deposited, total project tokens minted, and the current price, along with global configuration parameters like the launch fee. Callers can launch a new project by depositing base tokens, buy project tokens from an existing curve, sell project tokens back to the curve, and claim their share of base tokens after a project graduates. Only a designated administrator can set the global launch fee and withdraw accumulated launch fees. The launch fee is fixed at 0.5% of the initial base token deposit for new projects. Projects automatically graduate to an external decentralized exchange when their total base token deposits reach 100 base tokens. The contract announces project launches, token purchases, token sales, and project graduations.
