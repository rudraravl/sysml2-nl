This contract manages competitive gaming matches, holding a designated stablecoin for match entry fees and prize pools. It maintains a record of active matches, including their current state, participating players, and the stablecoin amount committed by each player, alongside a global configuration for game parameters. Callers can create a new match, join an existing match by depositing the entry fee, submit game results, and claim their winnings from completed matches. Only a designated operator can create new matches and resolve disputes by unilaterally declaring a match winner. The maximum number of players in any match is fixed at 8. A 5% fee is deducted from the total prize pool of each match before distribution to the winner. The contract announces match creation, player joins, result submissions, and prize claims.
