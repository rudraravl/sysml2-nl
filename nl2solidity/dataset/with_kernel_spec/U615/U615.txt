This contract manages a peer-to-pool options market, holding deposited collateral tokens and issued option tokens. It maintains records of individual user positions, global liquidity pools for each option series, and configuration parameters like fees and collateral ratios. Callers can deposit collateral, mint new option tokens, exercise options, redeem expired options, and withdraw their available collateral. A designated operator can adjust global fees and add new supported option series, while the owner can upgrade the contract logic. The maximum leverage for any option series is capped at 10x, and a 0.1% protocol fee is applied to all option premium payments. The contract emits events for all deposits, withdrawals, option mints, exercises, and redemptions, including the relevant token amounts and user addresses.
