This contract manages the locking of arbitrary fungible tokens for a specified duration, holding the locked tokens in escrow. It maintains records of each lock, including the depositor, the token type, the amount, the unlock time, and whether the lock has been withdrawn. Callers can create new locks by depositing tokens, and once the unlock time has passed, they can withdraw their locked tokens. A designated operator can extend the unlock time of an existing lock, but only before the original unlock time has passed. The contract owner can set a fee percentage for new locks, which defaults to 0.5% and must be between 0% and 5%, and can also designate new operators. The contract emits an event when a new lock is created, when a lock's unlock time is extended, and when tokens are withdrawn from a lock.
