This contract facilitates the creation and trading of fractionalized non-fungible tokens, holding the underlying non-fungible tokens in escrow. It maintains a record of each fractionalized token's total supply, the current reserve of fungible tokens backing it, and the bonding curve parameters for each fractionalized token. Callers can create new fractionalized tokens by depositing a non-fungible token, buy fractionalized tokens from the reserve, sell fractionalized tokens back to the reserve, and withdraw the underlying non-fungible token if they hold all fractionalized tokens. Only the owner can set the protocol fee percentage and update the allowed non-fungible token collection list. The protocol fee is fixed at 0.5% of each buy or sell transaction. A minimum of 100 fractionalized tokens must be minted when a new fractionalized token is created. The contract announces when new fractionalized tokens are created, when fractionalized tokens are bought or sold, and when underlying non-fungible tokens are withdrawn.
