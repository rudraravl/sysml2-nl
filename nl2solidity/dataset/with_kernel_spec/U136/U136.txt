This contract is a universal name service, managing the registration and ownership of unique, human-readable names. It maintains a record for each registered name, storing its owner, a resolver contract address, and a time of expiration. Callers can register a new name, transfer ownership of a name they own, renew the expiration time of a name, and configure the resolver for a name they own. A designated operator can set the registration fee and the renewal fee. The minimum registration period for a new name is 365 days. The fee for registering a new name is 0.01 ether per year. The contract emits an event when a new name is registered, when a name's ownership is transferred, when a name's expiration is renewed, and when a name's resolver is updated.
