This contract is a decentralized name service that custodies unique domain names. It maintains a registry of owned domain names, their associated resolver addresses, and expiration dates for each name. Callers can register a new domain name, renew an existing domain name, transfer ownership of a domain name to another address, and set the resolver address for a domain name. The owner can set the registration fee and the renewal fee. A domain name registration costs 0.01 ether per year, and renewals cost 0.005 ether per year. All domain names must be between 3 and 64 characters long. The contract announces when a domain name is registered, renewed, transferred, or when its resolver is updated.
