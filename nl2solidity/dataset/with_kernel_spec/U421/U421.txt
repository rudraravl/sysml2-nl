This contract facilitates the creation of new protocol tokens by allowing users to deposit a base currency in exchange for these new tokens, effectively bootstrapping a new decentralized autonomous organization. It maintains a pool of deposited base currency, a record of each user's deposited amount and corresponding token allocation, and a configurable exchange rate for the new tokens. Callers can deposit base currency to mint new tokens, withdraw their deposited base currency if the project fails to meet a minimum funding threshold, and claim their vested new tokens after a specified period. A designated operator can set the initial exchange rate for the new tokens, and initiate the project's launch after the minimum funding threshold is met. The initial exchange rate is fixed at 1000 new tokens per 1 unit of base currency, and the minimum funding threshold is 5000 units of base currency. The contract announces when a deposit is made, when a withdrawal occurs, and when the project is successfully launched.
