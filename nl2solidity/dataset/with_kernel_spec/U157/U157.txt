This contract is a decentralized exchange for token pairs, holding reserves of two distinct tokens for each pair. It maintains a record of each liquidity pool's token reserves, a global trading fee, and a per-pool swap fee. Callers can add liquidity to a pool, remove liquidity from a pool, swap one token for another within a pool, and transfer their liquidity provider tokens. A designated owner can set the global trading fee, create new token pairs, and update the swap fee for any existing pool. The global trading fee is 0.25% of the input amount for any swap. Adding liquidity to a pool requires depositing both tokens in proportion to their current reserves. The contract emits an event for every liquidity addition, removal, and token swap, including the amounts involved and the affected pool.
