This contract manages a fair launch mechanism for new tokens, holding deposited base tokens and newly minted project tokens. It maintains a record of each participant's purchased project token balance and their corresponding base token contribution, along with a global pool of base tokens and project tokens. Participants can deposit base tokens to acquire project tokens, claim their purchased project tokens, and withdraw any remaining base tokens after the launch concludes. Only the owner can set the initial project token supply, adjust the launch phase parameters, and finalize the launch. The initial project token supply must be between 1,000,000 and 10,000,000,000 tokens, and a 2% fee on base token deposits is automatically transferred to a designated treasury address. The contract announces when a new project token launch begins, when a participant makes a deposit, and when a participant claims project tokens.
