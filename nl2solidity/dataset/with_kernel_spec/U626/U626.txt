This contract facilitates the creation and funding of new token liquidity pools, holding deposited base tokens and newly minted project tokens. It maintains a record of each pool's base token deposits, project token supply, the current funding goal, and a list of comments associated with each pool. Callers can create a new pool by depositing a base token and specifying a project token address, contribute base tokens to an existing pool, claim their pro-rata share of project tokens once a pool is fully funded, and post comments on any pool. A designated administrator can set a global fee percentage for successful pool funding and pause all pool creation. New pools must specify a funding goal between 100 and 1,000,000 base tokens, and a 0.5% fee is deducted from the collected base tokens upon successful funding. The contract announces pool creation, contributions, funding completion, and new comments.
