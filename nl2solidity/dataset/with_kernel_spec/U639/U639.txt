This contract manages a decentralized game where players stake tokens against each other in one-on-one matches, holding staked tokens in escrow. It maintains player balances, active match states including staked amounts and chosen outcomes, and a global game configuration. Callers can initiate a match by staking tokens, accept an open match, declare a match outcome, and claim winnings from resolved matches. A designated operator can set the match fee, which is 5% of the staked amount, and pause all new match initiations. Each match has a maximum stake of 1000 tokens. The contract emits an event when a new match is created, when a match is resolved, and when winnings are claimed.
