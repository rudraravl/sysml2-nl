This contract facilitates cross-chain message passing between a Layer 1 and a Layer 2, holding no custodied assets itself. It maintains a mapping of message hashes to their current status (pending, relayed, failed) and the block number at which they were initiated, along with a configurable relay fee and a list of authorized message relayer addresses. Callers can initiate a message on Layer 1, and authorized relayers can relay a message to Layer 2, or prove a message failed on Layer 2. Only the contract owner can update the relay fee or add/remove authorized relayer addresses. The relay fee must be at least 0.001 ether, and a message can only be relayed to Layer 2 if at least 100 Layer 1 blocks have passed since its initiation. The contract announces when a message is initiated, when it is successfully relayed, and when a relay attempt fails.
