This contract facilitates the automated trading of non-fungible tokens (NFTs) and custodies both NFTs and fungible tokens used for purchases. It maintains individual user balances of fungible tokens, a global fungible token reserve, and specific buy and sell orders for each supported NFT collection, including their current price and available quantity. Callers can deposit fungible tokens, create a new NFT buy order, create a new NFT sell order, fill an existing buy order, fill an existing sell order, and withdraw their fungible tokens. Only a designated operator can add new NFT collections for trading and adjust the trading fee. A trading fee of 0.5% is applied to all successful NFT trades, and the maximum number of NFTs that can be bought or sold in a single order is 100. The contract announces successful NFT purchases, successful NFT sales, and changes to the trading fee.
