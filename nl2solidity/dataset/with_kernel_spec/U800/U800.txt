This contract manages investment pools, holding various ERC-20 tokens deposited by users. It maintains a record of each user's share balance within each pool, along with pool-specific configurations for allowed assets and trading strategies. Callers can create new pools, deposit ERC-20 tokens into existing pools to receive pool shares, withdraw their deposited tokens by redeeming shares, and propose trades for a pool's assets. A designated operator is privileged to approve or reject proposed trades, set the management fee for each pool, and add or remove allowed assets for a pool. The maximum management fee that can be set for any pool is 5% annually, and a 0.1% performance fee is charged on all profitable trades. The contract announces events for pool creation, deposits, withdrawals, and approved trades.
