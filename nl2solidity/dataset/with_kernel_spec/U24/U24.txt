This contract manages a tokenized representation of staked network tokens, allowing users to deposit network tokens and receive an equivalent amount of liquid staking tokens. It maintains a record of each user's deposited network tokens, the total supply of liquid staking tokens, and a global exchange rate between the two. Callers can deposit network tokens, withdraw their staked network tokens, and redeem liquid staking tokens for network tokens. A designated operator can update the exchange rate based on external oracle data, and only this operator can pause all withdrawals. The maximum number of network tokens that can be deposited in a single transaction is 1000, and a 0.5% fee is applied to all withdrawals. The contract announces when a deposit occurs, when a withdrawal occurs, and when the exchange rate is updated.
