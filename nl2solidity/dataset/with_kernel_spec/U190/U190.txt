This contract is a launchpad for new tokens, holding contributions of a base currency and newly minted project tokens. It maintains a record of each participant's contribution in the base currency and their allocated project tokens, along with the current state of the launch event and its configuration parameters. Callers can contribute base currency to participate in a launch, claim their allocated project tokens after the launch concludes, and withdraw any excess base currency if the project token allocation is not fully subscribed. The contract owner can initiate a new launch, set the project token allocation and contribution limits, pause and unpause contributions, and finalize the launch to enable token claims. A launch event must have a minimum contribution period of 24 hours and a maximum individual contribution cap of 1000 base currency units. The contract announces the start and end of a launch, successful contributions, and token claims.
