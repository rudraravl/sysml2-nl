This contract is a token locker, holding arbitrary ERC-20 tokens deposited by users for a specified duration. It maintains a record for each locked token deposit, including the depositor's address, the token's contract address, the amount locked, and the unlock timestamp. Callers can deposit tokens, extend the lock duration of their own deposits, and withdraw their tokens once the lock duration has expired. A designated owner can set a deposit fee, which is a percentage of the deposited amount, and can withdraw collected fees. The maximum lock duration for any deposit is 104 weeks, and the minimum deposit amount for any token is 1 unit of that token. The contract announces an event when tokens are deposited, when a lock duration is extended, and when tokens are withdrawn.
