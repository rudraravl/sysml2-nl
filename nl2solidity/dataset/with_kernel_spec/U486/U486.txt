This contract manages onchain portfolio vaults, holding baskets of ERC-20 tokens. It maintains a record of each vault's current token balances, its target token weights, and a global fee configuration. Callers can create new vaults, deposit tokens into an existing vault, withdraw tokens from a vault, and trigger a rebalance of a vault's token holdings. A designated operator can adjust the target token weights for any vault, and only the owner can set the global rebalancing fee. New vaults must be initialized with at least two different ERC-20 tokens, and the rebalancing fee is fixed at 0.5% of the value rebalanced. The contract announces when a vault is created, when tokens are deposited, when tokens are withdrawn, and when a rebalance operation completes.
