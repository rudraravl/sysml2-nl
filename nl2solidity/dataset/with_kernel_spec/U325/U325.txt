This contract serves as a launchpad for new token projects, holding deposited base currency and newly minted project tokens. It maintains a record of each participant's base currency deposit, their allocated share of project tokens, and global configuration settings for each project launch. Callers can deposit base currency to participate in a project launch, claim their allocated project tokens after the launch concludes, and withdraw any remaining base currency if their allocation is not fully utilized. A designated operator can initiate a new project launch, set its parameters, finalize a launch to enable token claims, and pause or unpause deposits for any active launch. Each project launch must have a minimum deposit amount of 0.01 base currency, and a 5% fee on all base currency deposits is automatically transferred to a designated treasury address. The contract announces when a new project launch is started, when a deposit is made, and when project tokens are claimed.
