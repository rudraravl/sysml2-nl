This contract facilitates the creation and management of tokenized portfolios, holding deposited base tokens as collateral. It maintains a record of each portfolio's constituent tokens and their target weights, the total supply of each portfolio token, and a global configuration for fees and minimum deposit amounts. Callers can create new portfolio types, deposit base tokens to mint portfolio tokens, redeem portfolio tokens for their underlying base tokens, and transfer portfolio tokens. Only a designated operator can adjust the global minting fee, which is fixed at 0.1% of the deposited value, or update the minimum deposit amount for any portfolio type, which is set to a minimum of 100 units of the base token. The contract announces events for portfolio creation, token minting, and token redemption, including the portfolio identifier, the amount of tokens involved, and the address of the interacting caller.
