This contract facilitates a prediction market, custodying user deposits in an escrow pool. It maintains individual user balances for each market, a total escrow balance per market, and a global configuration for market creation parameters. Callers can create new prediction markets, place predictions on existing markets, resolve markets by providing an outcome, and claim winnings from resolved markets. A designated operator can pause and unpause all market activity, and can set the fee percentage for market creation. Market creation requires a minimum deposit of 100 base tokens. A 0.5% fee is applied to all market creation deposits, which is sent to a designated treasury address. The contract announces market creation, prediction placement, market resolution, and winning claims through events.
