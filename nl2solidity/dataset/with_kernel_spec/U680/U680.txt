This contract manages a decentralized exchange's liquidity pools, holding deposited tokens for trading. It maintains records of each liquidity provider's deposited amounts and shares in specific pools, along with global pool configurations including token pairs and current reserves. Callers can deposit tokens to provide liquidity, withdraw their liquidity shares, and swap tokens between supported pairs. Only a designated operator can add new token pairs to the exchange, set initial swap fees for new pools, or pause all trading activity. Each swap transaction incurs a 0.3% fee, and a newly added token pair must have an initial liquidity deposit of at least 100 units of each token. The contract announces successful deposits, withdrawals, and token swaps, including the amounts involved and the affected pool.
