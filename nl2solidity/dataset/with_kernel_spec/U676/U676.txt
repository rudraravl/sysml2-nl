This contract facilitates automated market making for token pairs, holding reserves of two distinct fungible tokens for each liquidity pool. It maintains a record of each liquidity pool's token reserves, the total supply of liquidity tokens issued for each pool, and each user's balance of liquidity tokens. Callers can create new liquidity pools, add liquidity by depositing both tokens in a specific ratio, remove liquidity by burning their liquidity tokens, and swap one token for another within an existing pool. Only the contract owner can set the swap fee percentage, which is initially 0.3% and can be changed to any value between 0% and 1%. The contract announces events for liquidity additions, liquidity removals, and token swaps, including the tokens involved and the amounts exchanged.
