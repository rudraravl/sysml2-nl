This contract manages domain name registrations on the blockchain, holding ownership records for each registered name. It maintains a registry of owned names, their expiration dates, and the associated resolver addresses. Callers can register new names, renew existing names, transfer name ownership, and set a name's resolver. A designated operator can pause new registrations and renewals. New name registrations incur a flat fee of 0.01 ether, and name renewals extend ownership for exactly one year from the current expiration date. The contract emits an event when a name is registered, renewed, or transferred.
