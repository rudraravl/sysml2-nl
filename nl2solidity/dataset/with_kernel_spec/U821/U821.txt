This contract manages a game's property ownership and associated yield, custodying non-fungible tokens representing game properties and the game's native fungible token. It maintains a record of each player's owned properties, their accumulated yield per property, and global game configuration parameters like property prices and yield rates. Callers can purchase available properties, collect accumulated yield from their owned properties, and sell properties back to the game. Only a designated game administrator can set the base price for each property type, adjust the yield rate for each property type, and mint new property non-fungible tokens. A player can own a maximum of 10 properties at any given time. The yield collection action incurs a fixed 1% fee on the collected amount, which is transferred to the game administrator's treasury. The contract emits an event whenever a property is purchased, sold, or when yield is collected.
