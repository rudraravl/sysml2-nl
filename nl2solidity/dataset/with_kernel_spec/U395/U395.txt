This contract manages a decentralized token launchpad, custodying deposited base tokens and newly minted project tokens. It maintains records of each project's launch configuration, including its associated concentrated-liquidity pool, the amount of base tokens contributed by each participant, and the project tokens allocated to them. Callers can create new project launches, deposit base tokens into active launches, claim their allocated project tokens, and withdraw any remaining base tokens after a launch concludes. A designated operator can set the fee percentage for new project launches and pause or unpause the entire launchpad. Each project launch must specify a minimum base token deposit of 100 units and a maximum launch duration of 30 days. The contract emits an event when a new project launch is created, when base tokens are deposited, and when project tokens are claimed.
