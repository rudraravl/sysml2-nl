This contract is a gaming asset registry, providing a canonical source of truth for in-game items and their ownership, and it custodies no tokens directly. It maintains a record for each unique item, including its current owner, its type identifier, and a set of immutable properties defined at creation. Callers can create new item types, mint new items of an existing type to a specified owner, transfer ownership of an item they possess, and burn items they own. Only a designated operator can create new item types and mint new items. Item types have a maximum supply of 1,000,000 items, and a transfer fee of 0.5% of the item's value (denominated in a base currency) is applied to every transfer, payable to the designated operator. The contract announces when an item is minted, when its ownership changes, and when an item is burned.
