This contract manages a basket of tokens, holding a diverse portfolio of other fungible tokens. It maintains each user's balance of basket tokens, the current composition and quantity of each underlying asset in the basket, and a global rebalancing threshold. Callers can deposit supported tokens to mint basket tokens, withdraw underlying tokens by burning basket tokens, and claim rewards distributed to basket token holders. A designated rebalancer can initiate a rebalance operation to adjust the basket's asset distribution, and the owner can add or remove supported tokens from the basket, set the rebalancing threshold, and update the reward distribution rate. The rebalancing threshold is set at 1% deviation from target weights, meaning a rebalance can only occur if any asset's actual weight differs from its target by more than 1%. A 0.1% fee is applied to all withdrawals, which is distributed to basket token holders. The contract emits events when tokens are deposited, withdrawn, rewards are claimed, the basket composition changes, and the rebalancing threshold is updated.
