This contract facilitates the creation and launch of new token projects, holding the native blockchain currency and newly created tokens in escrow. It maintains a registry of launched tokens, each with its current bonding curve liquidity, total supply, and a record of individual user balances within the curve. Callers can create a new token by providing an initial supply of the native currency, buy tokens from an existing bonding curve, sell tokens back to a bonding curve, and finalize a launched token to enable external trading. A designated operator can set the base fee for creating new tokens, which is fixed at 0.1 native currency units, and can also set the percentage of native currency from sales that is allocated to the protocol, which is capped at 5%. The contract announces the creation of new tokens, all buy and sell orders, and the finalization of a token launch.
