This contract is a token launchpad that custodies deposited base tokens and newly minted project tokens. It maintains a record of each project's launch configuration, including its sale parameters and the amounts of base tokens contributed by each participant. Callers can create new project launches, contribute base tokens to active sales, claim their purchased project tokens after a successful sale, and withdraw their contributed base tokens if a sale fails. A designated administrator can pause or unpause the contract, set global fees, and upgrade the contract's logic. Each project launch has a maximum base token contribution cap of 1000 base tokens per participant, and a 2% fee is applied to all successful base token contributions, directed to a treasury address. The contract emits an event when a new project launch is created, when base tokens are contributed, and when project tokens are claimed.
