This contract provides a min-heap data structure, which is a specialized tree-based data structure that satisfies the heap property: the value of each node is greater than or equal to the value of its parent, with the minimum value always at the root. The contract maintains the heap's elements as an ordered list of unsigned 256-bit integers. Callers can retrieve the smallest element without removing it, add new elements, remove the smallest element, or replace the smallest element with a new one. There's also a specialized "enqueue" function for bounded heaps, which adds an element and potentially removes the smallest if the heap exceeds a maximum size. The contract also allows retrieving a specified number of the smallest elements without modifying the heap. If the heap is empty when an operation requires an element, the transaction will revert. There are no access control mechanisms, fees, or external integrations; all operations are public.
