This contract provides a utility library for encoding and decoding execution data and modes, primarily for use with ERC7579-compatible smart accounts. It defines various call types (single, batch, staticcall, delegatecall) and execution types (default, try-catch) as constants. Callers can encode a mode by combining a call type, execution type, a function selector, and a 22-byte payload, and subsequently extract these components from a given mode. The contract also offers functions to decode different execution data formats: single calls (with or without value), delegate calls, and batches of calls, including an option to decode additional operational data (`opData`) alongside a batch. It includes both checked and unchecked decoding functions, with the unchecked versions assuming prior validation. Furthermore, it allows re-encoding batch execution data to append `opData` and to format it as calldata for an `execute(bytes32,bytes)` function call. The contract does not maintain any state, nor does it have any access control, events, fees, or upgradeability mechanisms, as it serves purely as a stateless utility for data manipulation.
