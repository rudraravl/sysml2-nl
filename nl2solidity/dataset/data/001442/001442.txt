This contract implements an upgradeable proxy pattern using a beacon. It maintains the address of an `UpgradeableBeacon` contract, which in turn holds the address of the current implementation logic contract. All calls made to this proxy contract are delegated to the implementation contract specified by the beacon. The contract is initialized with a beacon address and an optional initialization data payload. The owner of the `UpgradeableBeacon` contract has the exclusive ability to change the implementation address stored within the beacon, thereby upgrading the logic for all associated proxy contracts. This contract emits an `Upgraded` event when its implementation is changed and a `BeaconUpgraded` event when the beacon itself is changed. This design allows for flexible and secure upgrades of contract logic without redeploying the proxy itself.
