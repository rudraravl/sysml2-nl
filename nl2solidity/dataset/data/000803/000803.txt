This contract allows multiple users to pool a fixed amount of Ether, which can then be returned to them. It maintains a list of addresses that have successfully contributed. Users can contribute exactly 1 Ether by calling the `enter` function, which adds their address to the list of entrants. At any point, any caller can trigger the `sendBack` function, which iterates through all recorded entrants and attempts to send 1 Ether back to each of them. After all attempts are made, the list of entrants is cleared. There are no access controls, so anyone can call `enter` or `sendBack`. No events are emitted. The contract does not handle cases where a transfer to an entrant fails, beyond requiring each individual transfer to succeed.
