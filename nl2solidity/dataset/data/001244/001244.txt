This contract serves as a foundational component for a Fluid Center Price oracle, designed to provide a standardized price feed. It maintains a single immutable piece of state: a short identifier, `_infoName`, which is a 32-byte string representing the oracle's name. This name is set once during deployment and cannot be changed. Callers can query the `infoName` to retrieve this identifier and `targetDecimals` to understand the expected decimal precision of the price, which is fixed at 27. The core functionality, `centerPrice`, is left abstract, meaning this contract itself doesn't provide a price but rather defines the interface and common properties for other contracts that will implement the actual price fetching logic. There are no access control mechanisms, events, or fees implemented directly in this base contract.
