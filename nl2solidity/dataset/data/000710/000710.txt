This contract serves as a registry for EVM-compatible blockchain network information, primarily for use in development and testing environments. It maintains a mapping of chain aliases (like "mainnet" or "goerli") to their corresponding network details, including name, chain ID, and a default RPC URL. Callers can retrieve chain information by either its alias or its chain ID. The contract initializes a set of common chains and their default RPC URLs upon the first request for chain data. Callers can also explicitly set or update chain information, which takes precedence over the default values. When retrieving chain data, the contract prioritizes RPC URLs provided during explicit `setChain` calls, then attempts to fetch an RPC URL from an external configuration (like a `foundry.toml` file), then from an environment variable, and finally falls back to its internally stored default RPC URL. This allows for flexible configuration of RPC endpoints.
