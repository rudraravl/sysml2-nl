This contract is a decentralized flash loan and asset tokenization platform. It allows users to deposit supported ERC-20 tokens, receive corresponding asset tokens, and then redeem those asset tokens for the underlying ERC-20s. The contract maintains a mapping of supported ERC-20 tokens to their unique asset token contracts, a global flash loan fee, and a flag indicating if a specific token is currently involved in a flash loan. The owner can add or remove supported tokens, which automatically deploys a new asset token contract for each added token, and can also update the flash loan fee. Users can deposit ERC-20 tokens, minting asset tokens based on an exchange rate that incorporates a fee. They can also redeem their asset tokens for the underlying ERC-20s. The core functionality is flash loans, where a borrower can temporarily take a large amount of a supported token without collateral, provided they return the original amount plus a calculated fee within the same transaction. Flash loan fees are calculated based on the token's value in WETH, obtained from an integrated oracle. The contract emits events for deposits, token allowance changes, redemptions, and flash loans, enabling off-chain monitoring. It includes re-entrancy guards by updating state before transfers and ensures only contracts can receive flash loans.
