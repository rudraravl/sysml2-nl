This contract extends an existing ERC6909 token implementation to include metadata for individual token IDs. It maintains a mapping where each unique token ID is associated with its own name, symbol, and decimal precision. Callers can query the name, symbol, and decimals for any given token ID. The contract provides internal functions to set these metadata fields for a specific token ID, which are intended to be called by the contract's implementer or owner. Each time a token's name, symbol, or decimals are updated, a corresponding event (ERC6909NameUpdated, ERC6909SymbolUpdated, or ERC6909DecimalsUpdated) is emitted, allowing off-chain applications to track these changes. The contract also supports the ERC165 interface for introspection, indicating its compliance with the ERC6909Metadata standard. There are no direct external functions for arbitrary callers to modify the metadata; modifications are expected to be handled by the contract's internal logic or privileged functions in a derived contract.
