This contract manages various protocol fee percentages within a Balancer V2 system. It maintains a record of different fee types, each with a name, a current percentage value, and a maximum allowable percentage. The contract is initialized with specific maximum values for yield and AUM fees, and also registers swap and flash loan fee types, though their actual values are stored and managed by an external `ProtocolFeesCollector` contract. Only an authenticated caller, as defined by the Balancer Vault, can register new fee types or modify existing fee percentages. When a new fee type is registered, or a fee percentage is changed, corresponding events are emitted to signal these updates. Callers can query the current percentage, maximum percentage, and name for any registered fee type, and can also check if a given fee type or percentage is valid.
