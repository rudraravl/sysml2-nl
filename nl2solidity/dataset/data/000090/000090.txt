This contract provides utility functions for interacting with ERC-1363 compliant tokens, specifically to validate recipient and spender contracts during token transfers and approvals. It does not maintain any state itself, but rather facilitates secure interactions by ensuring that target contracts properly acknowledge these operations. Callers can use two main operations: `checkOnERC1363TransferReceived` to verify a token transfer recipient, and `checkOnERC1363ApprovalReceived` to verify an approved spender. Both functions ensure the target address is a contract, implements the correct ERC-1363 interface, and returns the expected selector to confirm acceptance. If any of these conditions are not met, the operation reverts with specific error messages indicating an invalid receiver or spender. This contract acts as a safeguard, preventing tokens from being sent to or approved by contracts that do not correctly handle ERC-1363 callbacks.
