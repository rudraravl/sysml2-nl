This contract provides utility functions for interacting with Uniswap V3 pools, specifically to locate liquidity ranges around a given tick. It does not maintain any state itself, but rather queries an external Uniswap V3 pool contract. The primary operation is `findLiquidityRange`, which, given a Uniswap V3 pool, a target tick, and a direction (less than or equal to, or greater than), returns the lower and upper bounds of an initialized tick range and the net liquidity at the lower bound. This function internally uses `findInitializedTick` to efficiently locate the nearest initialized tick within the pool's tick bitmap, iterating through words if necessary. There are no access control mechanisms, events, or fees, as it's a pure utility library designed to be called by other contracts. It includes a safety guard to prevent infinite loops during tick searches.
