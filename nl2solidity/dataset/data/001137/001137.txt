This contract defines a data structure, `MarketState`, which efficiently stores four key pieces of information related to a financial market within a single 256-bit unsigned integer. It tracks a global borrow index, an epoch representing the last interaction time, a target interest rate, and accumulated unrealized interest. Callers can create a new `MarketState` by providing initial values for all four components. They can also retrieve any of these individual components from an existing `MarketState` or update any of them independently, with the contract ensuring that values are correctly masked and shifted to fit their designated bit ranges without affecting other stored data. This design optimizes storage and retrieval of market-specific parameters.
