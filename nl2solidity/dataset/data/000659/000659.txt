This contract is a non-transferable token designed to track variable-rate debt positions within a lending protocol. It maintains a record of each user's scaled debt balance and the total scaled debt supply for a specific underlying asset. The contract is initialized with the address of the main Pool contract and a rewards controller. Callers can query their current debt balance, which is dynamically calculated based on the current reserve index. The primary operations are `mint` and `burn`, which are restricted to the associated Pool contract. `mint` increases a user's scaled debt, potentially decreasing a delegate's borrow allowance if the debt is taken on behalf of another. `burn` reduces a user's scaled debt. All standard ERC20 transfer and approval functionalities are explicitly disabled, reverting any attempts to use them, as the token is not meant to be transferable. The contract also exposes the address of the underlying asset it represents.
