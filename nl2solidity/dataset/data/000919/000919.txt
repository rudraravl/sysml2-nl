This contract acts as a wrapper for an existing ERC721 token, allowing users to deposit underlying tokens and receive a corresponding wrapped token, or burn wrapped tokens to withdraw the underlying. It maintains a record of the designated underlying ERC721 token at deployment. Callers can deposit multiple underlying tokens for a specified account, which transfers the underlying tokens to the wrapper and mints new wrapped tokens. Conversely, callers can withdraw multiple underlying tokens to a specified account by burning their wrapped tokens, provided they are the owner or an approved operator of the wrapped token. The contract also supports direct ERC721 transfers of the underlying token to itself, automatically minting a wrapped token for the sender. An internal recovery function allows minting a wrapped token for an underlying token accidentally transferred to the contract. There are no fees or explicit events beyond standard ERC721 operations.
