This contract manages a system of keyed nonces for different addresses, allowing callers to track and consume unique, sequential numbers associated with a specific address and an arbitrary key. It maintains a mapping where each address can have multiple independent nonce sequences, identified by a 192-bit key. The contract provides a function to query the current, next available nonce for a given address and key, returning a packed value combining the key and the nonce. Internally, it offers operations to consume the next nonce for an address and key, incrementing the stored value and returning the consumed nonce. There are also functions to consume a nonce only if it matches the expected next value, preventing replay attacks by ensuring nonces are used in strict order. The contract does not emit any events.
