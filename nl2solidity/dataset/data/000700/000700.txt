This contract defines an ERC-20 compliant asset token, representing a share of an underlying ERC-20 token. It tracks an immutable underlying token and a designated "ThunderLoan" address, which is the sole entity permitted to perform core operations. The contract maintains an exchange rate, initialized to 1:1, which dictates how many underlying tokens one asset token is worth. Only the ThunderLoan address can mint or burn these asset tokens, and it can also directly transfer the underlying token to any address. Crucially, the ThunderLoan address can increase the exchange rate by providing a fee, which effectively increases the value of each asset token relative to the underlying; this rate can only ever increase, never decrease. Any update to the exchange rate emits an event. Callers can query the current exchange rate and the address of the underlying token.
