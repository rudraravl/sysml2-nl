This contract serves as a Uniswap V3 adapter, facilitating token swaps to the native blockchain token (WETH, then unwrapped to ETH) for its owner. It maintains the address of the Uniswap V3 router and the native token, along with a mapping of token addresses to their corresponding Uniswap V3 pool fees. The contract is owned by a single address, initially set at deployment, which has exclusive control over setting pool fees for different tokens. The primary operation is `swapToNative`, which allows the owner to swap a specified ERC20 token held by the contract into the native token, ensuring a minimum output amount. This function first approves the Uniswap router to spend the contract's entire balance of the input token, then executes a single-hop swap through Uniswap V3, unwraps the resulting WETH, and finally transfers the native token to the caller. An event is emitted whenever a pool fee is updated.
