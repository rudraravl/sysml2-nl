This contract provides utility functions for querying whether other contracts support specific interfaces, adhering to the ERC-165 standard. It maintains no state itself, acting purely as a library for introspection. Callers can check if a given address supports the ERC-165 interface, a specific interface ID, a list of interface IDs (returning individual support status), or all interfaces within a provided list. The core mechanic involves making low-level static calls to the target contract's `supportsInterface` function. There are no access controls, fees, or events; all functions are internal and designed to be used by other contracts. The contract is not upgradeable and does not integrate with other protocols beyond the ERC-165 standard itself.
