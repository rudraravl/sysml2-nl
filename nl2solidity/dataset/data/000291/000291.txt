This contract is a utility library designed to perform various bit manipulation and boolean operations on unsigned 256-bit integers and byte arrays. It does not maintain any on-chain state or define any access control mechanisms, as it is purely a collection of pure functions. Callers can use this library to find the last or first set bit in a `uint256`, count the number of set bits, count zero bytes within a `uint256`, a `bytes` memory array, or `bytes` calldata. Additionally, it provides functions to check if a `uint256` is a power of two, reverse bits or bytes within a `uint256`, and determine common bit, nibble, or byte prefixes between two `uint256` values. It also includes functions for converting a `bytes` memory array into its nibble representation. For boolean operations, it offers both "raw" and "safe" versions of AND and OR for up to four boolean inputs, and functions to convert booleans to `uint256` values. No events are emitted, and there are no fees, upgradeability, or external integrations; its purpose is solely to provide efficient, low-level computational utilities.
