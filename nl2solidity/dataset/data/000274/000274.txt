This contract implements a utility library for generating and interacting with Merkle trees on-chain. It does not maintain any state itself, but rather provides pure functions to process arrays of 32-byte leaves. Callers can build a complete Merkle tree from an array of leaves, retrieve the root hash of a built tree, determine the number of leaves or internal nodes, and fetch individual leaves or a collection of leaves by their indices. It also supports generating Merkle proofs for a single leaf or multiple leaves, which can be used to verify the inclusion of data within the tree. Additionally, the contract offers functions to pad an array of leaves to the nearest power of two, using a specified fill value or a default zero value, which is often a prerequisite for building a complete Merkle tree. All operations are permissionless, and the contract handles various error conditions such as empty leaf arrays or out-of-bounds access with custom error messages.
