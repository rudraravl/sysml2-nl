This contract facilitates the deployment of an upgradeable beacon for a CCIP gauge on the Arbitrum network. Its sole purpose is to create and register this beacon, which will point to a specific CCIP gauge implementation and be initially owned by a designated Timelock Controller. The contract maintains no persistent state itself beyond the deployment record. Callers can only execute the `run` function, which deploys the beacon. Access control is implicit: only the deployer with the correct private key can initiate the deployment. There are no events emitted by this contract. A notable mechanic is the chain verification, ensuring the deployment only occurs on Arbitrum, and the registration of the deployed beacon's address for future reference.
