This contract serves as a configuration manager for a testing framework, allowing users to define specific parameters for invariant testing. It maintains several lists in its state: excluded and targeted contract addresses, excluded and targeted sender addresses, excluded and targeted artifact names (strings), and targeted selectors, which pair an address with an array of function selectors, and targeted artifact selectors, which pair an artifact name with an array of function selectors. Users can add entries to these lists using dedicated internal functions like `excludeContract`, `targetSender`, or `targetArtifactSelector`. The contract also provides public view functions, such as `excludeContracts` or `targetArtifacts`, to retrieve the current state of these configuration lists. There are no access control mechanisms beyond the internal visibility of the modification functions, and no events are emitted. The contract does not handle any tokens or fees, nor does it integrate with other protocols; its sole purpose is to store and retrieve these testing parameters.
