This contract provides a read-only view into Uniswap V4 pool data, specifically designed to calculate the Total Value Locked (TVL) for a given pool. It does not maintain any persistent state itself, instead reading all necessary information directly from a Uniswap V4 PoolManager contract. Callers specify the PoolManager and a PoolKey to identify the target pool. The contract offers functions to retrieve the TVL for a single pool or a batch of pools. For large pools, it supports paginated TVL retrieval, allowing callers to process data incrementally using a cursor. It also provides a function to list all initialized ticks within a specific word position of a pool's tick bitmap. Additionally, the contract can query optional hook statistics from a designated provider, which can be the hook itself or an external address, and reports the status of these queries. All operations are view-only and do not alter any on-chain state.
