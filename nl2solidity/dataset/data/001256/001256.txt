This contract serves as a resolver for positions within the Fluid Vault protocol, enabling callers to query and retrieve detailed information about vault positions. Upon deployment, it immutably stores references to a Fluid Vault Resolver and a Fluid Vault Factory, ensuring these essential components are always accessible. Callers can retrieve all NFT IDs associated with a specific vault, or obtain comprehensive position data for a given array of NFT IDs. Additionally, the contract allows for the retrieval of all positions within a particular vault, providing details such as the NFT ID, owner, supply, and borrow amounts for each position. The contract does not implement any access control beyond the constructor, and it does not emit any events. It relies on external vault and factory contracts for underlying data and calculations, and handles complex internal logic to convert raw data into human-readable position information.
