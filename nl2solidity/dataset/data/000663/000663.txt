This contract defines a specialized ERC20 token designed for a lending pool, tracking users' balances in a "scaled" manner, which accounts for interest accrual over time. It maintains a record of each user's scaled balance and a historical index representing the state of the pool at their last interaction. The contract allows external callers to query a user's scaled balance, the total scaled supply, and a user's previous index. It also provides internal functions for minting and burning these scaled tokens, which are typically called by the associated lending pool. Minting increases a user's scaled balance and updates their index, emitting a `Mint` event along with a standard `Transfer` from the zero address. Burning decreases a user's scaled balance and updates their index, emitting a `Burn` event and a `Transfer` to the zero address. Notably, a burn operation might still result in a `Mint` event if accrued interest exceeds the burn amount. The contract is initialized with references to the main lending pool, token metadata, and a rewards controller, and it inherits standard ERC20 functionalities.
