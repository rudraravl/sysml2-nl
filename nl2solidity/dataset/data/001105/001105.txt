This contract serves as a factory for creating and managing oracle instances. It maintains a reference to a base oracle implementation that will be cloned for each new oracle. The contract tracks deployed oracles by their unique configuration ID (a hash of their initial settings) and also by their configuration address, ensuring that each configuration ID maps to a single configuration address, and each configuration address maps to a single oracle address. Callers can initiate the creation of new oracles, and the factory will record the new oracle's address, its configuration address, and its configuration ID. A `NewOracle` event is emitted whenever a new oracle is successfully registered. The contract prevents the creation of duplicate oracles for the same configuration ID, ensuring uniqueness and gas efficiency.
