This contract implements a Diamond proxy, allowing for modular and upgradeable functionality. It maintains a mapping of function selectors to their corresponding facet (implementation) addresses and their positions within the facet's function list, along with a list of all facet addresses. Upon deployment, the contract is initialized with an owner, core facets for diamond management (DiamondCut, DiamondLoupe, ERC165, ERC173), and any additional facets and their initialization data. The owner can then perform `diamondCut` operations to add, replace, or remove functions by specifying a facet address and a list of function selectors. All function calls to the Diamond contract are routed via `delegatecall` to the appropriate facet based on the function selector, enabling flexible upgrades and extensions. The contract emits an `OwnershipTransferred` event when the owner changes and a `DiamondCut` event for every modification to the contract's facets.
