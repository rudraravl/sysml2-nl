This contract defines a custom data type, `BalanceDelta`, which efficiently stores two signed 128-bit integer values, `amount0` and `amount1`, within a single 256-bit word. Its purpose is to represent changes or differences in two distinct quantities, such as token balances, in a compact manner. The contract provides functions to construct a `BalanceDelta` from two `int128` values, and to perform basic arithmetic operations: addition and subtraction, on these combined values. It also includes equality and inequality checks. Additionally, a library offers utility functions to extract the individual `amount0` and `amount1` components from a `BalanceDelta` and defines a constant for a zero delta. There are no state variables, access controls, events, or integrations with other protocols; it solely focuses on the efficient representation and manipulation of these paired integer values.
