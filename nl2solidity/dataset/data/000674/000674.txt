This contract serves as a factory for deploying and reporting on a specific set of Aave V3 helper contracts. It doesn't maintain any persistent state itself, but rather facilitates the creation of three distinct helper contracts: a `WrappedTokenGatewayV3`, an `L2Encoder`, and an `AaveProtocolDataProvider`. The primary operation is a single internal function that, when called, conditionally deploys these helper contracts based on provided parameters and returns their addresses in a structured report. The `WrappedTokenGatewayV3` is deployed only if a valid wrapped native token address is supplied, and the `L2Encoder` is deployed only if an L2 flag is set to true. The `AaveProtocolDataProvider` is always deployed. There are no access control mechanisms, events, or fee structures implemented within this contract; its sole purpose is to instantiate and report on these Aave V3 components.
