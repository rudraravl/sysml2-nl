This contract provides utility functions for Arbitrum Layer 2 (L2) to interact with cross-chain messages originating from Layer 1 (L1). It does not maintain any state itself. Its primary operations allow callers to determine if the current function call is a result of a cross-chain message and, if so, to retrieve the original sender's address from L1. There are no access control mechanisms as these are public utility functions. No events are emitted. The contract integrates with the Arbitrum system contract (`ARBSYS`) to query cross-chain message details. A notable mechanic is that attempting to retrieve the cross-chain sender when the call is not cross-chain will cause a reversion.
