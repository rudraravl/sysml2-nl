This contract serves as a wrapper for the native blockchain currency, allowing it to be converted to and from a wrapped token (WETH9). It permanently stores the address of the WETH9 contract upon deployment. The contract facilitates two primary internal operations: `_wrap`, which deposits a specified amount of native currency into the WETH9 contract to mint wrapped tokens, and `_unwrap`, which withdraws a specified amount of native currency from the WETH9 contract by burning wrapped tokens. Both operations only proceed if the amount is greater than zero. The contract includes a receive function that accepts native currency, but it strictly enforces that only the WETH9 contract or a designated `poolManager` can send native currency to it, reverting with an error for any other sender. This ensures controlled interaction with the wrapped token system.
