This contract serves as an extension for a governance system, enabling it to derive voting power from an external token. It maintains a reference to an immutable token that conforms to the `IVotes` and `IERC5805` interfaces. The primary function of this contract is to provide a mechanism for the governance system to query the voting weight of any given address at a specific historical point in time, by calling the `getPastVotes` function on the referenced token. It also exposes the token's clock and clock mode, defaulting to block numbers if the token doesn't implement ERC-6372. There are no direct operations for external callers to perform on this contract beyond querying the token address, its clock, and clock mode; all voting logic is handled by the overarching `Governor` contract it extends.
