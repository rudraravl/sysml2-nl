This contract is an ERC721 token designed for bridging NFTs from a remote chain. It stores the address of a designated `INFERNAL_RIFT_BELOW` contract, which is the only entity permitted to perform sensitive operations. The contract maintains its name, symbol, and a mapping of token IDs to their URIs. It also tracks the `REMOTE_CHAIN_ID` and `REMOTE_TOKEN` address, representing the original NFT's location. A one-time `initialize` function, callable only by `INFERNAL_RIFT_BELOW`, sets these remote chain details, the contract's name and symbol, and establishes a default royalty percentage. `INFERNAL_RIFT_BELOW` can also `setTokenURIAndMintFromRiftAbove`, which assigns a URI to a token ID and mints the NFT to a specified recipient. Additionally, `INFERNAL_RIFT_BELOW` can call `claimRoyalties` to transfer accumulated tokens (including native ETH if a zero address is provided) from the contract to a recipient. The contract implements standard ERC721 and ERC2981 interfaces, including royalty functionality.
