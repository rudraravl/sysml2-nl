This contract acts as an ERC-20 paymaster that allows a designated guarantor to cover the gas costs for user operations. It maintains the state of user operations, including the user, the guarantor, and the prefunded amount. Callers can initiate user operations, which are then prefunded by either the user or a guarantor. If a guarantor is involved, they pay an inflated amount upfront to cover both the operation's gas and an additional cost for the repayment process. After the operation, the contract attempts to recover the total cost from the user. If the user successfully repays, the guarantor receives their full prefunded amount back. If the user fails to repay, the guarantor absorbs the cost. The contract emits an event when a user operation is guaranteed, detailing the user operation hash, the guarantor, and the prefund amount. A critical mechanic is the `_fetchGuarantor` function, which must be implemented by developers to define the logic for identifying a guarantor for a given user operation. The contract also accounts for additional gas costs associated with guaranteed operations during the post-operation phase.
