This contract provides a utility for verifying RSA PKCS#1 v1.5 signatures using SHA256 hashing. It does not maintain any state on-chain itself, but rather offers a pure function for cryptographic validation. Callers can provide data, a signature, and the public key components (exponent and modulus) to the `pkcs1Sha256` function, which will return true if the signature is valid for the given data and public key, and false otherwise. The contract enforces a minimum modulus length of 2048 bits for security and performs checks to prevent malleability by verifying the padding structure. It also includes a warning that the verification does not prevent replay attacks, suggesting that callers incorporate nonces for such protection. There are no access control mechanisms, fees, or upgradeability features, as it is a stateless library for cryptographic verification.
