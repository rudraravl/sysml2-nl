This contract manages a voting system for setting interest rates on various tokens within a lending pool. It stores the associated lending pool, the address of the voting contract, and for each token, its minimum and maximum possible interest rates, along with the total votes cast for increasing or decreasing the rate. It also tracks individual user votes for each token and side, the last epoch rates were updated, and whether rate updates are currently frozen. Callers can trigger an epoch update, which, if not frozen, will prompt the associated quota keeper to retrieve new rates. Any caller can query the calculated rates for a list of tokens based on current votes. The designated voter contract can submit or remove votes for a specific token, user, and side (either towards the minimum or maximum rate). A configurator role can freeze or unfreeze epoch updates, and add new tokens to the gauge with initial minimum and maximum rates. A controller role can adjust the minimum or maximum rate for an existing token. All rate changes and vote actions emit events.
