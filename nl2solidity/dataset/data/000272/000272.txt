This contract provides a mechanism to recover accidentally sent assets, including native currency (ETH), ERC20, ERC721, ERC1155, and ERC6909 tokens, from the contract itself. It maintains a set of bit-flagged locks that control access to these rescue operations and the ability to set further locks. The contract is initialized with a deployer address, which by default is `tx.origin` but can be overridden. Rescue functions can be called either by the contract's deployer, provided the contract is not a proxy and the specific rescue function is not locked for the deployer, or by an `owner()` function (if implemented by an inheriting contract), provided the specific rescue function is not locked for the owner. A `lockRescue` function allows authorized callers to permanently disable specific rescue operations or access for certain roles. All rescue operations will revert if the transfer fails, and if an unauthorized or locked caller attempts a rescue, a `RescueUnauthorizedOrLocked` error is emitted.
