This contract is an ERC20 token extension designed to track and enable claiming of liquidity mining rewards from the Aave system. It maintains state regarding a reference asset (an Aave-related token), a list of reward tokens, and for each reward token, its starting index and the last interaction index and unclaimed rewards for each user. Callers can claim rewards for themselves or on behalf of another user, specifying a receiver for the rewards. A designated incentives controller can also claim rewards. The contract allows refreshing the list of reward tokens and collecting and updating rewards from the incentives controller. It also provides functions to query current reward indexes, total claimable rewards, and unclaimed rewards for a specific user and reward token. When the underlying ERC20 token is transferred, the contract updates the reward data for both the sender and receiver. The contract emits an event when a new reward token is registered.
