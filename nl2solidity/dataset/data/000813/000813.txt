This contract provides a utility library for parsing JSON strings on-chain. It does not maintain any state itself, but rather offers a collection of pure functions that interact with an external `Vm` contract, which is assumed to be a pre-deployed cheat code environment. Callers can provide a JSON string and a key, and the contract will attempt to extract and decode the corresponding value into various Solidity types, including unsigned integers, signed integers, bytes32, strings, addresses, booleans, and dynamic byte arrays, as well as arrays of these types. There are no access control mechanisms, as all functions are internal and intended for use by other contracts within the same execution context. No events are emitted, and there are no fees or upgradeability features. The core mechanic relies on delegating the actual JSON parsing to the `Vm` contract's `parseJson` function.
