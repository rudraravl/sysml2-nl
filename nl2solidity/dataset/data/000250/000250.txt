This contract provides foundational utilities for implementing EIP-712 typed structured data hashing and signing. It doesn't maintain any user-specific state but stores immutable hashes of the contract's name and version, along with its deployment address and the chain ID, to efficiently compute domain separators. Callers can retrieve the EIP-712 domain separator or compute the full EIP-712 digest for a given structured data hash, which can then be used to verify off-chain signatures. Specialized functions are available to compute digests that omit the chain ID or the verifying contract address, catering to cross-chain or multi-verifier scenarios. The contract requires inheriting contracts to define its domain name and version through an internal function, and optionally declare if these values can change post-deployment. The contract implements the EIP-5267 standard for on-chain retrieval of EIP-712 domain parameters. All operations are permissionless, focusing solely on cryptographic hashing.
