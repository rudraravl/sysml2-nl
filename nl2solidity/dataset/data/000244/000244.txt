This contract serves as a utility for enforcing specific call contexts, primarily for contracts designed to be used with proxies or EIP-7702 accounts. It stores its own address at deployment to distinguish between direct calls and calls made through a proxy. Callers can query whether the current execution is happening via an EIP-7702 authority or directly on the contract's implementation. It provides mechanisms to restrict function execution based on these call contexts: `onlyEIP7702Authority` ensures calls originate from an EIP-7702 account, `onlyProxy` ensures calls are made through a proxy, and `notDelegated` ensures calls are made directly to the contract, not through a proxy. If a call violates these restrictions, an `UnauthorizedCallContext` error is raised. There are no events, fees, or upgradeability features, as its sole purpose is to provide call context checks.
