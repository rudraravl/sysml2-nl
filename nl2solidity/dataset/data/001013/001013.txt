This contract serves as a registry for tracking which token addresses are designated as "native yield tokens" within a system. It maintains a mapping that associates each token address with a boolean value indicating whether it is currently enabled as a native yield token. The contract is owned, meaning only the designated owner can modify this registry. The owner can enable or disable any token address as a native yield token by calling a specific function, which will revert if a zero address is provided. Each time a token's native yield status is changed, an event is emitted, providing a public record of the update for off-chain monitoring.
