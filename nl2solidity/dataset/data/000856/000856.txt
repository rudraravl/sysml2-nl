This contract provides utility functions for managing and updating oracle sample data, specifically designed for a liquidity book system. It does not maintain any on-chain state itself, but rather operates on a single `bytes32` value representing a packed sample. This packed sample encodes five pieces of information: a boolean indicating initialization, a timestamp, a cumulative ID, a cumulative volatility accumulated value, and a cumulative bin crossed value. Callers can use the `pack` function to combine these individual components into a single `bytes32` sample. The core functionality is the `update` function, which takes an existing packed sample, an active ID, a volatility accumulated value, and a bin crossed value, then calculates and returns a new packed sample. This update involves computing the time difference since the last sample and using it to project new cumulative values, allowing for potential overflows in cumulative sums which are handled by unchecked math. Additionally, several view functions are available to decode and retrieve each individual component from a given packed sample. There are no access control mechanisms, fees, or events, as this contract serves purely as a stateless helper library.
