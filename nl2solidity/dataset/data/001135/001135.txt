This contract provides a utility library for efficiently managing two 128-bit values within a single 256-bit storage slot, supporting both unsigned and signed integers. It allows callers to extract the left or right 128-bit component from a 256-bit value and to add values to either the left or right slot. The contract also implements safe arithmetic operations (addition and subtraction) for these packed 256-bit values, reverting on overflow or underflow for individual 128-bit components. A specialized `subRect` function performs subtraction and rectifies negative results to zero for each slot. Additionally, an `addCapped` function enables conditional accumulation for two pairs of packed values, where an overflow in any of the four 128-bit components will cap the accumulation for both corresponding left or right slots. This contract does not maintain any state itself; all operations are pure functions that take and return values.
