This contract provides a mechanism for upgrading the logic of a proxy contract, following the UUPS (Universal Upgradeable Proxy Standard) pattern. It does not maintain any state directly but interacts with the proxy's storage to manage the implementation address. The primary operation is `upgradeToAndCall`, which allows an authorized caller to change the underlying implementation contract to a `newImplementation` address. Before upgrading, it verifies that the new implementation correctly identifies itself as compatible with the ERC-1967 standard. An `Upgraded` event is emitted upon a successful upgrade, indicating the new implementation address. The contract also supports an optional delegatecall to the new implementation with provided `data` immediately after the upgrade. Access control for performing upgrades is delegated to a separate, overriding function, `_authorizeUpgrade`, which must be implemented by inheriting contracts.
