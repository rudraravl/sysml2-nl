This contract extends an ERC-7579 compatible account to support a single "hook" module. The contract maintains the address of this optional hook module. Before any internal execution or fallback operation, and before installing or uninstalling any module, the contract will call a `preCheck` function on the installed hook module, if one exists, passing along the sender, value, and call data of the operation. After the operation completes, it will call a `postCheck` function on the hook module. Only one hook module can be installed at a time; attempting to install a second one will revert. The contract provides functions to query its unique account ID and to check if a specific module type or address is installed, including the hook module. Installing or uninstalling modules is restricted to internal calls.
