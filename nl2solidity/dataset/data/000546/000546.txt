This contract provides a set of utility functions for managing the configuration of a lending pool reserve. It does not maintain any state itself, but rather operates on a `ReserveConfigurationMap` data structure, which is expected to be stored elsewhere. The contract allows for setting and retrieving various parameters of a reserve, including its loan-to-value ratio, liquidation threshold, liquidation bonus, asset decimals, active status, frozen status, paused status, borrowing enablement, stable rate borrowing enablement, borrowable in isolation status, siloed borrowing status, flashloan enablement, reserve factor, borrow cap, supply cap, debt ceiling, liquidation protocol fee, unbacked mint cap, and eMode category. Each setter function includes validation to ensure the provided value is within acceptable bounds. There are also convenience functions to retrieve multiple related flags or parameters simultaneously. This contract is designed to be a pure library, meaning it does not store data on-chain but provides logic for manipulating a specific data type.
