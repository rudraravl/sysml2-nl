This contract manages a system of unordered nonces, allowing users to track and consume unique identifiers. It maintains a record for each address, storing a bitmap of used nonces. A nonce is represented by a 256-bit unsigned integer, where the higher bits indicate a "word" and the lower 8 bits specify a position within that word. The primary operation is to consume a nonce, which marks it as used and reverts if the nonce has already been consumed. This consumption can be initiated by any external caller for their own nonces via the `revokeNonce` function. The contract emits no events, and there are no fees, upgradeability mechanisms, or integrations with other protocols. The core mechanic ensures that each specific nonce can only be used once per owner.
