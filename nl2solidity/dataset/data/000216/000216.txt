This contract serves as a factory for deploying ERC4337-compatible smart accounts. It maintains a single, immutable state variable: the address of the core ERC4337 implementation contract, set during deployment. Callers can create new ERC4337 accounts by providing a unique salt, which deterministically derives the account's address. If an account for a given salt already exists, its address is simply returned. Any Ether sent with the creation call is forwarded to the newly created or existing account. The contract also provides functions to predict the deterministic address of an account given a salt, and to retrieve the initialization code hash for these accounts, which is useful for vanity address generation. There are no access control mechanisms; any caller can create an account. No events are emitted. The contract leverages a library for efficient, deterministic proxy deployments, ensuring the created accounts are minimal ERC1967 proxies pointing to the factory's immutable implementation.
