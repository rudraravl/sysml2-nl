This contract provides utility functions for working with CAIP-10 identifiers, which combine a chain identifier and an account address into a single string. It does not maintain any state on-chain. Callers can generate a CAIP-10 identifier for a given account on the current blockchain, or for an arbitrary CAIP-2 chain identifier and account address. Additionally, callers can parse a CAIP-10 identifier string back into its constituent CAIP-2 chain identifier and account address. There are no access controls, fees, or events associated with these operations, as the contract solely offers pure utility functions for string manipulation and formatting. It relies on external libraries for CAIP-2 formatting and address checksumming.
