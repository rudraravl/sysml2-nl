This contract is a utility library providing various bitwise and boolean operations. It does not maintain any state on-chain, nor does it have any access control or emit events. Its purpose is to offer pure functions that perform low-level manipulations on `uint256` values and `bytes` or `bytes calldata` arrays, such as finding the last or first set bit, counting leading zeros, counting set bits (population count), counting zero bytes, checking if a number is a power of two, reversing bits or bytes, and finding common prefixes at bit, nibble, or byte levels. Additionally, it includes functions for logical AND and OR operations on boolean values, with both "raw" variants for clean boolean inputs and more robust versions for potentially unclean inputs, and functions to convert booleans to unsigned integers. All operations are designed for efficiency, leveraging assembly where appropriate.
