This contract manages a collection of non-fungible tokens (NFTs) representing loans, adhering to the ERC-721 standard with enumerable extensions and ERC-5753 compatible locking. It maintains a record of each NFT's owner, a unique identifier, and an optional "unlocker" address if the token is locked. The contract also stores a reference to a central "Loans" contract, which holds administrative and guardian roles. Only the designated Loans contract can mint new NFTs. An administrator, defined by the Loans contract, can update the base URI for all tokens. Guardians, also defined by the Loans contract, can force transfer any unlocked token between addresses. Token owners, approved operators, or per-token approved addresses can lock a token by assigning an unlocker, preventing further transfers or approvals until the designated unlocker explicitly unlocks it. All transfers, locks, and unlocks emit corresponding events for off-chain tracking. The contract also tracks an ownership nonce for each address, incrementing it upon any ownership change to that address.
