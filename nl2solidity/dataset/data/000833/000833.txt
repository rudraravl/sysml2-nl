This contract implements an ERC20 token with the added functionality of creating historical snapshots of token balances and total supply. It maintains a monotonically increasing snapshot identifier and stores arrays of snapshot IDs and corresponding values for each account's balance and the overall total supply. Callers can retrieve an account's balance at a specific snapshot ID using `balanceOfAt` and the total supply at a specific snapshot ID using `totalSupplyAt`. A new snapshot is created by an internal function, `_snapshot`, which increments the snapshot ID and emits a `Snapshot` event. This internal function can be exposed externally with custom access control, allowing for flexible snapshot creation policies. The contract automatically updates relevant snapshots before any token transfer, mint, or burn operation, ensuring historical data accuracy. This mechanism allows for trustless dividend distribution or weighted voting based on past token holdings, preventing "double spend" attacks by reusing balances.
