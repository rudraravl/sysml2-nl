This contract functions as a specialized price oracle, designed to provide a fixed price for an asset. It maintains two immutable state variables: a `STATIC_PRICE` representing the asset's value, which cannot be zero, and a `LIQUIDATE_ZERO` flag indicating whether liquidation attempts should return a zero price. Callers can query the asset's price through three distinct view functions: `getExchangeRateOperate`, `getExchangeRateLiquidate`, and `getExchangeRate`. All three functions return the `STATIC_PRICE` by default. However, if the `LIQUIDATE_ZERO` flag is set to true, `getExchangeRateLiquidate` will return zero, effectively preventing liquidations. The contract inherits from a `FluidOracle` and initializes itself with an informational name and target decimals, but its core purpose is to consistently return the pre-defined static price, with a specific override for liquidation scenarios.
