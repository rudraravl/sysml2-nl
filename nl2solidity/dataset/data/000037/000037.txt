This contract extends a core governance mechanism to manage and count votes for proposals. It maintains the vote counts for each proposal, specifically tracking "against," "for," and "abstain" votes, and records which addresses have already voted on a given proposal. Callers can query the current vote tallies for any proposal ID and check if a specific account has voted. The contract defines how a proposal reaches quorum, which is satisfied if the sum of "for" and "abstain" votes meets a predefined threshold, and how a vote succeeds, requiring "for" votes to strictly exceed "against" votes. When a vote is cast, the contract updates the respective vote counts and marks the voter as having participated, preventing them from voting again on the same proposal. Invalid vote types will cause the transaction to revert.
