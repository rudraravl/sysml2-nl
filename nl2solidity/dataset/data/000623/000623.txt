This contract serves as a decentralized price oracle, providing asset prices primarily through Chainlink aggregators, with a fallback mechanism for unreliable data. It maintains a mapping of assets to their respective Chainlink price sources and stores a designated fallback oracle. Upon deployment, it initializes these asset-source mappings, the fallback oracle, and defines a base currency and its unit. Callers can query the price of a single asset or a list of assets. If an asset's price source returns a non-positive value, or if no source is configured for an asset, the query is automatically forwarded to the fallback oracle. Only authorized asset listing or pool administrators, as determined by an ACL manager, can update asset price sources or change the fallback oracle. Important state changes, such as setting the base currency, updating asset sources, or changing the fallback oracle, emit events for off-chain monitoring.
