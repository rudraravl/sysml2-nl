This contract provides a mechanism to update lending and borrowing caps for various assets within a Aave V3 lending pool. It does not maintain any state itself, but rather interacts with an external `IPoolConfigurator` to modify its settings. The primary operation is `executeCapsUpdate`, which takes a set of cap updates, each specifying an asset and its new supply and/or borrow cap. A special value, `EngineFlags.KEEP_CURRENT`, can be used to indicate that a particular cap for an asset should remain unchanged. The contract ensures that at least one update is provided in a batch. Access control is implicitly handled by the caller of this contract, as it is a library and does not have its own permissions. No events are emitted, and there are no fees, upgradeability, or security guards implemented directly within this contract.
