This contract acts as a central hub for a game ecosystem, managing administrative roles and linking to various game components. It maintains two administrative roles: a main admin and a contract admin, both initially set to the same address upon deployment. The main admin can transfer their ownership to a new address and update the contract admin. The contract stores references to different game modules, including PVE, PVP, and Dual game instances, a farming contract, and a hero NFT contract. It also tracks a `farmPointCondition` and a `heroCondition`, which is a minimum balance of hero NFTs required for certain actions. The main admin can update this `heroCondition`, emitting an event to signal the change. Additionally, the main admin can set the address of the hero NFT contract. Any caller can query if a given inviter meets the `heroCondition` by checking their hero NFT balance.
