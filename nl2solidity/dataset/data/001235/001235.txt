This contract manages dynamic expansion percentages for withdrawal and borrowing limits within a DeFi protocol, based on the protocol's total value locked (TVL) for specific tokens. It stores immutable references to a reserve contract, a liquidity contract, the protocol address it manages, and the specific withdrawal and borrow tokens. Crucially, it maintains a set of TVL checkpoints and corresponding expansion percentages for both withdrawal and borrowing, which are set at deployment. Callers can query the protocol's current supply and borrow data, including the current expansion percentage. The primary operation is `rebalance`, which can only be called by an authorized rebalancer. This function checks the protocol's current supply and borrow amounts against the predefined TVL checkpoints and, if necessary, updates the expansion percentages on the linked liquidity contract. Any update to these percentages emits a `LogUpdateWithdrawLimitExpansion` or `LogUpdateBorrowLimitExpansion` event, providing transparency on limit adjustments. If no update is required, the `rebalance` call will revert.
