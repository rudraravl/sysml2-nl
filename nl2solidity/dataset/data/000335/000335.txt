This contract provides a library of mathematical functions designed for fixed-point arithmetic, specifically for numbers scaled by 1e18, commonly referred to as "WAD" values. It offers operations for multiplication and division that handle this scaling, allowing for both rounding down and rounding up. Additionally, it includes a robust function for calculating integer powers with a specified scalar, and an optimized square root function. The contract also provides "unsafe" versions of modulo and division that return zero instead of reverting when the denominator is zero. This contract does not maintain any state, nor does it have any access control or emit events; its sole purpose is to provide reusable mathematical utilities for other contracts.
