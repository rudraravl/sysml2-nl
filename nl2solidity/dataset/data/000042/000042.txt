This contract extends a standard Governor contract, changing how proposal identifiers are assigned. Instead of using a hash-based ID, it assigns sequential, incrementing numbers to proposals. The contract maintains a record of the most recently assigned proposal ID and maps each proposal's unique hash to its sequential ID. Callers can query the sequential ID for a given proposal's parameters or retrieve the current highest sequential ID. When a new proposal is submitted, if it hasn't been seen before, the contract increments the latest proposal ID and assigns it to the new proposal, storing this mapping. An internal function allows an administrator to initialize the latest proposal ID, but only if no proposals have been created yet, preventing re-initialization. There are no fees or explicit events defined within this specific extension.
