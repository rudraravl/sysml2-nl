This contract manages administrative roles for various pools within a lending protocol. It maintains a system of distinct roles: `POOL_ADMIN_ROLE`, `EMERGENCY_ADMIN_ROLE`, and `RISK_ADMIN_ROLE`, each associated with a specific pool address. Callers can add or remove administrators for each of these roles and pools using functions like `addPoolAdmin`, `addEmergencyAdmin`, `addRiskAdmin`, and their corresponding `remove` counterparts. The contract also provides view functions such as `isPoolAdmin` to check if an address holds a particular role for a given pool. Access to certain operations within the protocol is controlled by these roles, enforced by modifiers like `onlyPoolAdmin` or `onlyEmergencyOrPoolAdmin`, which restrict execution to addresses possessing the required role(s) for a specified pool. The contract does not emit events for role changes, nor does it handle any fees or direct fund transfers.
