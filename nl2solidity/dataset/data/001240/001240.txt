This contract serves as a library for defining various data structures used in a lending protocol. It does not maintain any state itself, nor does it implement any functions or operations that can be called on-chain. Its sole purpose is to provide standardized data types for other contracts to use, ensuring consistency in how parameters for borrow rates, token configurations, and user-specific supply and borrow limits are represented. These structures include definitions for single and double-kink borrow rate models, token-specific fees and utilization thresholds, and detailed parameters for managing user withdrawal and debt ceilings, including expansion percentages, durations, and base/maximum limits. The contract has no access control, emits no events, and integrates with no other protocols, acting purely as a blueprint for data organization.
