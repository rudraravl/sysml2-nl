This contract serves as a utility library for decoding various data structures from calldata, specifically designed for interactions within the Uniswap V4 ecosystem. It doesn't maintain any on-chain state itself, but rather provides pure functions to interpret and extract parameters from raw `bytes calldata` inputs. The primary operations involve decoding complex data types like `PoolKey`, `Currency`, and various Uniswap V4 router parameters (e.g., for modifying liquidity, minting, burning, and swapping) into their constituent parts. All functions are internal and pure, meaning they don't modify the blockchain state and are intended to be used by other contracts. There are no access control mechanisms or events emitted, as its sole purpose is to facilitate efficient and precise parsing of calldata for other contracts. A notable mechanic is the use of inline assembly for optimized calldata slicing and decoding, including checks for strict ABI encoding and bounds to prevent overflows and ensure data integrity, reverting with a `SliceOutOfBounds` error if malformed data is encountered.
