This contract serves as a factory for deploying various types of upgradeable proxy contracts and beacons, facilitating a modular and upgradeable architecture. It maintains records of the bytecode hashes for standard proxies, upgradeable beacons, and beacon proxies, and maps initialization code hashes for deterministic deployments. Callers can deploy new proxies, beacons, or beacon proxies, either with a generated address or deterministically using a provided salt. For deterministic deployments, the salt must begin with the caller's address or be zero. The contract also allows for changing the admin of a deployed proxy or beacon, and upgrading their underlying implementation, provided the caller is the current admin. All deployments, admin changes, and upgrades emit corresponding events to signal these state transitions. The contract is designed to be compatible with both ZKsync and regular EVM environments, adapting its deterministic address prediction mechanism accordingly. Funds sent with deployment or upgrade calls are forwarded to the newly created or upgraded instance.
