This contract provides a set of utility functions designed to efficiently decode compressed transaction parameters for various lending protocol operations. It does not maintain any state itself, but rather operates on a provided mapping of asset IDs to their corresponding addresses. Callers can use these functions to unpack `bytes32` arguments into their constituent parts, such as asset addresses, amounts, referral codes, interest rate modes, permit deadlines, and permit signature values. Specifically, there are distinct decoding functions for supply, supply with permit, withdraw, borrow, repay, repay with permit, swap borrow rate mode, rebalance stable borrow rate, set user use reserve as collateral, and liquidation calls. The contract is purely a library for data manipulation and has no access control, events, or direct interaction with other protocols; its sole purpose is to optimize calldata size by enabling packed arguments.
