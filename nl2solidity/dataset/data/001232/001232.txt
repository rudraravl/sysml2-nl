This contract is a utility library designed to assist with interest rate calculations, specifically focusing on Annual Percentage Yield (APY). It maintains two constant values: `ONE`, representing a unit value for fixed-point arithmetic, and `TEN_THOUSAND_APY`, which is a pre-calculated interest rate factor derived from a 10,000% APY over a mean tropical year. The primary operation it offers is a `pow` function, which calculates the power of a base number raised to an exponent, handling fixed-point arithmetic by scaling the results. This function is intended for internal use by other contracts needing to perform exponentiation in financial calculations, particularly those involving compound interest. The library itself does not store any state or implement access control, nor does it emit events or handle fees; it simply provides a pure mathematical utility.
