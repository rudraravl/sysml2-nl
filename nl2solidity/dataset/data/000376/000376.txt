This contract provides utility functions for manipulating byte arrays. It does not maintain any state on-chain. Callers can perform three main operations: `slice`, which extracts a sub-array of bytes from a given array at a specified starting position and length; `toAddress`, which converts a 20-byte sequence within a byte array into an Ethereum address; and `toUint24`, which converts a 3-byte sequence into a 24-bit unsigned integer. All functions are pure, meaning they do not modify the blockchain state, and they are accessible to any caller. The contract includes checks to prevent out-of-bounds access and overflow errors during these operations. There are no access control mechanisms, events, fees, or upgradeability features, as its sole purpose is to offer low-level byte array manipulation.
