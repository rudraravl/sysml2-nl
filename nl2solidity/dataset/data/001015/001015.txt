This contract acts as a utility for interacting with the Blast L2 yield system. It doesn't maintain any state itself, but rather provides functions to configure yield settings and claim various types of yield from the Blast precompile and rebasing ERC20 tokens. Callers can enable claimable yield for specific rebasing tokens, configure default claimable modes for native ETH and gas, and claim maximum or specific amounts of gas yield, native ETH yield, and token yield. All yield claiming functions allow specifying a recipient address. Important events are emitted for every configuration change and every successful yield claim, detailing the recipient, token (if applicable), and amount. There is no explicit access control within this contract; any caller can invoke its internal functions, which then interact with the Blast precompile or rebasing tokens. A notable mechanic is the ability to make arbitrary calls to the Blast yield precompile for advanced or uncovered operations.
