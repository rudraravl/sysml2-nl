This contract provides a structured way to manage and retrieve various configuration parameters for a financial reserve, packing multiple values into a single 256-bit unsigned integer to optimize storage. It maintains a single `uint256` value, which represents a `ReserveConfigurationMap`, where different segments of the integer store specific reserve properties like Loan-to-Value (LTV), liquidation threshold, liquidation bonus, asset decimals, active status, frozen status, borrowing enablement, paused status, flashloan enablement, reserve factor, borrow cap, supply cap, and liquidation protocol fee. Callers can set and retrieve each of these individual parameters, with some setters enforcing maximum valid values. There are also convenience functions to retrieve multiple related flags or parameters simultaneously. This contract acts as a data management utility, not directly handling funds or external interactions, and does not implement any access control beyond the inherent immutability of its pure functions. No events are emitted, and there are no fees or upgradeability mechanisms.
