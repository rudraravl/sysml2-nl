This contract defines a comprehensive set of data structures used to manage a lending pool. It maintains detailed information about individual reserves, including their configuration (such as loan-to-value ratios, liquidation thresholds, and various caps), current liquidity and borrow rates, and associated token addresses (aToken, stable debt, variable debt). The contract also tracks user-specific configurations, indicating which assets a user has supplied as collateral or borrowed. Additionally, it defines structures for E-Mode categories, which allow for customized lending parameters, and various parameters for core lending operations like supplying, borrowing, repaying, withdrawing, liquidations, and flash loans. These data structures are designed to facilitate complex calculations and validations within a decentralized finance protocol, ensuring accurate state management and secure execution of financial operations.
