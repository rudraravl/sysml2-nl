This contract defines a set of constant integer values representing different levels of preference for a currency to appear in the numerator or denominator of a price ratio. Its sole purpose is to provide these predefined sorting preferences, which can be used by other contracts or off-chain systems to consistently order currencies when displaying price ratios. It does not maintain any state, nor does it have any functions or operations that can be called. There are no access controls, events, fees, or upgradeability mechanisms, as it is a static library of constants. The contract simply makes these specific integer values available on-chain for reference.
