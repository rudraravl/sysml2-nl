This contract serves as a transparent upgradeable proxy, enabling the logic of a deployed contract to be modified over time without changing its address. It maintains the address of the current implementation contract and an administrative address. When a regular user interacts with the proxy, their calls are forwarded to the current implementation. However, if the designated administrator calls the proxy, they can access specific administrative functions to manage the proxy itself. The administrator can retrieve the current implementation address, change the administrative address, or upgrade the proxy to a new implementation contract, optionally executing an initialization function on the new implementation. An `AdminChanged` event is emitted when the administrator is updated, and an `Upgraded` event is emitted when the implementation changes, allowing off-chain systems to track these critical lifecycle events. The contract prevents the administrator from accidentally calling implementation functions by reverting if they attempt to do so.
