This contract provides a utility library for performing a specific modulo calculation. Its sole purpose is to compute `(x - 1) % n` in a way that handles the edge case where `x` is zero, ensuring a positive result. It maintains no state on-chain. The only operation callers can perform is to invoke the `before` function, providing an unsigned integer `x` and an unsigned integer `n`. The function will return `n - 1` if `x` is zero, otherwise it returns `(x - 1) % n`. There are no access controls, permissions, or events. The contract is a pure utility and does not involve fees, upgradeability, or integrations.
