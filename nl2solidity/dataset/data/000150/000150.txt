This contract provides a utility for verifying Ethereum Merkle-Patricia trie inclusion proofs. It does not maintain any on-chain state itself but operates purely on input data. The primary operations are `verify` and `traverse`, which take a target value, a root hash, a key, and an array of proof elements. `verify` returns a boolean indicating whether the proof is valid and the value matches, while `traverse` returns the value if the proof is valid, otherwise it reverts with a specific error indicating the reason for failure. The contract handles different types of trie nodes (branch, leaf, extension) and various proof errors, such as invalid roots, mismatched keys, or unparseable nodes. There are no access controls, fees, or upgradeability mechanisms, as it's a stateless library. It does not emit any events.
