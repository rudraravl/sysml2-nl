This contract acts as a simple, immutable proxy to another contract. Upon deployment, it permanently stores the address of a single target contract. Any subsequent call made to this proxy contract, regardless of the function signature or value sent, will be immediately forwarded to the designated target contract. The proxy does not maintain any additional state beyond its immutable target. It has no specific functions; all interactions are handled through its fallback mechanism, which transparently passes all call data and value to the target and returns whatever the target returns, or reverts if the target reverts. A `TargetSet` event is emitted once during deployment to record the target address. This contract is designed for straightforward, unalterable redirection of all calls to a predefined destination.
