This contract serves as a factory for deploying Coinbase Smart Wallet accounts. It maintains the address of a single, immutable ERC-4337 compliant implementation contract, set during its deployment. Callers can create new smart wallet accounts by providing an initial set of owners and a unique nonce. Each new account is a minimal proxy pointing to the factory's stored implementation. If no owners are specified, the creation will fail. The contract also allows callers to deterministically predict the address of a smart wallet account before it is actually deployed, given the same owners and nonce. This factory does not involve any fees or complex math beyond hashing inputs for deterministic address generation. There are no special access controls; any caller can create or predict account addresses.
