This contract serves as an upgradeable beacon, allowing multiple proxy contracts to share a single, mutable implementation address. It maintains a single state variable: the address of the current implementation contract. The contract is deployed with an initial implementation address and an owner. Only the designated owner can change the implementation address by calling the `upgradeTo` function, providing a new contract address. This action emits an `Upgraded` event, signaling the change to off-chain listeners. The contract ensures that any new implementation address provided is indeed a deployed contract by checking its code length. Callers can query the current implementation address at any time using the `implementation` function.
