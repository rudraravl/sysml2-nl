This contract acts as a gatekeeper for a liquid staking derivative network, determining whether a specific BLS public key is permitted to join the network's "house." It maintains a single piece of state: the address of the core registry for the associated liquid staking network. Upon deployment, this registry address is immutably set. The primary operation callers can perform is to query whether a given BLS public key is permitted to be a member. This function simply delegates the check to the configured liquid staking manager, returning true if the manager confirms the key is part of the LSD network, and false otherwise. There are no fees, upgradeability mechanisms, or events emitted by this contract; its sole purpose is to provide a permission check based on an external liquid staking manager.
