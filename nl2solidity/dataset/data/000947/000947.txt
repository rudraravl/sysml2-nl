This contract defines a standard interface for interest rate models, designed to be implemented by other contracts. Its purpose is to provide a consistent way for financial protocols to calculate borrowing and supplying interest rates based on market conditions. It maintains a constant flag, `isInterestRateModel`, to identify itself. Callers can query two main functions: `getBorrowRate`, which calculates the borrow interest rate per timestamp given the market's cash, total borrows, and reserves; and `getSupplyRate`, which calculates the supply interest rate per timestamp using the same market parameters plus a reserve factor. Both functions return rates as percentages scaled by 1e18. This contract itself does not implement any specific rate calculation logic, but rather specifies the required signature for such implementations, acting as a blueprint for other contracts to adhere to.
