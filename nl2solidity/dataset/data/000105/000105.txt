This contract acts as a wrapper for an existing ERC-721 token, allowing users to convert an "underlying" NFT into a "wrapped" version of the same token ID within this contract. It maintains the address of the immutable underlying ERC-721 token. Callers can deposit underlying tokens by calling `depositFor`, which transfers the specified tokens from the caller to this contract and then mints corresponding wrapped tokens to a designated account. Conversely, `withdrawTo` allows callers to burn their wrapped tokens held by this contract and receive the underlying tokens back to a specified account. The contract also supports direct ERC-721 transfers of the underlying token to its address, automatically minting wrapped tokens to the sender via `onERC721Received`. An internal `_recover` function exists to mint wrapped tokens for underlying tokens that might have been transferred to the contract by mistake. There are no explicit fees or upgradeability mechanisms.
