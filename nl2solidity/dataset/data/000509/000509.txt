This contract allows a Gnosis Safe to record that it has signed an arbitrary message on-chain. It maintains a mapping of message hashes to a boolean value, indicating whether a specific message has been marked as signed. Any caller can invoke the `signMessage` function, providing arbitrary data. The contract then computes a unique hash for this data, incorporating a predefined Safe message type hash and the Safe's domain separator, and marks this hash as signed in its internal storage. After marking a message as signed, it emits a `SignMsg` event, including the message's hash, to notify off-chain observers. The contract also provides a public view function, `getMessageHash`, to allow anyone to pre-compute the hash for a given message without altering the contract's state. There are no fees, and access control is not restricted for signing messages.
