This contract acts as a factory for creating and managing permissioned token adapters. It maintains a record of a designated `POOL_MANAGER` set at deployment. The contract tracks which permissioned token an adapter is associated with and whether that adapter has been verified. Callers can create a new permissions adapter by providing an ERC20 token, an initial owner, and an allowlist checker; this action records the new adapter and emits an event. Separately, any caller can initiate a verification process for an existing adapter. Verification requires the adapter to hold a non-zero balance of its associated permissioned token, and if successful, marks the adapter as verified and emits an event. Only one verification is allowed per adapter.
