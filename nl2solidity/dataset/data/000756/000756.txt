This contract facilitates leveraged short selling of Ether (ETH) using USDC as collateral through an integrated exchange router. It maintains references to essential external contracts like WETH, USDC, the exchange router, a data store, a reader, and an oracle for price feeds. Users can initiate a short position by calling `createShortOrder`, providing the desired leverage and USDC collateral amount. This function requires the user to approve the contract to transfer the specified USDC and also to send an execution fee in ETH. The contract then internally handles the transfer of both the USDC collateral and the execution fee to the exchange's order vault, and subsequently creates the short order. Users can query the unique key for their position using `getPositionKey` and retrieve detailed position information via `getPosition`. To close an existing short position, users call `createCloseOrder`, which also requires an execution fee in ETH, and the contract then creates a corresponding close order on the exchange. The contract does not implement any access control beyond standard `msg.sender` for initiating orders. No events are emitted.
