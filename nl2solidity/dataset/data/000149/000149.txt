This contract provides a utility for verifying digital signatures on-chain, supporting multiple signature schemes. It does not maintain any persistent state itself. Its primary function is to determine if a given signature is valid for a specific data hash and signer. Callers can use `isValidSignatureNow` to verify signatures from externally owned accounts (EOAs) using standard ECDSA recovery, or from smart contract wallets implementing ERC-1271. An overloaded version of `isValidSignatureNow` also supports ERC-7913 signatures, where the signer is a byte array representing an address and an optional key. Additionally, there's `areValidSignaturesNow` to verify a batch of signatures against a batch of signers for a single hash, ensuring no duplicate signers. There are also `isValidSignatureNowCalldata` and `isValidERC1271SignatureNowCalldata` variants for signatures passed as calldata. The contract handles the nuances of each signature type, including the potential revocability of contract-based signatures.
