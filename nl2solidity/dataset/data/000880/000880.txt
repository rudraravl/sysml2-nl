This contract is a specialized vault designed to manage staking funds within a liquid staking ecosystem. It maintains references to a SavETH registry, an account manager, and a dETH token contract. Its primary purpose is to initialize these dependencies by retrieving them from a dependency injector associated with a liquid staking manager. Once initialized, it provides read-only access to these stored references for other components of the system. The contract itself does not implement any direct fund transfer or staking logic, but rather acts as a configurable gateway for other contracts to interact with the core components of the liquid staking protocol. It does not emit any events or implement any access control beyond its initialization function, which can only be called once.
