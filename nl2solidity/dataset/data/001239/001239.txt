This contract serves as a utility library for interacting with the storage of a Fluid Money Market protocol. It does not maintain any state itself, nor does it define any access control or emit events. Its sole purpose is to provide a standardized way to calculate storage slot addresses for various data structures within the Fluid Money Market, which are assumed to be internal to that protocol. It defines constant values representing the base storage slots for different categories of data, such as authorization mappings, money market variables, NFT configurations, token configurations, and various position caps. Additionally, it specifies bit offsets within these slots for individual data fields, like oracle addresses, collateral factors, and position details. The contract offers three pure functions to calculate the exact storage slot for single, double, and triple nested mappings, taking the base slot and mapping keys as input. This allows other contracts to read or write specific data points within the Fluid Money Market's storage by deriving their precise memory locations.
