This contract implements a self-balancing binary search tree, specifically a Red-Black Tree, designed to store unique unsigned 256-bit integer values on-chain. It maintains the tree structure and its nodes in storage, allowing for efficient insertion, removal, and retrieval of values. Callers can query the total number of values stored, retrieve all values in sorted order (though this can be gas-intensive for large trees), check for the existence of a specific value, or find values nearest to a given input. Values can be added to the tree, and existing values can be removed either by specifying the value itself or by providing a pointer to its location within the tree. The contract enforces that values cannot be zero and prevents the insertion of duplicate values. It also handles cases where the tree reaches its maximum capacity. All operations that modify the tree's structure are designed to maintain the Red-Black Tree properties, ensuring balanced performance.
