This contract provides a stateless utility for calculating the outcome of a single swap step within a decentralized exchange. It does not maintain any on-chain state itself. The primary operation is `computeSwapStep`, which takes the current price, a target price, available liquidity, the remaining amount to be swapped (either input or output), and a fee percentage. It returns the new price after the swap, the actual amount of tokens swapped in, the actual amount of tokens swapped out, and the fee amount incurred. This utility is designed to be called by other contracts that manage the actual token balances and liquidity, allowing them to determine the precise quantities involved in a swap, including fees, without directly handling asset transfers. It integrates with external math libraries for complex price and amount calculations.
