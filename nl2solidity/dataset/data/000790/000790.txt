This contract defines various data structures used for managing and updating trading positions within a decentralized exchange or similar financial protocol. It does not maintain any state itself, nor does it implement any functions that can be called on-chain. Instead, it serves as a library, providing structured data types for other contracts to use when performing operations related to positions, such as updating collateral, calculating profit and loss, or determining liquidation status. These structures encapsulate details like market properties, order parameters, position characteristics, and various financial calculations including price impact, PnL, and collateral sufficiency. There are no access controls, events, or specific mechanics like fees or upgradeability within this contract, as its sole purpose is to define data schemas for a larger system.
