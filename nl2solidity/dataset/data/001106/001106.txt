This contract defines a configuration for a decentralized oracle, specifically for integrating with the DIA Oracle V2 system. It stores immutable parameters established at deployment, including the base and quote tokens for a price pair, a heartbeat value indicating data freshness, and normalization factors for price adjustments. It also records the address of the DIA Oracle V2 contract it will interact with. Crucially, it maintains flags to determine if a secondary price conversion to the quote token is needed and if that secondary price should be inverted. A single public function allows any caller to retrieve all these configuration details, providing a snapshot of the oracle's setup. The contract itself does not perform any price fetching or calculations; it solely serves as a read-only repository for these specific oracle configuration parameters.
