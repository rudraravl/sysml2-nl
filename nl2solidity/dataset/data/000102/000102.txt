This contract implements an ERC-721 non-fungible token, extending its functionality to include the ERC-2981 NFT Royalty Standard. It maintains the standard ERC-721 token state, such as ownership and approvals, and additionally stores royalty information for each token. Royalty details, including the recipient address and percentage, can be set globally for all tokens or individually for specific token IDs, with individual settings overriding global ones. Callers can query the royalty information for any given token ID. The contract does not enforce royalty payments; it merely provides a standardized way for marketplaces and other platforms to retrieve this information. It also supports the ERC-165 interface for introspection, allowing other contracts to discover its supported functionalities.
