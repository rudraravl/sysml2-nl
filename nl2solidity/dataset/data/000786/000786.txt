This contract defines various data structures and enumerations used to manage market-related information, particularly for a perpetual futures or similar derivatives exchange. It categorizes changes in funding rates, specifies how market prices for index, long, and short tokens are represented, and outlines collateral types for both long and short positions. The contract also details complex structures for calculating and caching funding amounts per unit of position size, including open interest, duration, and various USD-denominated funding values. Furthermore, it includes structures for caching parameters related to funding factor calculations, funding configuration thresholds, and expected minimum token balances, encompassing pool amounts, swap impacts, and various claimable amounts like collateral, fees, and affiliate rewards. The contract itself does not implement any executable logic or state changes but rather serves as a blueprint for data organization within a larger system.
