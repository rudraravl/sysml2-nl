This contract acts as a vault that holds Ether, which can only be withdrawn by providing a specific password. Upon deployment, it stores a cryptographic hash of a secret password and accepts an initial deposit of Ether. The contract maintains the current balance of Ether it holds and the stored secret hash. Callers can attempt to withdraw the entire balance by providing a password. If the hash of the provided password matches the stored secret hash, the entire Ether balance is transferred to the caller, and a success event is emitted. If the password is incorrect, a fail event is emitted, and no funds are transferred. A dedicated function allows anyone to query the contract's current Ether balance. There are no fees, and the contract is not upgradeable.
