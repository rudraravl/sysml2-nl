This contract is a utility library designed to efficiently store and retrieve small unsigned integer values (uint8, uint16, uint32, uint40, uint64, uint128) within a larger storage slot, effectively packing multiple values into a single `uint256` mapping entry. It defines several struct types, each representing a map for a specific unsigned integer size, which internally uses a `mapping(uint256 => uint256)` to store the packed data. Callers can use `get` functions to read a value at a given index and `set` functions to update a value at a given index within these packed maps. Additionally, the contract provides `searchSorted` functions to perform binary searches on sorted ranges of these packed integer maps, returning whether a `needle` value is found and its index. All operations are internal, meaning this contract is intended to be used by other contracts rather than directly by external accounts, and it does not maintain any state directly accessible by external callers or emit any events.
