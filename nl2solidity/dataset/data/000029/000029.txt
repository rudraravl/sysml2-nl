This contract facilitates cross-chain transfers of multiple tokens, such as ERC-1155 tokens, between different blockchain networks using an ERC-7786 gateway. It maintains no explicit state itself, but orchestrates the sending and receiving of token data. The primary operation is initiating a cross-chain transfer, which involves an internal function that takes the sender's address, the destination interoperable address (including chain reference), an array of token IDs, an array of corresponding values, and arbitrary data. This function first calls an abstract `_onSend` function, which must be implemented by inheriting contracts to handle the actual token movement on the source chain (e.g., burning or locking tokens). It then sends a message via the configured cross-chain gateway. Upon receiving a message from a gateway, the contract decodes the payload, which contains the original sender's interoperable address, the recipient's EVM address, token IDs, values, and data. It then calls an abstract `_onReceive` function, which must be implemented by inheriting contracts to handle token creation or unlocking on the destination chain. Access control for processing incoming messages is managed by an authorized gateway mechanism. Important events are emitted for both sending and receiving transfers, providing a record of cross-chain activity.
