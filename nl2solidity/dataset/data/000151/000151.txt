This contract provides a utility for verifying WebAuthn Authentication Assertions on-chain, enabling smart contracts to leverage strong authentication methods. It does not maintain any state itself, but rather offers a `verify` function that takes a WebAuthn authentication assertion, a challenge, and a public key (qx, qy coordinates) as input. The `verify` function performs several checks: it validates the assertion type, ensures the challenge matches, confirms user presence, and optionally verifies user authentication strength (User Verified flag). It also checks the consistency of backup eligibility and state flags. The contract relies on an external P256 library for cryptographic signature verification. A `tryDecodeAuth` function is also provided to safely decode the WebAuthnAuth structure from calldata. This contract is designed to be integrated into other contracts that require WebAuthn authentication, without managing any internal state or access control.
