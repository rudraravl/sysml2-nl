This contract facilitates the distribution of non-fungible tokens (NFTs) by allowing users to claim them based on Merkle proofs. It maintains a record of the associated NFT contract, a list of Merkle roots, each linked to a specific NFT tier, and a bitmap to track which nodes within each Merkle tree have already been claimed. Callers can claim NFTs by providing a valid Merkle proof, which includes their address, the number of NFTs they are claiming, and the specific node index within the Merkle tree. The contract verifies this proof against the stored Merkle root for the corresponding tier. If the proof is valid and the node has not been claimed previously, the contract marks the node as claimed and mints the specified number of NFTs of the associated tier to the caller's address. A `Claimed` event is emitted upon successful NFT claims. The contract does not have specific access control for claiming, but relies on the validity of the Merkle proof.
