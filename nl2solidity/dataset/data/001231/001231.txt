This contract provides utility functions for calculating fees and refunds related to orders within a conditional token exchange system. It doesn't maintain any state on-chain itself, acting purely as a stateless library for computations. Callers can determine the refund amount for an order based on the order's signed fee rate versus an operator's fee rate, the number of outcome tokens, and the maker/taker amounts and side of the order. It also allows calculation of the amount of tokens to be received for a given making amount, and the total fee for an order based on a specified fee rate, outcome tokens, maker/taker amounts, and order side. All calculations are pure mathematical operations, involving no external calls or state modifications. There are no access controls, events, or upgradeability mechanisms, as it's a computational utility.
