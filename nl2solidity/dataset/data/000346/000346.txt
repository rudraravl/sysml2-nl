This contract provides utility functions for working with unsigned 256-bit integers, specifically for determining the position of their most and least significant bits. It does not maintain any state on-chain. Callers can invoke two main operations: `mostSignificantBit` and `leastSignificantBit`. Both functions take a single unsigned 256-bit integer as input, which must be greater than zero. `mostSignificantBit` returns the zero-indexed position of the highest set bit, while `leastSignificantBit` returns the zero-indexed position of the lowest set bit. There are no access controls, fees, or events associated with these operations, as they are pure mathematical computations. The contract is designed to be a stateless library, offering fundamental bit manipulation capabilities for other contracts to utilize.
