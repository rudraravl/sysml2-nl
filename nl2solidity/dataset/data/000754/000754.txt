This contract facilitates leveraged long positions on ETH using WETH as collateral. It maintains references to WETH and USDC tokens, an exchange router, a data store, a reader, and an oracle for price feeds. Upon deployment, it stores the address of the oracle. Callers can initiate a long ETH position by providing WETH collateral and specifying leverage, which involves transferring WETH and an execution fee to an order vault, then creating an order. The contract also allows callers to retrieve the key for a position, fetch the full details of a position given its key, and calculate the profit and loss of a position based on a provided ETH price. Finally, callers can create an order to close an existing long position, which also requires an execution fee. All interactions involve sending funds to an external order vault for processing.
