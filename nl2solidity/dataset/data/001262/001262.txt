This contract serves as a repository for various constant values used across a decentralized exchange (DEX) system. It does not maintain any mutable state or offer any callable functions. Its sole purpose is to define and store fixed parameters, such as specific storage slot identifiers for extra data and governance, boolean flags for different swap types (single or hopped), the address and decimals for a native token, precision values for token decimals and prices, minimum and maximum token decimal limits, coefficient sizes, default exponent settings, and a collection of hexadecimal constants representing various bitmasks or multipliers. Additionally, it defines a minimum liquidity threshold for swaps and a unique identifier for estimating swaps. This contract acts as a central, immutable source of truth for these foundational parameters, ensuring consistency across integrated components.
