This contract calculates the net asset value (NAV) of a portfolio of loans by applying configurable discount factors. It stores a set of eight discount factors, one for each loan valuation bucket (Current, DQ30, DQ60, DQ90, DQ120, ChargedOff, Closed, Cancelled), and a portfolio-level adjustment factor, all initialized at deployment. The contract allows authorized callers to retrieve the total value of a list of loans from an external `Loans` contract, applying the appropriate discount factor based on each loan's status and due date, and then applying the portfolio-level adjustment. Access control is managed by roles: a `GUARDIAN_ROLE` can set the maximum allowed portfolio factor, while a `CALCULATING_AGENT` role can adjust individual discount factors and the portfolio factor within its defined maximum. Changes to any factor increment a configuration version and emit corresponding events, allowing external systems to detect stale NAV calculations.
