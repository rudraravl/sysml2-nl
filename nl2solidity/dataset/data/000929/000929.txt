This contract provides a library for managing enumerable map data structures on-chain, allowing developers to store key-value pairs while also being able to iterate through all stored keys. It supports various key-value type combinations, including `uint256` to `address`, `address` to `uint256`, `bytes32` to `bytes32`, `uint256` to `uint256`, and `bytes32` to `uint256`. Callers can add new key-value pairs or update existing ones, remove entries, check if a key exists, retrieve the total number of entries, and fetch a key-value pair by its index. Additionally, functions are available to retrieve a value by its key, with options for custom error messages or non-reverting attempts. A notable feature is the ability to retrieve all keys as an array, though this operation has an unbounded cost and is primarily intended for off-chain queries due to potential gas limitations for large maps. There are no specific access controls or events defined within this library; its functionality is designed to be integrated into other contracts.
