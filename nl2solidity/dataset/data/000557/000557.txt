This contract manages the total outstanding debt associated with assets used in "isolation mode" within a lending protocol. It maintains a record of each reserve's configuration and current state, along with individual user configurations. The primary operation is to update the isolated debt whenever a user repays a loan or is liquidated. If a user is in isolation mode, the contract calculates the portion of the repayment that applies to the isolated debt, adjusts the total isolated debt for the collateral asset, and emits an event indicating the updated total. This ensures that the system accurately tracks the debt ceiling for isolated assets, even if the repayment amount exceeds the recorded isolated debt due to accrued interest.
