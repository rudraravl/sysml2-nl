This contract acts as a plugin for a proxy system, specifically designed to enable the proxy to receive and hold ERC-1155 and ERC-721 tokens. It maintains no internal state beyond its inherent ability to receive these token types. The primary operation it performs is to declare its support for the standard token reception functions: `onERC1155Received`, `onERC1155BatchReceived`, and `onERC721Received`. Any external caller can query the contract via the `getMethods` function to retrieve a list of these supported function signatures. There are no access control mechanisms, fees, or events emitted by this contract; its sole purpose is to provide the necessary interfaces for a proxy to handle incoming ERC-1155 and ERC-721 token transfers.
