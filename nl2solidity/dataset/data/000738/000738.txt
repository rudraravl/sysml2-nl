This contract implements a sliding window oracle designed to provide moving average prices for token pairs. It maintains a record of cumulative prices for various token pairs over a defined `windowSize`, divided into `granularity` periods. The contract stores these observations in a mapping from each pair's address to an array of `Observation` structs, each containing a timestamp and cumulative prices for both tokens in the pair. Any caller can invoke the `update` function for a specific token pair (identified by `tokenA` and `tokenB`) to record the current cumulative prices, but this update only occurs once per period to prevent excessive state changes. The `consult` function allows any caller to query the moving average price for a given `amountIn` of `tokenIn` to receive `tokenOut`, calculated over the specified window. This function relies on the `update` function having been called sufficiently to populate the historical observations. The contract is initialized with a factory address, the desired `windowSize` for the average, and the `granularity` of observations within that window.
