This contract establishes a robust ownership management system, maintaining a single owner address and optionally tracking pending ownership transfers. The owner is set during initialization, and subsequent changes are recorded. The primary operations include `transferOwnership`, allowing the current owner to directly assign ownership to a new address, and `renounceOwnership`, which relinquishes ownership by setting it to the zero address. For enhanced security, a two-step ownership handover process is available: a potential new owner can `requestOwnershipHandover`, which sets an expiry timestamp for the request (defaulting to 48 hours), and the current owner can then `completeOwnershipHandover` to that specific address. The pending owner can also `cancelOwnershipHandover` before it's completed. All ownership changes and handover requests/cancellations emit corresponding events for off-chain monitoring. Access to owner-restricted functions is controlled by the `onlyOwner` modifier, which reverts if the caller is not the current owner. The contract stores the owner address and the expiry timestamps for pending handovers.
