This contract provides a robust and secure library for handling ETH and ERC20 token transfers. It doesn't maintain any state itself, but offers a collection of functions that other contracts can use to interact with tokens and native currency. For ETH, it provides standard transfers, functions to transfer all ETH, and "force" transfer options that employ a `SELFDESTRUCT` mechanism to guarantee delivery even if the recipient reverts or runs out of gas, with configurable gas stipends. It also includes "try" variants that return a boolean indicating success instead of reverting. For ERC20 tokens, it offers functions for `transferFrom`, `transfer`, `approve`, and `balanceOf` queries. Notably, it includes a `safeApproveWithRetry` function to handle tokens like USDT that require a zero-approval before setting a new allowance. All functions are designed to revert on failure, with specific error messages for different transfer types, ensuring clear feedback on operation outcomes.
