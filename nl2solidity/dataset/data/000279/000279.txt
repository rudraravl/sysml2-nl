This contract implements a Red-Black Tree data structure, designed to store and manage a sorted collection of unique unsigned 256-bit integers on-chain. It maintains the tree's internal structure, including node relationships and color properties, to ensure efficient search, insertion, and deletion operations. Callers can query the total number of values in the tree, retrieve all values in ascending order (though this can be gas-intensive for large trees), and find specific values or their nearest neighbors. Values can be inserted into the tree, and existing values can be removed, either by specifying the value itself or by providing a pointer to its location. The contract also allows navigation through the sorted values by finding the first, last, next, or previous element relative to a given pointer. All operations are designed to maintain the Red-Black Tree properties, ensuring logarithmic time complexity for most actions. The contract does not implement any access control, allowing any caller to modify the tree. It emits no events.
