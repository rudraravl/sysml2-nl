This contract provides a utility library for calculating interest, primarily for financial applications. It maintains a constant representing the number of seconds in a year, ignoring leap years. Callers can compute linear interest, which calculates a simple accumulation based on a rate and time elapsed since a last update. Additionally, the contract offers a function to calculate compounded interest using a binomial approximation to optimize gas costs. This approximation slightly favors borrowers and underpays liquidity providers, but significantly reduces transaction fees. This compounded interest calculation can be performed either by providing a specific current timestamp or by using the current block timestamp. All calculations are performed using a fixed-point arithmetic library for precision.
