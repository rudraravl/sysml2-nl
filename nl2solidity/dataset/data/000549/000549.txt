This contract provides a utility for retrieving a user's current debt balances within a lending protocol. It does not maintain any state itself, but rather operates on external data provided to it. The primary operation is to query the stable and variable debt token balances for a specific user. This is achieved by taking a user's address and a `ReserveCache` data structure, which contains the addresses of the stable and variable debt tokens for a particular reserve. The contract then directly queries the `balanceOf` function on these external ERC-20 debt token contracts to determine the user's outstanding stable and variable debt. There are no access controls, fees, or events associated with this contract, as its sole purpose is to perform a read-only calculation based on provided inputs and external contract states.
