This contract extends a Governor, enabling it to utilize an external token for voting power. It is initialized with the address of an `IVotes` compatible token, which it stores immutably. The contract's primary purpose is to delegate the calculation of voting weight to this external token. When queried for the current "clock" (a timepoint for voting), it attempts to retrieve it directly from the token; if the token doesn't support this, it defaults to the current block number. Similarly, it describes its clock mode by querying the token, falling back to a block number description if unavailable. For any account and a given timepoint, the contract determines the voting power by calling the `getPastVotes` function on the associated token, effectively using the token's snapshot mechanism for vote counting.
