This contract provides a pausing mechanism for other contracts to inherit. It maintains a single boolean state variable indicating whether the contract is currently paused. Any contract inheriting this functionality can be paused or unpaused by an authorized account. When paused, functions marked with `whenNotPaused` will revert, and when unpaused, functions marked with `whenPaused` will revert. The contract emits a `Paused` event when it transitions to a paused state, including the address of the account that triggered the pause, and an `Unpaused` event when it transitions back to an unpaused state, also including the triggering account's address. Callers can query the current pause status using the `paused()` function. This mechanism allows for emergency stops or controlled maintenance periods.
