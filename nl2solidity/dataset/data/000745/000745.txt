This contract provides utility functions for bitwise operations on unsigned 256-bit integers. Its purpose is to efficiently determine the position of the most significant bit (MSB) or the least significant bit (LSB) within a given non-zero integer. It does not maintain any state on-chain, nor does it have any access control or specific permissions. Callers can invoke two main operations: `mostSignificantBit` which returns the index of the highest set bit, and `leastSignificantBit` which returns the index of the lowest set bit. Both functions require the input integer to be greater than zero. There are no events emitted, no fees, no upgradeability mechanisms, and no integrations with other protocols. The contract is purely a mathematical utility library.
