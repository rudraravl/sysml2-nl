This contract extends a standard ERC721 non-fungible token to provide enumerability features, allowing callers to discover all tokens held by a specific owner and all tokens ever minted by the contract. It maintains internal mappings to track the index of each token within an owner's collection and within the contract's total supply, along with arrays to store the token IDs themselves. Callers can query the total number of tokens in existence via `totalSupply()`, retrieve a specific token by its index in the global list using `tokenByIndex()`, and find a specific token owned by an address by its index within that owner's collection using `tokenOfOwnerByIndex()`. The contract automatically updates these enumeration lists whenever a token is minted, transferred, or burned. It explicitly disallows batch minting to ensure the integrity of its enumeration data structures.
