This contract implements a Merkle tree data structure that allows for sequential insertion and updating of leaves. It maintains the tree's depth, the next available leaf index, and an array of "zero" values used to represent empty nodes at each level, along with an array to store intermediate hashes ("sides") during tree construction. Callers can initialize a tree by specifying its depth and a zero-value, optionally providing a custom hashing function. New leaves can be added sequentially, which updates the tree's root. Existing leaves can also be updated by providing the old and new leaf values, along with an inclusion proof, which returns both the old and new root. The contract ensures that updates are applied to valid indices and that proofs are correct, otherwise it reverts. It does not store historical roots, requiring external mechanisms to track them.
