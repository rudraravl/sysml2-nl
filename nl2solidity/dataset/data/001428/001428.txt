This contract creates an ERC-721 compliant non-fungible token collection. It functions as an upgradeable proxy, meaning its core logic resides in a separate, immutable implementation contract, allowing for future upgrades to its functionality without changing the contract address. Upon deployment, it initializes the underlying ERC-721 implementation with a specified name and symbol for the token collection. All subsequent calls to this contract are automatically delegated to the current implementation contract, enabling standard ERC-721 operations like minting, transferring, and managing NFTs. The contract itself does not maintain any unique state beyond the address of its current implementation, which is stored in a specific storage slot. There are no direct functions for callers to interact with on this proxy contract, as all interactions are forwarded to the implementation.
