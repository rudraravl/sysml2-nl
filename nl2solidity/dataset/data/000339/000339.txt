This contract provides a mechanism to store arbitrary byte data on-chain efficiently. It does not maintain any state itself, but rather deploys new, uncallable contracts to hold the provided data as their bytecode. Callers can write data by invoking the `write` operation, which returns the address of the newly deployed contract acting as a pointer to the stored data. Subsequently, callers can retrieve this data, or portions of it, using various `read` operations by providing the pointer address and optional start/end offsets. There are no access controls, fees, or events; any caller can write new data or read existing data. The core mechanic involves deploying contracts whose runtime code is the data itself, prefixed with a `STOP` opcode to prevent execution, and then using `extcodecopy` to retrieve it.
