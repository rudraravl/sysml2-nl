This contract serves as a read-only data resolver for the Fluid Lending protocol, providing convenient access to various details about its fTokens and user positions. It maintains immutable references to the core lending factory and a liquidity resolver. Callers can query the contract to retrieve lists of all fToken types and deployed fTokens, compute the address of an fToken for a given asset and type, and check if an address has specific authorization or deployer roles within the lending factory. The contract can fetch comprehensive details for any fToken, including its underlying asset, EIP-2612 permit support, native underlying status, name, symbol, decimals, total assets, total supply, conversion rates between assets and shares, current rewards rate, supply rate, and rebalance difference. It also provides internal fToken data like associated liquidity, rewards rate model, and Permit2 integration. Furthermore, the contract can retrieve all fToken details in a single call, or gather all user-specific positions across all fTokens, including fToken shares, underlying assets, underlying balance, and allowance. It also allows querying fToken reward model configurations and previewing deposit, mint, withdraw, and redeem operations.
