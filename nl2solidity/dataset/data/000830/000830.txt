This contract extends the ERC-1155 token standard to provide flexible management of token metadata URIs. It maintains an optional base URI that can apply to all tokens, and individual token URIs for specific token IDs. When a token's URI is requested, the contract first checks if a specific URI is set for that token ID; if so, it concatenates the base URI with the token-specific URI. Otherwise, it defers to the default ERC-1155 URI behavior. Callers can set the base URI for all tokens or set a specific URI for a given token ID. Any update to a token's URI emits a `URI` event, allowing off-chain systems to track metadata changes. This contract is designed to be inherited by other contracts, providing a modular way to handle token URI storage.
