This contract provides utility functions for safely retrieving metadata for ERC20 tokens, specifically their symbol and decimals, even if the token contract does not fully implement the ERC20 standard or provides inconsistent data. It does not maintain any state itself. Callers can query for a token's symbol, which will attempt to read the standard ERC20 symbol, but will fall back to generating a symbol from the token's address if the standard symbol is unavailable or empty. Symbols exceeding a maximum length are truncated. Callers can also query for a token's decimals, which will attempt to read the standard ERC20 decimals, defaulting to 18 for a zero address or 0 if the call fails or returns an invalid value. There are no access controls, fees, or events, as it's a stateless utility.
