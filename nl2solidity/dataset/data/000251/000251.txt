This contract acts as a factory for deploying and managing upgradeable proxy contracts. It maintains a record of the administrative address for each proxy it creates, which is stored internally. Callers can deploy new proxies, either with a standard deployment or deterministically using a salt, optionally providing initial call data to execute on the new proxy. The contract also allows the designated admin of a deployed proxy to change that proxy's admin or to upgrade its underlying implementation, again with an optional call. All deployments and administrative changes emit events, including the proxy address, implementation address, and admin, enabling off-chain monitoring. Access control for changing admin or upgrading a proxy is strictly enforced: only the currently registered admin for a specific proxy can perform these actions, otherwise, the transaction will revert.
