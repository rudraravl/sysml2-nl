This contract implements an ERC-20 compliant token named "420OG" with the symbol "420OG", featuring a fixed maximum supply of 420 tokens (with 18 decimal places). It maintains a state variable indicating whether token transfers are generally allowed, initially set to false. The contract owner can enable or disable general token transfers at any time, emitting an `AllowTransfer` event upon change. Additionally, the owner can designate a specific "OG Staking Contract" address, which is the only entity permitted to mint new tokens up to the cap or burn existing tokens. Minting and burning operations emit `Mint` and `Burn` events respectively. All other standard ERC-20 token functionalities, such as balance queries and approvals, are available.
