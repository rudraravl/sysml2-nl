This contract provides a library for performing fixed-point arithmetic using unsigned integers. It defines two fixed-point number types: `uq112x112` for numbers with 112 bits for the integer part and 112 bits for the fractional part, and `uq144x112` for numbers with 144 integer bits and 112 fractional bits. The library maintains constants for the fractional resolution and masks for bitwise operations. Callers can decode a `uq144x112` to its integer component, multiply a `uq112x112` by an unsigned integer, and calculate the fixed-point representation of a fraction. All operations include checks to prevent overflow and division by zero, ensuring mathematical correctness within the defined fixed-point ranges. There are no state variables, access controls, events, or external integrations as it is purely a utility library.
