This contract serves as a registry for Collateralized Debt Positions (CDPs), tracking which users own CDPs for specific collateral assets. It maintains a list of CDP owners for each asset and an index to quickly locate an owner's position within that list. The contract is initialized with references to a Vault contract, which manages the actual debt positions, and a Collateral Registry contract, which lists supported collateral assets. Any external caller can trigger a "checkpoint" operation for a given asset and owner. This operation checks if a CDP exists and has outstanding debt in the Vault and if it's currently listed in this registry. If a CDP is alive but not listed, it's added to the registry; if it's listed but no longer alive, it's removed. These additions and removals emit events for off-chain monitoring. Callers can also perform batch checkpointing for multiple owners of a single asset or for multiple assets and owners. The contract provides functions to query the existence and status of CDPs, retrieve all CDPs associated with a specific collateral asset or owner, or get a comprehensive list of all active CDPs and their counts. There are no fees or special access controls; all checkpointing and query functions are publicly accessible.
