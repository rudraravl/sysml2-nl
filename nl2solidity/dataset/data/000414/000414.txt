This contract provides a utility for managing the initialized state of "ticks" within a specific range, optimized for efficient storage. It maintains a mapping where each key represents a "word" and its associated value is a 256-bit integer, with each bit indicating the initialized status of a particular tick. Callers can flip the initialized state of a specific tick, effectively toggling it between true and false. A key constraint is that ticks must be aligned with a predefined `tickSpacing`, otherwise the operation will revert with a `TickMisaligned` error. The contract also offers a function to find the next initialized tick within a limited range, either to the left or right of a given starting tick, returning both the tick value and whether it is initialized. This functionality is designed to work within a single "word" of 256 ticks for efficiency.
