This contract serves as a centralized access control manager for a system, maintaining a registry of various administrative and operational roles. It stores the address of a Pool Addresses Provider, which is immutable after deployment. The contract defines several distinct roles: Pool Admin, Emergency Admin, Risk Admin, Flash Borrower, Bridge, and Asset Listing Admin. Upon deployment, a default administrator is assigned based on the Pool Addresses Provider. This default administrator is the only entity initially authorized to set the administrator for any specific role. For each defined role, there are functions allowing any caller to check if a given address possesses that role, and functions for granting or revoking roles. The `grantRole` and `revokeRole` operations are restricted to the default administrator for all roles. The contract emits events whenever a role is granted or revoked, allowing off-chain systems to track permission changes.
