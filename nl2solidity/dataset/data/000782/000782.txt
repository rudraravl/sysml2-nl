This contract defines a data structure, `GlvDeposit.Props`, to encapsulate all the necessary information for a GLV deposit operation. It records various addresses involved, such as the GLV protocol address, the user's account, the receiver of funds, a callback contract, a UI fee receiver, the market address, and the initial long and short tokens. It also stores numerical values like the market token amount, initial long and short token amounts, minimum GLV tokens expected, a timestamp for updates, execution fees, and callback gas limits. Additionally, it includes boolean flags to indicate whether a native token should be unwrapped and if the deposit is for market tokens. This structure serves as a comprehensive record for a GLV deposit, enabling other contracts to process and manage these deposits by passing around a single, organized data object.
