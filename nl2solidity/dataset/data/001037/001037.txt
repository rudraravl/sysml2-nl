This contract provides a utility library for performing ECDSA signature verification on the secp256k1 elliptic curve. It does not maintain any state on-chain, serving purely as a computational tool. The primary operation is `ecdsa_verify`, which takes a message hash, the `r` and `s` components of a signature, and the `x` and `y` coordinates of the public key, then returns a boolean indicating whether the signature is valid for the given message and public key. The contract incorporates several helper functions for elliptic curve arithmetic, such as point addition, doubling, and modular inversion, leveraging the ModExp precompiled contract for efficient modular exponentiation. There are no access controls or special permissions, as all functions are internal and designed to be called by other contracts within the same transaction context. No events are emitted, and there are no fees or upgradeability mechanisms. The contract is optimized for curves with a specific 'a' coefficient and prime order, and includes checks to ensure input points are on the curve and signature components are within valid ranges.
