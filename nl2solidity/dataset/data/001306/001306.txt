This contract provides a mechanism to query the structure of a "Diamond" proxy contract, which aggregates functionality from multiple external "facet" contracts. It maintains state about which facet addresses are currently active and which function selectors (the first four bytes of a function's keccak256 hash) are associated with each facet. Callers can retrieve a list of all active facets along with their supported function selectors, get all function selectors for a specific facet address, list all active facet addresses, or find the specific facet address that handles a given function selector. This contract is purely for introspection and does not modify the Diamond's behavior; it only exposes its current configuration. There are no access control restrictions on these read-only operations, and no events are emitted by these specific functions. The contract relies on an internal storage structure managed by a library to access the Diamond's configuration.
