This contract establishes a multi-owner access control system, allowing multiple designated entities to manage its privileged functions. It maintains a record of owners, identified either by an Ethereum address or a 64-byte public key, and assigns each a unique index. Callers can add new owners using either an Ethereum address or a public key, but only existing owners or the contract itself can perform this action. Owners can also be removed by specifying their assigned index. The contract provides functions to check if a given address or public key is currently an owner, and to retrieve the owner bytes associated with a specific index. It also tracks the next available index for new owners. Important events are emitted when an owner is added or removed, allowing off-chain systems to monitor changes in ownership. The contract ensures that only authorized owners can execute privileged operations and prevents adding an owner that is already registered. Initial owners can be set during deployment, with validation for correct address or public key formats.
