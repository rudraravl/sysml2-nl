This contract provides a utility for verifying WebAuthn authentication assertions on-chain. It does not maintain any persistent state itself, but rather offers functions to validate data provided by a caller. The core operation is the `verify` function, which takes a challenge, a flag indicating if user verification is required, WebAuthn authentication data (including authenticator data, client data JSON, challenge and type indices, and signature components `r` and `s`), and the public key components `x` and `y`. This function checks several aspects of the WebAuthn assertion, such as the "User Present" flag, the type and challenge within the client data JSON, and the validity of the secp256r1 signature over the combined authenticator and client data. It also provides helper functions to encode and decode the WebAuthn authentication data in both standard and compact formats, optimizing for gas or calldata usage. There is no access control, as all functions are internal and intended for use by other contracts. No events are emitted, and there are no fees or upgradeability mechanisms.
