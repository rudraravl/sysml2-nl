This contract acts as a factory for deploying Arbitrum root gauges, which are specialized contracts for bridging Balancer (BAL) tokens to a single recipient on Arbitrum. It maintains the current gas limit, gas price, and maximum submission cost for these bridging transactions. Callers can query these Arbitrum fee parameters at any time. The contract's primary function is to create new Arbitrum root gauges, specifying a recipient address for the bridged BAL and a relative weight cap for the gauge. Only an authenticated caller, as defined by a linked Balancer Vault, can modify the Arbitrum fee parameters. Any change to these fees emits an event, allowing off-chain systems to track updates.
