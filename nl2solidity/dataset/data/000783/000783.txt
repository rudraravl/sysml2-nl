This contract defines utility structures and constants for managing GLV deposits within a decentralized exchange ecosystem. It outlines parameters for creating a GLV deposit, including the GLV token address, associated market, receiver, callback contract, UI fee receiver, initial long and short tokens, swap paths, minimum GLV tokens, execution fee, and gas limits. It also specifies parameters for executing a GLV deposit, such as data store, event emitter, GLV vault, oracle, and a unique key. Additionally, it provides parameters for canceling a GLV deposit, including a reason. The contract maintains no state itself, but defines the data structures used by other contracts to manage the lifecycle of GLV deposits. A notable constant is defined for the receiver of the first GLV deposit. This contract serves as a blueprint for interactions with GLV deposits, ensuring consistent data handling across related components.
