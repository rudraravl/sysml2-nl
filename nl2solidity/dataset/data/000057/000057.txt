This contract serves as a factory for deploying minimal, upgradeable proxy contracts that adhere to the ERC-1967 standard. It does not maintain any persistent state itself, but rather facilitates the creation of other contracts. Callers can deploy new proxies using either a standard `create` operation or a deterministic `create2` operation, optionally sending native currency to the newly created proxy. The `clone` function deploys a proxy to a new, non-deterministic address, while `cloneDeterministic` deploys to an address predictable by a given salt. Each successful proxy deployment emits an `Upgraded` event from the new proxy's address, indicating its implementation. The contract also provides a `predictDeterministicAddress` function to calculate the address a proxy would occupy if deployed with `cloneDeterministic`. It's important to note that these proxies do not automatically initialize, requiring the caller to perform initialization in a subsequent transaction.
