This contract serves as a foundational utility for testing and development environments, providing a suite of "cheat codes" to manipulate the blockchain state and simulate various scenarios. It does not maintain any persistent on-chain state in the traditional sense, but rather interacts with a virtual machine to alter temporary states for testing purposes. Callers can perform operations such as advancing or rewinding time, impersonating specific addresses for transactions (pranking), and directly setting the Ether balance of an account or the token balance of an ERC20 or ERC1155 token for any address, optionally adjusting the total supply. The contract also includes functions to create labeled addresses and their corresponding private keys, destroy accounts, and read transaction and receipt data from JSON artifacts. Access control is not implemented as this contract is intended for a controlled testing environment. It emits no events as its operations are primarily off-chain or within a simulated environment. Notable mechanics include the ability to parse transaction and receipt data conforming to both EIP-1559 and legacy formats, and modifiers to conditionally execute code based on whether the environment is a fork or to temporarily disable gas metering.
