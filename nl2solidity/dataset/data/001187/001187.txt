This contract provides a comprehensive library for fixed-point arithmetic operations, primarily focused on calculations involving a `WAD` (1e18) scalar. It offers functions for multiplication and division, both rounded down and up, for both unsigned and signed integers, with and without overflow checks. Beyond basic arithmetic, it includes advanced mathematical functions like exponentiation (`expWad`), natural logarithm (`lnWad`), and the Lambert W function (`lambertW0Wad`), all operating with `WAD` denominated inputs and outputs. The contract also features full-precision multiplication and division (`fullMulDiv`, `fullMulDivUp`) to handle intermediate products that might exceed 256 bits, ensuring accuracy and preventing overflows. All functions include robust error handling for common issues like division by zero, overflow, and out-of-domain inputs, reverting with specific error codes. This contract is purely a utility library and does not maintain any state or implement access control; its purpose is to be imported and used by other contracts requiring precise fixed-point calculations.
