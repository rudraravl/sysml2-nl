This contract serves as a factory for creating new, independently owned smart wallets. It maintains a record of a "master wallet" template, which is itself an `OwnableSmartWallet` instance created upon the factory's deployment. The contract tracks which wallet addresses have been generated by it. Callers can request the creation of a new smart wallet, either for themselves as the owner or for a specified address. Each new wallet is a clone of the master template and is immediately initialized with the designated owner. The factory ensures that the provided owner address is not zero. Every successful wallet creation emits an event, indicating the address of the new wallet and its initial owner, allowing off-chain systems to monitor new wallet deployments.
