This contract provides a set of utility functions for calculating a user's financial position within a lending protocol. It does not maintain any state itself, but operates on data provided by other contracts, specifically reserve data, user balances, and configuration settings. The primary function calculates a user's total collateral, total debt, average loan-to-value (LTV), average liquidation threshold, and health factor across all active reserves. It also indicates if any collateral has a zero LTV. Another function determines the maximum amount a user can borrow based on their collateral, existing debt, and average LTV. These calculations rely on asset prices obtained from an external pool contract and account for asset decimals. The contract does not have any access control or emit events, serving purely as a computational library for complex financial metrics.
