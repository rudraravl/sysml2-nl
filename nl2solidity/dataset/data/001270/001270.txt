This contract provides a helper function for calculating fee collection amounts during a liquidation process involving two tokens. It takes as input the fee amounts for each token, the total value to be withdrawn, the prices of each token, and liquidation penalties for each token. The contract determines how much of each token's fee can be collected, prioritizing the first token, and ensures that the protocol is on the winning side by rounding calculations appropriately. It incorporates liquidation penalties into the withdrawal value and includes checks to prevent collecting more fees than available or processing withdrawals below a certain value threshold. If the remaining withdrawal value is still significant after attempting to collect fees, it reverts, indicating invalid parameters.
