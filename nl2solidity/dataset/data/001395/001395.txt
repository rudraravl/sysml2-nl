This contract functions as a proxy for an ERC721 non-fungible token collection, named "Gmba00 Calendar" with the symbol "GMBAC". Its primary purpose is to enable upgradeability for the underlying NFT contract logic. Upon deployment, it immediately initializes an external implementation contract at a predefined address, passing the collection's name and symbol. All subsequent calls to this contract are automatically delegated to this external implementation, allowing the core NFT functionalities like minting, transfers, and ownership management to be handled by the linked contract. The contract itself only maintains a single state variable: the address of its current implementation, which can be queried by anyone. There are no direct functions for callers to interact with the NFT logic on this contract; all interactions are routed through the delegated calls to the implementation.
