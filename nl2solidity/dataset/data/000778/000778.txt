This contract acts as a callback handler for a vault, primarily managing WETH withdrawals and execution fee refunds. It maintains a mapping of order keys to refund addresses. The contract is initialized with the address of the vault it interacts with and permanently stores the WETH token address. Only a designated GMX order handler can invoke the core callback functions. It allows for three main callbacks: `refundExecutionFee`, which sends any held Ether to a previously set refund account for a given order key; `afterOrderExecution`, which processes a market decrease order by transferring WETH from the contract to the user's account, potentially sending excess WETH back to the vault; and `afterOrderCancellation` and `afterOrderFrozen`, which both set a refund account for a market decrease order and remove the order from the vault. A separate `transfer` function allows an authorized address to move WETH from the contract.
