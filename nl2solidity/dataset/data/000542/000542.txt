This contract acts as a sentinel for a price oracle, determining if certain operations are allowed based on the oracle's health. It maintains the address of a `PoolAddressesProvider`, a `SequencerOracle`, and a `gracePeriod` duration. Callers can query `isBorrowAllowed()` and `isLiquidationAllowed()`, both of which return true only if the `SequencerOracle` is considered "up" and its `latestRoundData` indicates that the time since its last update exceeds the configured `gracePeriod`. The contract's `SequencerOracle` can be updated by a Pool Admin, and the `gracePeriod` can be adjusted by either a Risk Admin or a Pool Admin. Updates to the `SequencerOracle` and `gracePeriod` emit corresponding events. The contract also provides view functions to retrieve the current `SequencerOracle` address and `gracePeriod`.
