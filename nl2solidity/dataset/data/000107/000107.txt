This contract provides a utility function to verify if a recipient address is prepared to receive an ERC-721 token. It does not maintain any state itself. The primary operation is `checkOnERC721Received`, which takes the operator, sender, recipient, token ID, and optional data as input. This function attempts to call the `onERC721Received` method on the recipient address if that address contains code. If the recipient is a smart contract, it must implement `onERC721Received` and return a specific magic value to signal acceptance of the token transfer. If the recipient contract does not return the correct magic value, or if the call reverts, the function will revert, indicating the recipient is invalid. This ensures that ERC-721 tokens are not accidentally sent to contracts that cannot handle them. There are no access controls, events, fees, or upgradeability mechanisms within this utility.
