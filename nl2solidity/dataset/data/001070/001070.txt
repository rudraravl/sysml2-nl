This contract provides a foundational pausing mechanism for other contracts. It maintains a record of when it was last paused, storing a timestamp for this event, and resets this timestamp when unpaused. The primary operations are `pause` and `unpause`, which allow designated administrators to halt or resume contract functionality. Access to these functions is strictly controlled: only accounts granted the `PAUSER_ROLE` can invoke them. When the contract is paused, its state is updated, and the `pausedAt` timestamp is set to the current block time. Conversely, unpausing clears this timestamp. This contract is designed to be inherited, providing a robust and permissioned way to manage operational pauses for more complex systems.
