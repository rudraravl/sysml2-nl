This contract provides utility functions for creating empty `bytes` and `string` calldata objects. Its purpose is to offer a standardized way to represent empty calldata sequences without allocating memory or requiring any specific input. The contract does not maintain any state, nor does it have any access control or permissions, as all its functions are pure and internal. Callers cannot directly interact with this contract on-chain; instead, other contracts can internally call its `emptyBytes()` or `emptyString()` functions to obtain an empty calldata representation. There are no events emitted, no fees, and no integrations with other protocols. The core mechanic is the use of assembly to efficiently return calldata pointers to zero-length data, ensuring memory safety.
