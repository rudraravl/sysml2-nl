This contract provides a set of utility functions for interacting with ERC-20 tokens safely, handling variations in token implementations where some tokens might not return a boolean value on success. It doesn't maintain any state itself but rather offers operations to perform on external ERC-20 token contracts. Callers can safely transfer tokens, transfer tokens on behalf of another address, increase or decrease allowances for a spender, and force an approval (which handles tokens requiring a zero-out before re-approval). Additionally, it includes functions for ERC-1363 `transferAndCall`, `transferFromAndCall`, and `approveAndCall` with a relaxed fallback for non-contract addresses, and a utility to attempt to retrieve a token's decimals. All operations are designed to revert if the underlying token operation fails, providing robust error handling. There are no specific access controls as it's a library, and no events are emitted directly by this contract.
