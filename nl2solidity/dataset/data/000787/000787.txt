This contract defines a structured representation for various types of trading orders within a decentralized exchange context. It does not implement any on-chain logic itself, but rather provides a blueprint for order data. The contract categorizes orders by their type, such as market swaps, limit swaps, and different types of position increases or decreases (market, limit, stop-loss, stop-increase). It also includes a liquidation order type and secondary order types like ADL. Each order maintains detailed state, including addresses for the account, receiver, cancellation receiver, callback contract, UI fee receiver, market, initial collateral token, and a swap path. Numerical parameters like order type, swap type for position decreases, size delta, collateral delta, trigger price, acceptable price, execution fee, callback gas limit, minimum output amount, and timestamps for updates and validity are also stored. Additionally, boolean flags indicate if the order is for a long position, if native tokens should be unwrapped, if the order is frozen, or if it should auto-cancel. There are no functions, access controls, events, or specific mechanics like fees or upgradeability implemented within this definition; it solely serves as a data structure.
