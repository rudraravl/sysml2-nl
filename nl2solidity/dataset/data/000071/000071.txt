This contract extends an existing ERC-1155 token implementation to track the total supply of each token ID and the overall total supply across all IDs. It maintains two state variables: a mapping that stores the total quantity of tokens for each unique `id`, and a single variable for the grand total of all tokens across all IDs. Callers can query the `totalSupply` for a specific `id` or the `totalSupply` of all tokens combined. Additionally, a public `exists` function indicates if any tokens of a given `id` are currently in circulation. The contract automatically updates these supply counts whenever tokens are minted (transferred from the zero address) or burned (transferred to the zero address) through its internal update mechanism, ensuring accurate supply tracking without requiring explicit calls from external users. There are no access control mechanisms beyond the base ERC-1155 contract, and no events are emitted directly by this extension.
