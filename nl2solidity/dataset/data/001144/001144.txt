This contract serves as a foundational building block for applications that wish to receive simple flash loans from a specific lending pool. Its primary purpose is to store the address of the lending pool it will interact with. Upon deployment, the contract is initialized with the address of the `IPool` contract from which it intends to receive flash loans, and this pool address is permanently stored. The contract itself doesn't perform any operations beyond this initialization and storing the pool reference; it is designed to be inherited by other contracts that will implement the actual logic for handling received flash loans. There are no direct functions for callers to interact with, no access control mechanisms, and no events emitted by this base contract. It simply provides the immutable reference to the lending pool for its future inheritors.
