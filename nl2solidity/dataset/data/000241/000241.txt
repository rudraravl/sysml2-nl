This contract provides a utility for encoding and decoding data using the Base64 standard, as defined in RFC 4648. It does not maintain any persistent state on-chain. Callers can encode raw byte data into a Base64 string, with options to make the output file-safe (replacing '+' and '/' with '-' and '_') and to omit padding characters. Conversely, callers can decode a Base64 string back into its original byte representation. The decoding function supports both standard and file-safe Base64, as well as a variant from RFC 3501, but it does not handle line breaks within the input. There are no access controls, fees, or events; all functions are pure and operate solely on the provided input data, returning the transformed result. A notable mechanic is that the decoding function prioritizes performance and will not revert on invalid input, meaning it's the caller's responsibility to ensure valid Base64 strings are provided for predictable results.
