This contract establishes and manages a single "manager" role, which can be assigned to a specific address. It stores the current manager's address and allows for its modification. The contract's purpose is to provide a foundational access control mechanism for other contracts that need a designated manager. Callers can query the current manager's address. The manager can be changed by either the current manager or an external "owner" role, which is expected to be defined in a contract inheriting this one. An event is emitted whenever the manager address is successfully updated. The contract prevents setting a zero address as the manager, or changing the manager to the same address it already holds.
