This contract determines a user's eligibility for rewards based on their locked liquidity and outstanding debt. It stores the addresses of a vault registry, a multi-fee distribution contract, and a price provider, along with configurable ratios for required deposits and price tolerance. It also tracks each user's last known eligibility status and any disqualification time. The contract owner can set the Chef Incentives Controller (CIC) address, the LP token address (only once), and adjust the required deposit and price tolerance ratios within defined bounds. The CIC is the only entity permitted to set a user's disqualification time or refresh a user's eligibility status, which involves updating token prices via the price provider. Users can query their locked USD value, the required USD value to be eligible, their current eligibility for rewards, their disqualification time, and the last eligible time. All critical updates to contract parameters or user eligibility status emit events for off-chain monitoring.
