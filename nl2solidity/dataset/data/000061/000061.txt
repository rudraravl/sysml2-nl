This contract acts as a transparent proxy, forwarding all calls to an implementation contract determined by an associated beacon. Upon deployment, it permanently records the address of an `UpgradeableBeacon` contract. This beacon's address cannot be changed after creation. When any function is called on this proxy, it queries the beacon to get the current implementation address and then delegates the call, including any provided data and Ether, to that implementation. This allows the underlying logic of the contract to be upgraded by changing the implementation address within the beacon, without altering the proxy's address. The contract can also be initialized with data during deployment, which is passed as a delegate call to the initial implementation to set up its state.
