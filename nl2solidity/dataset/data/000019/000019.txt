This contract provides a suite of utility functions for interacting with ERC-4337 User Operations, without maintaining any on-chain state itself. Its primary purpose is to help parse and construct the complex data structures involved in account abstraction. Callers can use it to extract various fields from a `PackedUserOperation` such as the factory address, gas limits, and paymaster details, including the paymaster's address, gas limits, and any associated data or signature. It also offers functions to calculate the user operation's hash for a given EntryPoint and to parse or pack validation data, which includes an aggregator address and validity periods based on either timestamps or block numbers. The contract defines constants for different EntryPoint versions and magic values used in validation, facilitating interoperability with the ERC-4337 standard. There are no access control mechanisms or events, as it's a stateless library.
