This contract manages a transaction guard system, allowing a designated entity to enforce pre- and post-execution checks on transactions. It maintains a single state variable: the address of the currently active guard. The primary operation is `setGuard`, which allows an authorized caller to set or change the guard's address. If a guard is set, it must support the `ITransactionGuard` interface, otherwise the operation reverts. The contract emits a `ChangedGuard` event whenever the guard's address is updated. Access to `setGuard` is restricted to an authorized caller, which is determined by an inherited `SelfAuthorized` mechanism. The contract also provides an internal function to retrieve the current guard's address.
