This contract provides utility functions for managing a bitmap that represents the configuration of reserves. Its purpose is to efficiently track which reserves are enabled within a 128-bit integer. The contract maintains no state itself; all operations are pure functions that take a bitmap and a reserve index as input. Callers can perform two main operations: `setReserveBitmapBit` allows enabling or disabling a specific reserve at a given index within the bitmap, returning the modified bitmap. The `isReserveEnabledOnBitmap` function checks if a particular reserve index is currently enabled in a provided bitmap, returning a boolean. There is no access control as these are pure utility functions. No events are emitted, and there are no fees, upgradeability, or external integrations. The contract ensures that the provided reserve index is within a valid range before performing any bitwise operations.
