This contract extends a standard ERC-721 non-fungible token to manage token-specific metadata URIs. It maintains a mapping of token identifiers to their unique URI suffixes. Callers can query the full token URI for any existing token, which combines a contract-wide base URI (if set) with the token's specific suffix. The contract owner or an authorized minter can set or update the URI suffix for individual tokens. Any update to a token's metadata URI triggers a `MetadataUpdate` event, allowing off-chain services to track changes. The contract also supports the ERC-4906 interface, indicating its compatibility with metadata update notifications, and inherits standard ERC-721 access control for minting and burning tokens.
