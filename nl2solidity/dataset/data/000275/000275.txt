This contract provides a utility for safely reading metadata from other contracts, specifically their name, symbol, and decimals, or any arbitrary string or unsigned integer. It does not maintain any state itself, but rather interacts with other contracts to retrieve information. Callers can request the `name()` or `symbol()` as a string, or `decimals()` as a uint8, from a specified target address. Additionally, it offers generic functions to read any string or unsigned integer by providing the calldata directly. The contract employs a best-effort approach, meaning it attempts to decode the return data in multiple ways and will not revert if the target contract behaves unexpectedly, instead returning an empty string or zero. It also includes mechanisms to limit the length of strings read and to provide a gas stipend for the call, preventing griefing attacks. There are no access control mechanisms or events, as its sole purpose is to facilitate robust, read-only interactions with other contracts.
