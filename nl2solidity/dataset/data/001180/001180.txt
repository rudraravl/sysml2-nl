This contract defines a library of custom error types for an NFT Position Manager. It does not maintain any state or perform any on-chain operations itself. Its sole purpose is to provide specific, descriptive error messages that can be used by other contracts to signal various failure conditions. These errors cover scenarios such as unauthorized token ID access, invalid zero addresses or values, balance discrepancies, uncleared positions, unregistered pools, failed ETH transfers, and mismatches between sent and expected amounts. There are no functions, access controls, events, or notable mechanics within this library; it simply serves as a collection of predefined error codes for improved clarity and debugging in a larger system.
