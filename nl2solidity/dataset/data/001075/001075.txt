This contract acts as a proxy for interacting with a Voting Escrow (veBAL) system, specifically for managing boost delegation. It stores the address of the core veBAL token contract and an optional delegation contract. Callers can query the current delegation implementation and the veBAL contract address. It provides functions to retrieve an adjusted veBAL balance for a given user, either directly from the veBAL contract or through the active delegation contract if one is set. Similarly, it can report the total supply of veBAL. Only an authenticated administrator can update the delegation contract or disable it entirely, with each change emitting an event to signal the new implementation address.
