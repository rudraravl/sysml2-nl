This contract provides a set of mathematical functions for calculating price and liquidity changes in a decentralized exchange context, specifically using square root prices represented as Q64.96 fixed-point numbers. It does not maintain any on-chain state itself, acting purely as a stateless library of computations. Callers can determine the next square root price after an input or output of either currency (currency0 or currency1), or calculate the amount of currency0 or currency1 required to move between two specified square root prices given a certain liquidity. The contract handles both positive and negative liquidity changes for these calculations. All operations are permissionless, as it's a library of pure functions. The contract includes robust error handling for invalid inputs like zero prices or liquidity, or potential arithmetic overflows, ensuring calculations remain within valid bounds. It does not emit any events, nor does it involve fees, upgradeability, or direct integrations with other protocols.
