This contract provides a set of mathematical functions designed for precise multiplication and division of unsigned 256-bit integers, specifically handling intermediate products that might exceed 256 bits without losing precision. It does not maintain any state on-chain. The primary operations are `mulDiv`, which calculates the floor of `(a * b) / denominator`, and `mulDivRoundingUp`, which calculates the ceiling of the same expression. Both functions ensure that the result fits within a 256-bit unsigned integer and revert if the denominator is zero or if the final result overflows. There are no access controls, events, or integrations with other protocols, as its sole purpose is to offer robust arithmetic calculations for other contracts to utilize.
