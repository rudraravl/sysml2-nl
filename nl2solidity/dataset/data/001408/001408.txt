This contract implements a deflationary ERC-20 token with a fixed total supply, named "JINUSHINU" and 9 decimal places. It tracks token balances for each address and allows standard ERC-20 operations like transfers and approvals. The contract maintains an owner who has special privileges. A key feature is a dynamic fee structure applied to transfers, which varies based on whether the transaction is a buy (from the Uniswap pair) or a sell (to the Uniswap pair). These fees are split between a reflection mechanism, which redistributes a portion to existing token holders, and a marketing/development address. The contract integrates with Uniswap V2 to facilitate automated token swaps for ETH, which are then sent to the marketing address. It enforces trading restrictions, such as a maximum transaction amount and a maximum wallet size, and can blacklist addresses to prevent them from trading. The owner can enable or disable trading, adjust fee percentages, modify transaction and wallet size limits, and manage fee exclusions for specific addresses. Important events are emitted for token transfers, approvals, and ownership changes.
