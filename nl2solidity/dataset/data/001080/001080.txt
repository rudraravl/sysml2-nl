This contract serves as a cache for protocol fee percentages, aiming to reduce gas costs by storing frequently accessed fee values locally. It maintains the current cached percentages for swap, yield, and AUM (Assets Under Management) fees, along with immutable identifiers for how these fees map to an external protocol fee provider. Upon deployment, it initializes these fee identifiers and populates its cache by querying the external provider. Any caller can trigger an update to the cached fee percentages, which will fetch the latest values from the external provider and store them, emitting an event to signal the change. Callers can query the cached percentage for a specific fee type or retrieve the immutable fee identifier associated with it. During a recovery mode state, all fee percentage queries will return zero.
