This contract serves as a utility for verifying Merkle proofs on-chain. It does not maintain any state itself, acting purely as a stateless function library wrapper. Callers can provide a Merkle proof, a root hash, and a leaf hash to the `verify` function, which will return true if the leaf is included in the Merkle tree represented by the root and proof, or false otherwise. Similarly, the `verifyMultiProof` function allows callers to verify the inclusion of multiple leaves within a Merkle tree, given a multi-proof, the root, the array of leaves, and an array of flags indicating the proof structure. All functions are accessible to any caller and do not involve any fees or special permissions. The contract does not emit any events.
