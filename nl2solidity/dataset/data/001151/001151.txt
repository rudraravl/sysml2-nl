This contract defines a library for managing the configuration of a reserve within a lending protocol. It stores various parameters for each reserve, such as Loan-to-Value (LTV), liquidation threshold, liquidation bonus, asset decimals, frozen status, borrowing enabled status, borrow cap, and supply cap, all packed efficiently into a single `uint256` variable. Callers can set and retrieve these individual parameters, with each setter function validating the input against predefined maximum values. For instance, `setLtv` updates the LTV, while `getLtv` retrieves it, returning zero if the reserve is frozen. Similarly, functions like `setBorrowingEnabled` and `getBorrowingEnabled` manage the borrowing status. There are also convenience functions like `getFlags` to retrieve the frozen and borrowing enabled states simultaneously, and `getParams` to fetch a set of core reserve parameters. The contract does not maintain its own state directly but operates on a `ReserveConfigurationMap` provided by the caller, ensuring modularity and reusability.
