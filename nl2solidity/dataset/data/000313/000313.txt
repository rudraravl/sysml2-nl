This contract provides a library for efficient storage and retrieval of packed unsigned integer values within a larger mapping, optimizing gas usage by storing multiple small integers within a single 256-bit storage slot. It defines several data structures, `Uint8Map`, `Uint16Map`, `Uint32Map`, `Uint40Map`, `Uint64Map`, and `Uint128Map`, each designed to hold a specific unsigned integer size. Callers can use `get` functions to read a value at a given index and `set` functions to update a value at a given index within these maps. Additionally, the contract offers `searchSorted` functions to perform binary searches for a specific value within a sorted range of any of these packed integer maps, returning whether the value was found and its index. The contract does not maintain any state itself, but rather provides utility functions for other contracts to manage their own storage more efficiently. There are no access control mechanisms, events, or external integrations as it's purely a utility library.
