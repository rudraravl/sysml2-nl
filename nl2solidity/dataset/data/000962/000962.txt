This contract provides a utility for calculating the integer square root of a non-negative integer. It does not maintain any state on-chain, nor does it have any owners, access controls, or emit events. Its sole purpose is to offer a pure mathematical function, `sqrt`, which takes a `uint256` as input and returns its integer square root as a `uint256`. Callers can invoke this function to obtain the square root of any given number, with the result being the largest integer less than or equal to the true square root. There are no fees, upgradeability mechanisms, or integrations with other protocols; it is a self-contained mathematical tool.
