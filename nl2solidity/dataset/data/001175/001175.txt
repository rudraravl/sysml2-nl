This contract is a utility library providing fixed-point arithmetic operations, primarily for calculations involving a `WAD` constant, which is defined as 1e18. It does not maintain any on-chain state, nor does it have any callable functions or operations that directly interact with the blockchain. There are no access controls, permissions, or events. Its sole purpose is to offer pure mathematical functions for multiplication and division, both rounded up and down, specifically designed for scenarios where one of the operands is implicitly scaled by `WAD`. This contract is not intended to be deployed as a standalone entity but rather to be used by other contracts that require precise fixed-point arithmetic.
