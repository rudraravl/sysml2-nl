This contract defines a strategy for calculating interest rates within a lending protocol, specifically for a single reserve. It maintains several immutable parameters set at deployment: an optimal usage ratio, a base borrow rate, and two debt slopes. These parameters dictate how interest rates change based on the utilization of the reserve's liquidity. Callers can query the individual debt slopes, the base borrow rate, and the maximum possible borrow rate. The core function calculates the current liquidity rate and borrow rate given the reserve's total debt, available liquidity, and any pending liquidity changes. This calculation uses a two-slope model: one slope applies when the reserve's usage is below the optimal ratio, and a steeper slope applies when usage exceeds this ratio. The contract does not manage funds directly but provides the mathematical logic for interest rate determination, which other parts of the lending protocol would then apply. There are no access control mechanisms beyond the immutability of the initial parameters, and no events are emitted.
