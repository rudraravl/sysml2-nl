This contract provides utility functions for managing the upgradeability of a proxy contract following the ERC-1967 standard. It maintains three key state variables: the address of the current implementation contract, the address of the administrative account, and the address of an upgradeable beacon contract. Callers can retrieve the current implementation, admin, or beacon addresses. The contract allows for upgrading the implementation to a new address, optionally executing a setup function on the new implementation, and emits an `Upgraded` event. It also permits changing the administrative account, emitting an `AdminChanged` event. Finally, it supports upgrading the beacon contract, optionally executing a setup function on the new beacon's implementation, and emits a `BeaconUpgraded` event. All upgrade functions revert if the new address is invalid or if Ether is sent without a setup call, preventing accidental loss of funds.
