This contract provides a utility library with two pure functions: `min` and `zeroFloorSub`. The `min` function takes two unsigned 256-bit integers and returns the smaller of the two. The `zeroFloorSub` function takes two unsigned 256-bit integers, `x` and `y`, and returns the result of `x - y`, but if `y` is greater than `x`, it returns zero instead of a negative value. This contract does not maintain any state, have any access control, emit events, or integrate with other protocols; it simply offers these mathematical helper functions for use by other contracts.
