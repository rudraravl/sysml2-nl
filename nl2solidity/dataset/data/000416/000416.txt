This contract provides read-only access to transient state variables within a PoolManager contract. It allows any caller to query the reserves of a currently synced currency, returning zero if no currency is synced or its reserves are zero. Callers can also retrieve the specific currency that is currently synced. Additionally, it provides the count of outstanding "nonzero deltas" within the PoolManager, which must be cleared before the contract can be locked. The contract also enables querying the delta for a specific caller and currency combination. Finally, it allows any caller to check if the associated PoolManager contract is currently in an unlocked state. The contract itself does not maintain any state; all information is retrieved from an external PoolManager contract.
