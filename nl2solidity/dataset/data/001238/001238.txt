This contract serves as a utility library for interacting with the storage of a separate "Fluid Dex" contract. It does not maintain any state itself, nor does it implement any on-chain operations or access control. Its sole purpose is to provide predefined storage slot identifiers for various data points within the Fluid Dex, such as general variables, total supply and borrow shares, user-specific supply and borrow data, oracle configurations, and price range/threshold shifts. It also defines bit positions for unpacking structured data within these slots, like user supply and borrow allowances, amounts, and timestamps. Additionally, it offers helper functions to calculate the exact storage slot for single and double-mapped data within the Fluid Dex, enabling external callers to directly read specific data points from the Fluid Dex's storage.
