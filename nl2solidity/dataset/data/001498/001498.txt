This contract serves as an "Arbitration and Monitoring" (ARM) system, managing a set of voters who can "bless" specific data roots or "curse" the system. It maintains a dynamic configuration of voters, each with distinct addresses for blessing, cursing, and un-cursing, along with assigned weights for their votes. The contract tracks the progress of blessing votes for individual data roots, marking a root as "blessed" once a cumulative weight threshold is met. It also monitors a global "curse" state, which activates if a collective curse weight threshold is reached. The contract owner has special privileges to reset blessing votes, initiate a curse, or remove curse votes. All significant actions, such as setting configuration, blessing a root, or voting to curse, emit events to allow off-chain systems to track the contract's state and activity. The contract prevents re-entrancy by updating state before any external calls.
