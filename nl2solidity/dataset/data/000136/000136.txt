This contract provides utilities for efficient storage and retrieval of short strings on the blockchain. It doesn't maintain any state itself but offers functions to manipulate a special `ShortString` type. Callers can convert a standard string into a `ShortString` if it's 31 bytes or less, packing the string data and its length into a single 32-byte word. If a string exceeds this length, it can be stored in a separate storage slot, with the `ShortString` then acting as a sentinel value indicating the fallback. Conversely, callers can decode a `ShortString` back into a standard string, automatically handling both the packed and fallback storage mechanisms. Functions are also provided to determine the byte length of a string, whether it's packed or stored via fallback. The contract ensures that strings exceeding the 31-byte limit are rejected when attempting direct packing, and that invalid `ShortString` formats are caught during decoding.
