This contract manages the declaration of supported interfaces for a specific "safe" entity, allowing it to conform to the ERC-165 standard for interface detection. It maintains a record of which interfaces are supported by a given safe. Callers can explicitly set the support status for an interface, add multiple method selectors associated with an interface in a batch, or remove them in a batch. Only the contract itself, acting on behalf of its manager, can modify these interface support settings. When an interface's support status changes, an event is emitted, either `AddedInterface` or `RemovedInterface`, indicating the safe and the interface ID. The contract also provides a `supportsInterface` function, which checks if a given interface ID is supported by the safe, including the ERC-165 and its own handler interface, and any interfaces explicitly set.
