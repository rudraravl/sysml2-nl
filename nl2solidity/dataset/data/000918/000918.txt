This contract extends a standard ERC721 non-fungible token, adding a mechanism to manage token-specific metadata URIs directly on-chain. It maintains a mapping from each token's unique identifier to its associated URI string. Callers can query the URI for any given token, which might combine a contract-wide base URI with a token-specific URI if both are set. The contract allows for setting or updating a token's URI, provided the token already exists, and this action triggers a `MetadataUpdate` event. When a token is burned, any associated token-specific URI is automatically removed from storage. This contract does not introduce any new access control beyond what is inherited from the base ERC721 implementation, nor does it implement fees, upgradeability, or direct integrations with other protocols.
