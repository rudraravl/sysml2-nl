This contract defines a collection of data structures used to manage a decentralized lending protocol. It does not implement any on-chain logic itself, but rather serves as a blueprint for organizing information within such a system. The contract describes the state of individual reserves, including their configuration (like loan-to-value ratios, liquidation thresholds, and borrowing caps), liquidity and borrow indices, interest rates, and timestamps of updates. It also outlines structures for user-specific configurations, tracking which assets a user has supplied as collateral or borrowed. Further data structures detail various parameters for operations such as liquidations, asset supply and borrowing, repayments, withdrawals, and flash loans, including associated amounts, addresses, and extra data. Finally, it provides structures for initializing reserves and an entire lending pool, specifying initial configurations and administrative roles. This contract acts as a foundational data library for a complex lending protocol, ensuring consistent data representation across its various components.
