This contract provides a utility for deploying "clones with immutable arguments" (CWIA), which are minimal proxy contracts that can be initialized with immutable data. It allows for both standard and deterministic deployments of these clones. Callers can deploy a clone of a specified implementation contract, optionally providing Ether during deployment and immutable arguments. For deterministic deployments, a unique salt value is also provided, enabling the prediction of the clone's address before deployment. The contract also offers functions to calculate the initialization code and its hash for a given implementation and immutable data, and to predict the deterministic address of a clone. If a deployed clone receives Ether without any calldata, it will emit a `ReceiveETH` event. Errors are raised if a deployment fails, if a deterministic salt does not meet specific criteria, or if an ETH transfer fails. The contract itself does not maintain any state beyond facilitating these deployments.
