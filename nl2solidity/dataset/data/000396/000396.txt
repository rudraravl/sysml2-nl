This contract provides utility functions for determining bit properties of an unsigned 256-bit integer. It does not maintain any state on-chain. Callers can query the contract to find the index of the most significant bit or the least significant bit of a given positive integer, where the least significant bit is at index 0 and the most significant is at index 255. Both functions require the input value to be greater than zero. There are no access controls, fees, or events associated with these operations; they are pure computations.
