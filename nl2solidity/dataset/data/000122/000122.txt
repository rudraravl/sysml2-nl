This contract provides utility functions for verifying the consistency of an ERC-6372 compatible clock. It doesn't maintain any state itself, but rather interacts with external contracts implementing the `IERC6372` interface or directly with a clock function. Callers can use `blockNumberClockMode` to check if a given clock value matches the current block number, or `timestampClockMode` to check if it matches the current block timestamp. If the provided clock value does not align with the expected on-chain time (either block number or timestamp), the contract will revert with an `ERC6372InconsistentClock` error, indicating that the clock has been unexpectedly modified. Otherwise, it returns a string describing the clock mode and its origin. There are no access control mechanisms, events, or fees associated with these operations.
