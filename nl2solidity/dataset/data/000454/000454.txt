This contract serves as a utility to generate a comprehensive token URI for Uniswap v4 Non-Fungible Tokens (NFTs), which represent liquidity positions. It takes various parameters describing a liquidity position, such as token IDs, currency details (addresses, symbols, decimals), tick ranges, current tick, fee, pool manager, and hooks address. The contract then constructs a JSON-formatted string containing the NFT's name, a detailed description, and an SVG image, all encoded in Base64. The description includes information about the liquidity position, pool manager, currency addresses, hook address, fee tier, and a disclaimer. The name reflects the fee tier, currency pair, and the price range of the position. The SVG image is dynamically generated based on currency addresses, token ID, and other position parameters, including a visual representation of whether the position is currently in range. The contract handles decimal precision for prices and fees, and escapes special characters in currency symbols to ensure proper JSON formatting. All operations are pure functions, meaning they do not modify any state on the blockchain.
