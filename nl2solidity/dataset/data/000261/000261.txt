This contract provides a utility for managing a large collection of boolean flags, efficiently storing them as a "bitmap" in storage. It maintains a single state variable, `map`, which is a mapping of `uint256` keys to `uint256` values, effectively representing buckets of 256 bits. Callers can perform several operations: retrieve the boolean value of a specific bit by its index, set a bit to true, set a bit to false, toggle a bit's value and receive its new state, or set a bit to a specified boolean value. Additionally, it supports batch operations to set or unset a contiguous range of bits. The contract can also count the number of set bits within a given range, find the index of the highest-indexed set bit up to a certain point, and find the index of the lowest-indexed unset bit within a specified range. There are no access control mechanisms, fees, or events; all functions are internal and designed for use by other contracts to manage their own boolean states.
