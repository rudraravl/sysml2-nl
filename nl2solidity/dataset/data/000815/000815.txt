This contract provides a framework for building cross-chain enabled contracts. It doesn't maintain any state itself, but rather defines two access control modifiers and two internal view functions that concrete implementations will use. The `onlyCrossChain` modifier ensures that a function can only be called as part of a cross-chain execution, reverting if not. The `onlyCrossChainSender` modifier further restricts calls to only those originating from a specific cross-chain sender address, reverting with details of the actual and expected sender if there's a mismatch. The internal `_isCrossChain` function determines if the current call is cross-chain, and `_crossChainSender` retrieves the address of the cross-chain message's originator. These functions are virtual and must be implemented by specialized contracts that integrate with specific cross-chain bridges, allowing them to enforce cross-chain specific permissions.
