This contract manages a collection of fungible and non-fungible tokens, adhering to the ERC-1155 standard. It tracks the balances of various token IDs for each owner, allowing for both whole and fractional token amounts internally, though only whole numbers are exposed externally. The contract maintains a list of addresses authorized to mint and burn tokens, and a single administrator address that can manage these minter permissions and set an external inventory manager. Token transfers can be initiated by the token owner or an approved operator, either individually or in batches, and the contract includes safeguards to ensure recipients can properly handle token receipts. All token transfers, approvals, and URI changes are announced via events. The contract integrates with an external inventory manager to retrieve token metadata URIs.
