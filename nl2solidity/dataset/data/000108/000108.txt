This contract provides a standardized way to define and retrieve royalty payment information for NFTs, adhering to the ERC-2981 standard. It maintains state for a default royalty receiver and fraction applicable to all tokens, and also allows for specific royalty configurations for individual token IDs, which take precedence over the default. Callers can query the `royaltyInfo` function with a token ID and sale price to determine the designated royalty receiver and the calculated royalty amount. The contract owner or an authorized entity can set or remove the default royalty information, specifying a receiver address and a fee numerator, which represents a fraction of the sale price. Similarly, they can set or reset royalty information for a particular token ID. The contract includes checks to ensure that royalty receivers are not the zero address and that the royalty fraction does not exceed the sale price. It does not enforce royalty payments but merely signals the information.
