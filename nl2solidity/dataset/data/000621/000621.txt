This contract represents a specific instance of a variable debt token within a lending protocol. It maintains its current revision number and stores the address of the associated lending pool, the underlying asset it tracks, and a rewards controller. Callers can initialize this token instance by providing the lending pool, underlying asset, token decimals, name, symbol, and additional parameters. This initialization can only occur once and verifies that the provided pool matches the one stored internally. The contract emits an `Initialized` event upon successful setup, detailing all the configuration parameters. This token is designed to be upgradeable, allowing for future revisions without deploying an entirely new contract.
