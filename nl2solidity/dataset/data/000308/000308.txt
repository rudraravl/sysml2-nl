This contract provides a library for managing enumerable key-value maps in storage, supporting various key and value types including `bytes32`, `uint256`, and `address`. It allows callers to store, retrieve, and remove key-value pairs, and to query the existence of a key or the total number of entries. Each map maintains an ordered list of its keys, enabling iteration through all stored entries by index. When adding a key-value pair, it can optionally enforce a maximum capacity for the map, reverting if the limit is exceeded. Retrieving a value for a non-existent key will cause a transaction to revert. The contract does not implement any access control or emit events, as it is a utility library designed to be used by other contracts.
