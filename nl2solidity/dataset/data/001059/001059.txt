This contract manages interactions with vaults that conform to the ERC-4626 standard, acting as an intermediary for depositing and withdrawing collateral. It maintains no internal state, instead relying on external vault contracts for all asset tracking. Callers can initiate deposits into a specified vault, providing either the vault's native collateral token or its underlying asset. Similarly, withdrawals can be performed, receiving either the collateral token or its underlying asset. The contract also facilitates increasing or decreasing leverage positions within a vault, handling the necessary swaps and deposits/withdrawals from both the ERC-4626 vault and an associated CDP vault. Access to these operations is controlled by the `PositionAction` base contract, which defines the overall framework for these actions. All token transfers are handled securely using SafeERC20.
