This contract provides a set of mathematical utility functions, specifically for calculating binary logarithms and powers, designed to operate on fixed-point numbers. It does not maintain any persistent state on-chain. Callers can compute the binary logarithm of a given unsigned 128.128-binary fixed-point number, which must be greater than zero, or calculate the power of a 128.128-binary fixed-point number `x` raised to an integer `y`. The logarithm function returns a signed 128.128-binary fixed-point number, while the power function returns an unsigned 128.128-binary fixed-point number. There is no access control, as these are pure mathematical operations. The contract will revert if a logarithm is attempted for zero, or if a power calculation results in an underflow. These functions are intended for internal use by other contracts requiring precise fixed-point arithmetic.
