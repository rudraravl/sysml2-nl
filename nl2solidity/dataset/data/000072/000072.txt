This contract extends a standard ERC-1155 token to manage token-specific metadata URIs. It maintains an optional base URI and a mapping of individual token IDs to their specific URI fragments. Callers can query the full URI for any token ID, which is constructed by concatenating the base URI with the token's specific URI fragment if one is set; otherwise, it defers to the parent ERC-1155 implementation. Internally, the contract allows setting the base URI for all tokens and individually setting or updating the URI fragment for a specific token ID. Each time a token's URI is explicitly set, an event is emitted, providing the new full URI and the token ID, enabling off-chain systems to track metadata changes. There are no direct public functions for setting URIs; this functionality is intended for use by inheriting contracts.
