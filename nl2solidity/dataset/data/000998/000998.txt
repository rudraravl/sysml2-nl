This contract serves as a central hub for retrieving token prices, primarily in ETH and USD, by integrating with various price feeds like Chainlink and Uniswap V3 TWAP oracles. It stores mappings between token addresses and their corresponding price feed contracts, along with their decimal precision and any underlying tokens for derivative feeds. The contract allows callers to query the latest ETH or USD value of a given token amount, or convert USD/ETH values back into token amounts. A crucial feature is its heartbeat mechanism, which monitors the freshness of price data for each token, marking an oracle as "dead" if updates are not received within an expected timeframe. Only a designated master address, controlled by a timelock and multisig, can add new price feeds or TWAP oracle configurations, either individually or in bulk. The contract also provides functions to recalibrate the heartbeat threshold for specific tokens.
