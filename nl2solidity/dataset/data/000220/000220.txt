This contract serves as a utility library for managing EIP-7702 compatible proxy contracts, facilitating their deployment, administration, and upgrade mechanisms. It does not maintain any state itself, but rather provides functions to interact with and query the state of EIP-7702 proxies. Callers can deploy new EIP-7702 proxies, either to a standard address or a deterministic address using a salt, by providing an initial implementation and an initial administrator. The contract also allows querying the delegation of an account, the implementation of a proxy, and whether an address is a valid EIP-7702 proxy. Furthermore, it enables the current administrator of a proxy to change the proxy's administrator or upgrade its implementation. For UUPS-style upgrades, it provides functions for a delegated authority to upgrade its own implementation or request re-initialization. All operations are permissioned by the proxy's internal admin logic, and the contract emits custom errors for various failure conditions like deployment, proxy queries, or administrative changes.
