This contract defines a structured data type, `RiskParameters`, which efficiently stores various risk-related configuration values within a single 256-bit unsigned integer. It does not maintain any on-chain state itself, but rather provides a library of pure functions to encode and decode these parameters. Callers can use the `storeRiskParameters` function to combine individual risk components like safe mode status, different fee percentages (notional, premium, protocol split, builder split), liquidation thresholds, maximum spread, buffer for basis point decrease, and maximum open legs into a single `RiskParameters` value. Conversely, a suite of getter functions allows any caller to extract specific risk parameters from an existing `RiskParameters` value, such as `safeMode`, `notionalFee`, `premiumFee`, `protocolSplit`, `builderSplit`, `tickDeltaLiquidation`, `maxSpread`, `bpDecreaseBuffer`, `maxLegs`, and `feeRecipient`. This contract acts as a utility for compact storage and retrieval of complex risk configurations, without any access control or events, as it merely processes data without altering any state.
