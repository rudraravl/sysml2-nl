This contract extends an existing ERC6909 token standard by adding functionality to associate content URIs with both the contract itself and individual token IDs. It maintains two pieces of state: a single contract-wide URI and a mapping of token IDs to their respective URIs. Callers can query the contract's URI and the URI for any specific token ID. There are no public functions for directly modifying these URIs; instead, internal functions are provided for setting the contract URI and individual token URIs, which are expected to be called by other parts of the inheriting contract. When the contract URI is updated, a `ContractURIUpdated` event is emitted. Similarly, when a token URI is changed, a `URI` event is emitted, including the new URI and the token ID. The contract also correctly reports its support for the `IERC6909ContentURI` interface.
