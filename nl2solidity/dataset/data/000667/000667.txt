This contract manages the distribution of rewards for multiple staking assets. It maintains a record of various assets eligible for rewards, their associated reward tokens, and the configuration for each reward, including emission rates, distribution end times, and accumulated indices. It also tracks individual user data, such as their accumulated rewards and personal indices for each asset-reward pair. Only a designated "emission manager" can configure reward distributions, specifically by setting the distribution end time or updating the emission rate per second for a given asset and reward. Callers can query various data points, including the current reward data for an asset, the distribution end time, the list of available rewards for an asset, and a user's accrued or pending rewards across multiple assets. The contract emits an event whenever an asset's reward configuration is updated or when rewards are accrued for a user. The core mechanic involves calculating reward indices based on asset total supply and emission rates, and then using these indices to determine user rewards.
