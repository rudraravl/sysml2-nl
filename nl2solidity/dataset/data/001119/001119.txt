This contract serves as a factory for deploying and managing Panoptic Pools, which are specialized financial instruments built on top of Uniswap V4 pools. It maintains a record of all deployed Panoptic Pools, mapping a unique identifier (derived from the Uniswap V4 pool key and a risk engine address) to the address of the corresponding Panoptic Pool contract. Callers can deploy a new Panoptic Pool by providing a Uniswap V4 pool key, a risk engine address, and an optional salt value for address customization. This deployment process also creates associated collateral tracker contracts and initializes the new Panoptic Pool. Upon successful deployment, an NFT representing the new pool is minted to the deployer, and a `PoolDeployed` event is emitted, containing the addresses of the new pool, its Uniswap V4 ID, collateral trackers, and risk engine. The contract also offers a helper function to "mine" for Panoptic Pool addresses with a desired number of leading zeros, allowing users to optimize for gas costs or vanity addresses. Additionally, it provides a query function to retrieve the address of a deployed Panoptic Pool given its Uniswap V4 key and risk engine.
