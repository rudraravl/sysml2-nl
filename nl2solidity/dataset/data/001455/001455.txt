This contract functions as a treasury for managing a specific payout token, with an emphasis on interactions with designated bond contracts. It stores the address of a single, immutable payout token and maintains a whitelist of addresses identified as bond contracts. The contract is owned by a single policy address, which is set at deployment and can be transferred to a new address by the current policy. Only whitelisted bond contracts can call the `sendPayoutTokens` function to receive a specified amount of the payout token from the treasury. The policy can withdraw any ERC20 token held by the treasury to a specified destination and amount, emitting a `Withdraw` event. Additionally, the policy has exclusive control over whitelisting and dewhitelisting bond contract addresses, with corresponding `BondContractWhitelisted` and `BondContractDewhitelisted` events emitted for each action. A view function `valueOfToken` provides a conversion of a given amount of any ERC20 token into an equivalent value in the payout token, based on their decimal differences.
