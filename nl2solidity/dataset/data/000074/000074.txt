This contract provides utility functions for handling ERC-1155 token transfers, specifically focusing on recipient validation. It doesn't maintain any state itself but offers two core operations: `checkOnERC1155Received` and `checkOnERC1155BatchReceived`. These functions are designed to be called by an ERC-1155 token contract during a transfer to ensure the receiving address is prepared to accept the tokens. If the recipient is a smart contract, it must implement the `IERC1155Receiver` interface and return a specific magic value to signal acceptance; otherwise, the transfer is rejected with an `ERC1155InvalidReceiver` error. If the recipient is an externally owned account (EOA), no check is performed. This mechanism ensures secure and compliant ERC-1155 token transfers by preventing tokens from being sent to contracts that cannot handle them.
