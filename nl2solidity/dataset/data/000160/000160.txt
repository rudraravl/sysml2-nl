This contract establishes an RSA public key as a signer for cryptographic operations. It maintains two pieces of state: the RSA public exponent (`e`) and the RSA modulus (`n`). The contract can be initialized with these values either during deployment or through a dedicated internal function, which is crucial for setting up the signer correctly. Callers can retrieve the stored public key components (`e` and `n`) at any time. The primary operation is to validate a raw signature against a given hash using the stored RSA public key. This validation specifically employs the PKCSv1.5 standard with SHA256 hashing, ensuring the signature's authenticity. There are no fees, upgradeability mechanisms, or direct integrations with other protocols within this contract itself; its purpose is solely to manage and utilize an RSA public key for signature verification.
