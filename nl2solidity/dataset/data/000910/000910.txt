This contract extends the ERC1155 token standard, enabling the destruction of tokens. It maintains the standard ERC1155 state, including token balances for various IDs and addresses. Callers can perform two main operations: `burn` to destroy a specific quantity of a single token ID from an account, and `burnBatch` to destroy quantities of multiple token IDs from an account simultaneously. Access control dictates that only the token holder themselves or an address that has been granted `isApprovedForAll` permission by the token holder can initiate a burn operation for that account. The contract does not emit any specific events for burning beyond what the underlying ERC1155 implementation might provide for balance changes, nor does it implement any fees, upgradeability, or external integrations.
