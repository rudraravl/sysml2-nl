This contract manages the collection and distribution of protocol fees across various currencies. It maintains a record of accrued fees for each currency and designates a specific address as the protocol fee controller. The contract owner can set this controller, which is the only entity permitted to set the protocol fee for a given pool and collect accrued fees. When collecting fees, the controller can specify an amount or collect all accrued fees for a particular currency, which are then transferred to a designated recipient. The contract prevents fee collection for a specific "synced" currency to avoid conflicts during settlement. It also ensures that protocol fees are within valid bounds when set. All updates to the protocol fee controller and individual pool fees emit events for off-chain monitoring.
