This contract provides a set of utility functions for verifying Merkle proofs on-chain. It does not maintain any state itself, but rather offers pure functions that take Merkle proof components as input and return a boolean indicating validity. Callers can verify a single leaf against a Merkle root using a provided proof, or verify multiple leaves simultaneously with a multi-proof and corresponding flags. The contract includes optimized versions for proofs passed in memory and directly from calldata. There are no access control mechanisms, as all functions are pure and stateless. No events are emitted, and there are no fees, upgradeability, or integrations with other protocols. The contract's sole purpose is to provide gas-efficient Merkle proof verification.
