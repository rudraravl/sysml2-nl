This contract is a non-transferable ERC20-like token designed to track variable-rate debt positions within a lending protocol. It maintains the total supply of variable debt for a specific underlying asset and each user's individual scaled balance. The contract is initialized by a Pool contract, which sets the underlying asset, an incentives controller, and token metadata like name, symbol, and decimals. Only the designated Pool contract can mint new debt tokens to a user, optionally on behalf of another, or burn existing debt tokens. The `balanceOf` and `totalSupply` functions return the actual debt amount by applying a global index from the Pool to the scaled balances. Standard ERC20 transfer and approval functions are explicitly disabled, ensuring the tokens cannot be moved or delegated. An `Initialized` event is emitted upon successful setup.
