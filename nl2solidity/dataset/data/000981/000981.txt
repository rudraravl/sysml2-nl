This contract provides a set of mathematical and utility functions for managing leveraged positions within a Pendle Power Farm, interacting with external WISE lending, Aave, and Oracle Hub protocols. It maintains no direct state but relies on data from these integrated systems. Callers can query the total ETH value of borrowed funds for a specific NFT position, the total weighted collateral in ETH for an NFT position, and calculate a leveraged amount based on an initial sum. The contract also offers internal functions to update pool states by syncing WETH, Aave WETH, and Pendle child token pools with the WISE lending protocol. It includes re-entrancy guards that check the sending progress of itself, WISE lending, and Aave Hub before executing state-changing operations. Furthermore, it provides internal calculations for approximating net APY and new borrow rates, and checks for debt ratios and minimum deposit amounts for NFT positions.
