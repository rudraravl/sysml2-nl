This contract provides a set of utility functions for generating various cryptographic message hashes, primarily for use with signature recovery mechanisms like ECDSA. It does not maintain any on-chain state itself. Callers can compute hashes for different message formats: an Ethereum Signed Message hash from a pre-hashed message or a raw message, a data hash with an intended validator, and an EIP-712 typed data hash from a domain separator and a struct hash. Additionally, it offers functions to construct an EIP-712 domain separator based on specified fields (name, version, chainId, verifyingContract, salt), either from raw strings or their pre-hashed forms. A specific error is raised if unsupported EIP-5267 extensions are requested during domain type hash generation. There are no access controls, fees, or events; all operations are pure computations.
