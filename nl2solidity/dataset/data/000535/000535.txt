This contract serves as a central price oracle for various assets, providing their values in a specified base currency. It maintains a mapping of assets to their primary price sources, which are Chainlink Aggregators, and also stores a fallback oracle address. The contract is initialized with a set of assets and their corresponding price sources, a fallback oracle, and details about the base currency. Callers can query the price of a single asset or multiple assets. If an asset's primary Chainlink source is not set or returns a non-positive price, the request is automatically forwarded to the fallback oracle. Only designated asset listing administrators or pool administrators, as determined by an associated ACL Manager, can update the price sources for assets or change the fallback oracle. Important state changes, such as setting the base currency, updating asset sources, or changing the fallback oracle, emit events for off-chain monitoring.
