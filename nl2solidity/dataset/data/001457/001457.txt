This contract serves as a read-only data aggregator, allowing callers to efficiently retrieve various balance and allowance information across multiple tokens and Beefy-related protocols in a single transaction. It maintains no internal state, acting purely as a utility for external queries. Callers can request the balances of multiple standard tokens for a given owner, or query the balances and earned rewards from multiple Beefy Boosts or Gov Vaults for an owner. Additionally, it provides functions to retrieve allowances for multiple tokens granted to multiple spenders by a specific owner, returning these allowances either grouped by token or as a flattened array. All functions are public and permissionless, allowing any external entity to query the data without restriction. The contract does not emit any events, nor does it involve any fees, upgradeability, or security guards beyond standard Solidity practices.
