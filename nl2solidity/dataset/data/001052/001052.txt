This contract serves as a decentralized price oracle, providing on-chain price feeds for various tokens by integrating with Chainlink. It maintains a mapping of token addresses to their corresponding Chainlink aggregator contracts, along with a configurable stale period and a scaling factor for each oracle. The contract can be upgraded by authorized managers. Upon deployment, an admin and a manager are assigned roles. The administrator can configure the oracle settings for different tokens, including the Chainlink aggregator address, stale period, and scaling factor. Any caller can query the latest price for a token, which is fetched from Chainlink and validated against the configured stale period and a positive value. If the price is invalid or stale, the query will revert. The contract also allows checking the validity status of an oracle for a given token.
