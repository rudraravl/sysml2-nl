This contract provides a utility for tracking temporary currency changes for specific accounts within a single transaction. It maintains no persistent state on the blockchain. Instead, it uses transient storage to record integer deltas for a given currency and target address, which are only accessible during the current transaction and are discarded afterwards. Callers can retrieve the current transient delta for any account and currency, or apply a new delta to an existing one. When a delta is applied, the contract returns both the value before the modification and the new value after the modification. There are no access controls, events, or fees associated with this utility, as its purpose is solely to facilitate in-memory calculations within a transaction.
