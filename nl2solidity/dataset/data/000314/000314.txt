This contract provides a suite of pseudorandom number generation and shuffling utilities. It maintains a `PRNG` state for generating random numbers and a `LazyShuffler` state for efficiently shuffling a range of numbers in storage. Callers can seed the `PRNG` with an initial value, then request the next pseudorandom `uint256`, a uniformly distributed number within a specified upper bound, or samples from standard normal and exponential distributions. The contract also offers in-place Fisher-Yates shuffling for `uint256`, `int256`, `address` arrays, and `bytes` in memory, including partial shuffles. For storage-based shuffling, a `LazyShuffler` can be initialized with a length, grown to a larger length, or restarted to allow re-shuffling. Callers can query the number of elements shuffled, the total length, whether it's initialized, or if the shuffle is finished. The `get` function retrieves the current value at an index, accounting for historical shuffles. The core `next` function performs a single shuffle step and returns the next value, requiring external randomness as input. The contract ensures valid lengths for shuffler initialization and growth, and prevents operations on uninitialized or finished shufflers. There are no access control mechanisms, fees, or events.
