This contract acts as a proxy for an ERC721 token creator, enabling upgradeability for the underlying NFT collection logic. When deployed, it immediately initializes an implementation contract at a fixed address with a specified name and symbol for the NFT collection. All subsequent calls to this contract are automatically delegated to this underlying implementation, meaning the contract itself holds no state beyond the address of its implementation. Callers can query the current implementation address. This design allows the core logic of the NFT creator to be updated in the future by changing the implementation contract, without requiring users to interact with a new proxy address.
