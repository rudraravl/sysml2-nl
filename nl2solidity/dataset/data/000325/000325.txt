This contract establishes a single, designated owner for itself. It maintains a record of this owner's address. The primary operation available is the ability for the current owner to transfer ownership to a new address. Only the current owner can initiate this transfer. Any attempt to call the `transferOwnership` function by an address other than the current owner will be rejected. Each time ownership is transferred, an event is emitted, logging both the previous owner and the new owner, allowing off-chain systems to track changes in control. The contract is initialized with an owner address provided at its creation.
