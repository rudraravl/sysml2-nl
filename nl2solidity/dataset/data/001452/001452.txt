This contract acts as a factory for creating and managing Aave supply and withdrawal routers for various assets. It maintains a reference to the Aave lending pool and the WETH token. Upon deployment, it automatically creates dedicated supply and withdrawal routers for WETH. For any other ERC20 asset, users can call a function to deploy a pair of routers: one for supplying that asset to Aave and another for withdrawing it. The factory can also compute the addresses of these routers without deploying them, and check if a router pair for a specific asset has already been deployed. When supplying or withdrawing, users interact with the specific router, which then handles the Aave interaction. For token operations, the amount can be specified as a fraction of the user's balance by providing calldata, otherwise the maximum amount is used. All router deployments are announced via an event.
