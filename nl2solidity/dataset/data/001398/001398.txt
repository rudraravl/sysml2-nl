This contract defines a collection of data structures and utility functions related to managing a vault system, but it is not a deployable contract itself. Its purpose is to provide standardized definitions for various parameters and states within a vault, along with mathematical helpers for share calculations. It maintains no on-chain state directly, but rather defines the schema for state variables that other contracts would implement. Key operations include converting asset amounts to shares and vice-versa, calculating unredeemed shares from a deposit receipt, and determining the price per share based on total supply, balance, and pending amounts. It also includes functions to assert that numbers fit within specific `uint` sizes. There are no access control mechanisms or events within this library, as it's purely a set of definitions and stateless computations intended to be used by other contracts.
