This contract serves as a utility library for calculating various fees and impacts related to trading positions within a larger decentralized exchange system. It does not maintain any on-chain state itself, but rather defines data structures for input parameters and calculated results. Callers can use these structures to pass in details about a position, its market, and associated prices to compute comprehensive fee breakdowns, including referral fees, professional trader discounts, funding fees, borrowing fees, UI fees, and liquidation fees. It also provides a structure for calculating price impact based on USD delta and position direction. The contract's purpose is purely computational, offering structured data types for complex financial calculations without storing any persistent data or enforcing access control. No events are emitted, and there are no direct interactions with other protocols or mechanisms like upgradeability or security guards implemented within this specific utility.
