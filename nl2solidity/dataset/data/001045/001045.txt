This contract facilitates flash loans of a specific underlying stablecoin and internal credit from a designated pool. It stores the address of the associated pool, the immutable protocol fee for flash loans, and the underlying stablecoin token. Callers can query the maximum available flash loan amount for the stablecoin, which is determined by the pool's credit manager. They can also determine the fee for a given stablecoin flash loan amount. The primary operations are `flashLoan` and `creditFlashLoan`. The `flashLoan` function allows a receiver to borrow the underlying stablecoin, while `creditFlashLoan` enables borrowing internal credit. Both functions transfer the requested amount to the receiver, then call a callback function on the receiver's contract. Upon successful callback, the receiver must return the original amount plus the protocol fee to the contract, which then repays the pool. Both flash loan types emit an event detailing the receiver, token, amount, and fee. The contract prevents re-entrancy attacks by using a re-entrancy guard. Only the underlying stablecoin is supported for `flashLoan` operations.
