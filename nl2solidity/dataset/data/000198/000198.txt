This contract provides a set of utility functions for validating cryptographic signatures on-chain. It does not maintain any persistent state itself, acting purely as a stateless signature verification service. Callers can submit a signer's address, a message hash, and a signature in various formats (full bytes, R and VS components, or V, R, and S components) to check if the signature is valid for the given signer and hash. The contract supports both standard ECDSA signature verification and ERC-1271 compatible signature verification, allowing for smart contract wallets to validate signatures. A separate, internal contract demonstrates a basic ERC-1271 implementation, where a signature is considered valid if it was signed by the transaction's origin. All functions are read-only and do not alter the blockchain state.
