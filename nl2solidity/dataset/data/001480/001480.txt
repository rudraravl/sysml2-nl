This contract acts as a router for retrieving various financial metrics related to investment funds, such as Gross Asset Value (GAV), Net Asset Value (NAV), and share values. It maintains a mapping between fund deployer addresses and their corresponding fund value calculator contracts. Upon deployment, it initializes this mapping with a set of fund deployers and their associated calculators. The contract allows external callers to query these financial metrics for a given fund (identified by its vault proxy address), delegating the actual calculation to the appropriate fund value calculator. Only the owner of the associated Dispatcher contract can update the mapping of fund deployers to fund value calculators. Each update to this mapping emits an event, `FundValueCalculatorUpdated`, to signal the change. The contract integrates with a Dispatcher contract to determine the correct fund deployer for a given vault proxy.
