This contract serves as a data structure library, defining several complex data types for managing debt and collateral information within a financial system. It does not maintain any state itself, nor does it implement any functions or operations. Its sole purpose is to provide structured definitions for `TickDebt`, which records raw and normalized debt/collateral amounts, a ratio, and a tick identifier; `VaultsTickDebt`, which aggregates multiple `TickDebt` entries along with a target tick, vault address, and vault ID; `BranchDebt`, which expands on debt and collateral details with a branch ID, status, partials, ratio, debt factor, and base branch information; and `BranchesDebt`, which groups multiple `BranchDebt` entries with a vault address and vault ID. There are no access controls, events, or notable mechanics as it's purely a blueprint for data.
