This contract manages token quotas for a lending pool, tracking which tokens are "quoted" and their associated parameters to limit the system's exposure to risky assets. It maintains a list of all quoted tokens, their individual quota parameters (rate, cumulative index, increase fee, total quoted amount, and limit), the address of a gauge contract that determines quota rates, and the timestamp of the last rate update. Callers can query the cumulative interest index for a token, its current quota rate, the list of all quoted tokens, and detailed parameters for any specific token. Only the designated gauge contract can add new quota tokens or update the rates for existing ones. A configurator role can set the gauge address and associate credit managers with specific tokens. The contract emits events when a new quota token is added, when a token's quota rate is updated, or when the gauge address is changed, allowing off-chain systems to monitor these critical state changes.
