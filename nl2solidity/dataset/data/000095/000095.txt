This contract extends a base ERC-6909 token implementation to track the total supply for each unique token ID. It maintains a record of the aggregate quantity of each specific token ID that exists. Callers can query the total supply of any given token ID. The contract automatically updates these total supply figures whenever tokens are minted (created from a zero address) or burned (sent to a zero address). It also supports standard interface introspection, allowing external systems to discover its capabilities. There are no specific access controls beyond those inherited from the base ERC-6909 contract, and no explicit events are emitted by this particular extension, as its primary function is to maintain internal supply counts.
