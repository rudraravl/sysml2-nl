This contract acts as a proxy for managing NFT listings and associated token airdrops within a Pilgrim ecosystem. It maintains the addresses of core Pilgrim contracts (PilgrimCore, PilgrimToken, PilgrimMetaNft) and lockup contracts (uniLockup, nftLockup). The contract stores pending token claims for specific NFT/token ID combinations and allows an owner to deposit tokens for future claims. Users can prelist an NFT with an initial price, which is recorded. When an NFT is listed through this proxy by a designated lockup contract, the NFT is transferred to the proxy, then approved for the PilgrimCore contract, and finally listed on PilgrimCore using the prelisted price. If there's an outstanding token claim for that NFT, the tokens are automatically transferred to the original transaction sender. The contract emits events for token claims, token drops, proxy listings, and prelistings. Only the contract owner can set Pilgrim and lockup addresses, drop tokens, and withdraw any held Pilgrim tokens.
