This contract provides a robust JSON parsing library, enabling on-chain smart contracts to interpret and interact with JSON strings. It does not maintain any persistent state itself, acting purely as a utility. Callers can parse a JSON string into a tree-like structure of "Item" objects, which are pointers to parsed JSON nodes. Once parsed, functions allow querying an item's value, its index within an array, its key within an object, or its children. It also provides functions to determine an item's type (array, object, number, string, boolean, or null) and retrieve its parent. Additionally, the library includes utilities for parsing unsigned integers, signed integers, and unsigned hexadecimal integers from strings, and for decoding JSON-encoded strings. All operations are pure, meaning they do not modify the blockchain state, and access control is not applicable as it's a library. The contract reverts with a `ParsingFailed()` error if an invalid JSON string or an improperly formatted input is provided to any parsing function. No events are emitted, and there are no fees or upgradeability mechanisms.
