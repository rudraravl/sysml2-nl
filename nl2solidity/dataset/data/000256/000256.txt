This contract provides a comprehensive library for fixed-point arithmetic, primarily using a WAD (1e18) representation for precision. It does not maintain any state itself but offers a suite of pure functions for calculations. Callers can perform various operations including multiplication and division with WAD scaling, both rounded down and up, for unsigned and signed integers. It also includes more complex mathematical functions like exponentiation (`expWad`), natural logarithm (`lnWad`), and the Lambert W function (`lambertW0Wad`), all denominated in WAD and implemented as approximations. Additionally, it provides a full-precision multiplication and division function (`fullMulDiv`) for large numbers, ensuring accuracy by handling 512-bit intermediate products. The contract includes numerous custom error types to signal specific arithmetic failures, such as overflows or division by zero, ensuring robust error handling. There are no access control mechanisms or events, as it functions purely as a utility library.
