This contract implements a BEP-20 compatible token named SHIBIBI with a fixed total supply. It tracks token balances for each address and allows standard token operations like transfers and approvals. A key feature is its reflection mechanism, where a portion of each transaction (buy or sell) is distributed proportionally to all token holders, effectively increasing their balance over time. The contract also implements a dynamic fee structure, applying different reflection and tax fees for buy and sell transactions, which are sent to designated development and marketing addresses. It includes anti-bot measures, transaction limits, and wallet size limits to prevent manipulation. The contract owner has special privileges, including the ability to set trading on or off, adjust transaction and wallet limits, modify fee percentages, enable/disable the swap mechanism, and exclude specific addresses from fees. The contract integrates with a Uniswap V2 router to facilitate automatic token swaps for ETH, which are then sent to the marketing address. Important events are emitted for token transfers and approvals, allowing off-chain services to monitor token activity.
