This contract establishes a foundational testing environment for other contracts, simulating on-chain interactions without deploying to a live network. It maintains a set of predefined user accounts—Alice, Bob, and Carol—each initialized with a specific Ether balance, and tracks a stack of "pranked" addresses to simulate calls from different users. Callers can create new user accounts with specified balances and labels, advance the blockchain's block number or timestamp, and manage the active "prank" to control the message sender for subsequent operations. It also includes functionality to set up mock contracts for specific chain IDs, particularly for Blast, allowing for testing of Blast-specific integrations. The contract does not implement any access control beyond the testing framework's capabilities, and its primary purpose is to provide a controlled and predictable state for unit and integration tests.
