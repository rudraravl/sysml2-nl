This contract serves as a utility for calculating storage slot identifiers and processing tick values. It maintains no persistent state of its own, but inherits configuration for a factory and a liquidity resolver from its base `Variables` contract. Callers can compute a storage slot for a simple `uint256` value, or for single mappings where the key is either a `uint` or an `int`. It also supports calculating a storage slot for a double mapping with an `int` as the first key and a `uint` as the second. Additionally, the contract provides a helper function to convert a raw `uint` tick value into a signed `int` tick, ensuring the input is within a defined range and handling positive and negative conversions based on the least significant bit. The contract is initialized with the addresses of a factory and a liquidity resolver.
