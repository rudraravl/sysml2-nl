This contract acts as a factory for creating and managing "CuratedVault" instances. It maintains a record of all vaults it has created and stores the address of the current vault implementation. Any caller can request the creation of a new CuratedVault by providing initialization parameters, including a unique salt, proxy admin, and various roles (admins, curators, guardians, allocators), along with a timelock, asset, name, and symbol. Upon creation, the new vault is initialized with these parameters and its address is added to the factory's internal list. The contract owner has exclusive permission to update the address of the vault implementation used for future creations. Events are emitted when a new vault is created and when the implementation address is updated, allowing off-chain systems to track these changes.
