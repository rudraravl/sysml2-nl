This contract serves as a centralized registry for EVM-compatible blockchain network information, primarily for use in development and testing environments. It stores and retrieves details such as chain name, chain ID, and a default RPC URL for various networks, identified by an alias. The contract maintains a mapping of chain aliases to their full data, chain aliases to their default RPC URLs, and chain IDs to their aliases. Callers can retrieve chain data by either its alias or its chain ID. If a chain's RPC URL is not explicitly set, the contract attempts to fetch it from external configuration sources (like a `foundry.toml` file or environment variables) before falling back to its internally stored default RPC URL. Callers can also explicitly set or update chain information using an alias and chain data. The contract initializes a predefined set of common blockchain networks and their default RPC URLs upon the first attempt to access or modify chain data. There are no access control mechanisms; any caller can interact with the public functions. No events are emitted, and there are no fees or upgradeability features.
