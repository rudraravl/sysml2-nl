This contract provides a utility library for formatting and parsing ERC-7930 interoperable addresses, which are a standardized way to represent addresses across different blockchain networks. It does not maintain any on-chain state. Callers can format an interoperable address from its components (chain type, chain reference, and address) or specifically for EVM chains using a chain ID and an Ethereum address. Conversely, callers can parse an interoperable address to extract these components. There are also "try" variants of the parsing functions that return a success boolean instead of reverting on invalid input. The contract handles both memory and calldata inputs for parsing to optimize gas usage. All functions are pure, meaning they do not modify the blockchain state. There are no access control mechanisms, events, fees, or upgradeability features, as it's a stateless utility library.
