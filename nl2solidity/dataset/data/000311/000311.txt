This contract provides a utility for managing a large collection of boolean flags, efficiently stored as a bitmap. It maintains a mapping where each key represents a "bucket" of 256 bits, allowing for a virtually unlimited number of flags. Callers can query the state of an individual bit (set or unset), explicitly set or unset a bit, or toggle its state. Additionally, the contract supports batch operations to set or unset a contiguous range of bits. It can also count the number of set bits within a specified range and find the index of the most significant set bit or the least significant unset bit within given bounds. There are no access control mechanisms, fees, or external integrations; its sole purpose is to offer a robust and gas-efficient way to handle boolean arrays on-chain.
