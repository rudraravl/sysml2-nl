This contract serves as a composite price oracle, combining data from multiple Chainlink price feeds to derive a single, consolidated price. It maintains immutable references to up to three Chainlink oracle addresses: a base oracle, a first multiplier oracle, and an optional second multiplier oracle, all set at deployment. The contract also defines a constant `decimals` value of 18, which is the expected decimal precision for all derived prices. Callers can query the latest composite price through the `latestRoundData` function, which returns the calculated price along with a timestamp and placeholder values for compatibility with Chainlink's `AggregatorV3Interface`. If only two oracles are provided, the price is derived by multiplying the base and first multiplier oracle prices. If three are provided, all three oracle prices are multiplied together. The contract ensures that all intermediate and final prices are positive and scaled to 18 decimals, reverting if any oracle data is invalid or if a negative price is encountered. There are no access control mechanisms; any external caller can retrieve the composite price.
