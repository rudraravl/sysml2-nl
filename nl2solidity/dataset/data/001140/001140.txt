This contract defines a data structure called `PoolData` to efficiently store and retrieve information related to a Uniswap pool within a system called SFPM. It doesn't maintain any on-chain state itself, but rather provides utility functions for encoding and decoding a single `uint256` value into its constituent parts. Callers can create a `PoolData` value by providing the maximum liquidity per tick, a unique pool identifier, the minimum and maximum enforced ticks for the pool, and an initialization flag. Subsequently, any `PoolData` value can be queried to extract each of these individual components: the maximum liquidity per tick, the pool ID, the minimum enforced tick, the maximum enforced tick, and whether the pool has been initialized. There are no access controls, events, or complex mechanics like fees or upgradeability, as its sole purpose is data packing and unpacking.
