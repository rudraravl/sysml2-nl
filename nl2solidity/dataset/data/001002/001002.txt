This contract establishes foundational parameters and access control for a system interacting with Aave and Wise Lending protocols. It maintains immutable references to the Aave and Wise Lending contracts, a WETH address, and a Position NFT contract, along with a mutable reference to a Wise Security contract. It also tracks a mapping of Aave token addresses. The contract's master owner can set the Wise Security contract address once. Callers can query the `sendingProgressAaveHub` flag and the `aaveTokenAddress` mapping. Internal functions allow for checking ownership and lock status of NFTs through the Wise Security and Wise Lending contracts, respectively. The contract is initialized with the master owner, Aave address, and Wise Lending address, ensuring these critical components are set at deployment.
