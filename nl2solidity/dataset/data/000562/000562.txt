This contract defines a set of validation rules for various operations within a lending protocol, ensuring the integrity and security of its financial mechanics. It does not maintain any state itself, but rather performs checks against provided reserve and user data. The contract validates actions such as supplying assets, withdrawing funds, borrowing assets (both stable and variable rate), repaying debt, swapping borrow interest rate modes, rebalancing stable borrow rates, setting assets as collateral, and performing flash loans. It also validates liquidation calls and user health factors. Access control is implicitly handled by the calling functions, as this contract only performs validation logic. Key checks include ensuring active and unpaused reserves, sufficient user balances, adherence to supply and borrow caps, and maintaining a healthy collateralization ratio. It also incorporates a price oracle sentinel for additional security checks. The contract defines several constant thresholds, such as minimum health factors and rebalance liquidity rate thresholds, to enforce protocol rules.
