This contract provides a utility for configuring collateral-related parameters for assets within a lending pool. It doesn't maintain any state itself but interacts with an external pool configurator and a lending pool. Callers can update multiple collateral settings for various assets in a single operation. For each asset, it allows setting the loan-to-value (LTV), liquidation threshold, and liquidation bonus. It also permits configuring the liquidation protocol fee. A notable mechanic is the ability to preserve current values for specific parameters by indicating "KEEP_CURRENT," in which case the contract fetches the existing configuration from the lending pool. It enforces a critical security guard: the product of the liquidation threshold and the liquidation bonus (plus 100%) must not exceed 100%, preventing instant undercollateralization. Additionally, the liquidation protocol fee must be less than 100%. All modifications are executed via an external pool configurator.
