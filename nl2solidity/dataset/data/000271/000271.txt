This contract provides a utility library for compressing and decompressing byte arrays, offering two distinct compression methods. One method, `flzCompress` and `flzDecompress`, implements a FastLZ-based LZ77 algorithm, suitable for general data compression. The other method, `cdCompress` and `cdDecompress`, is optimized for calldata compression using selective run-length encoding for sequences of zero bytes or all-ones bytes. A special `cdFallback` function is included, designed to be called within a contract's fallback function, which decompresses incoming calldata and then performs a delegatecall with the decompressed data. This allows for contracts to receive and process compressed calldata, effectively reducing transaction costs. The contract does not maintain any persistent state, nor does it have any access control or emit events. All operations are pure functions, performing calculations on provided input and returning processed output.
