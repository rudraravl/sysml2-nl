This contract implements a tiered sales mechanism for digital assets, allowing for multiple pricing and allocation plans. It maintains a record of defined sales tiers, including their start and end times, currency, price, maximum items per wallet, a Merkle root for allowlisting, reserved quantities, and total allocation. It also tracks the total number of reserved items across all tiers, the number of reserved items already minted, the total items minted per tier, and the number of items minted by each wallet for each tier. Callers can query if an address is on a tier's allowlist, determine the maximum number of items a specific wallet can mint for a given tier, and execute a mint operation for a specified tier and quantity. The contract owner has special permissions to configure sales tiers. Important events are emitted when ownership is transferred. The contract integrates with ERC20 tokens for payments and uses Merkle proofs for allowlist verification, ensuring that only eligible participants can mint.
