This contract serves as a comprehensive library for defining and managing a wide array of error conditions that can occur within a decentralized exchange or similar financial protocol. It does not maintain any state itself, nor does it implement any functions that can be called directly. Instead, its sole purpose is to provide a standardized set of custom error types, categorized by their functional area (e.g., `AdlHandler`, `Oracle`, `PositionUtils`), along with descriptive messages and relevant parameters. This allows other contracts to revert with specific, informative errors, improving debugging and user experience by clearly indicating why an operation failed. There are no access controls, events, fees, or upgradeability mechanisms within this library, as it is purely a collection of error definitions intended for use by other contracts.
