This contract acts as an upgradeable proxy, allowing its underlying logic to be changed while maintaining the same on-chain address. It stores a single, immutable administrator address upon deployment. The administrator is the only entity with special permissions. Callers can query the current implementation address and the administrator's address, but only the administrator can initiate an upgrade to a new implementation contract, either by simply setting a new address or by setting a new address and then immediately calling a function on the new implementation. All other calls are forwarded to the current implementation contract, unless the caller is the administrator, in which case the call will revert. This design ensures that only the designated administrator can manage the contract's upgrade path.
