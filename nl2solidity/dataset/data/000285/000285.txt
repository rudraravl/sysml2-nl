This contract provides a utility for comparing two Semantic Versioning (SemVer) strings, represented as `bytes32` values. Its sole purpose is to determine the relative order of two versions. It maintains no state on-chain. The contract offers a single public function, `cmp`, which takes two `bytes32` inputs representing the SemVer strings and returns an integer indicating their comparison: -1 if the first version is less than the second, 0 if they are equal, and 1 if the first is greater. This function is designed for efficiency and is forgiving of some malformed inputs, skipping a leading 'v' or 'V' and attempting to parse numeric components. It does not emit any events, nor does it have any access control, fees, upgradeability, or integrations with other protocols, as it is a pure utility library.
