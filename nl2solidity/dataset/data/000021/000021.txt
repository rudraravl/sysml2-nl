This contract establishes and manages connections to other blockchain networks for cross-chain messaging. It maintains a record of "links," where each link associates a specific remote chain with an ERC-7786 gateway address and the full interoperable address of a counterpart contract on that remote chain. Upon deployment, it can be initialized with a set of these links. Callers can query the gateway and counterpart address for any registered chain. The contract allows sending messages to a registered counterpart on a remote chain via its associated gateway, and it verifies that any incoming cross-chain messages originate from a registered counterpart and its designated gateway. When a new link is established, an event is emitted, and attempting to register a link for an already linked chain will fail. This contract serves as a foundational component for building more complex cross-chain applications.
