This contract defines a data structure for managing parameters related to a GLV (presumably a decentralized exchange or similar protocol) withdrawal. It serves as a blueprint for encapsulating all necessary information for such an operation, rather than implementing executable logic itself. The structure maintains details about various addresses involved, including the GLV protocol, the market, the user's account, the ultimate receiver of funds, a callback contract, and a UI fee receiver. It also stores numerical values such as the amount of GLV token to withdraw, minimum expected amounts for long and short tokens, a timestamp for updates, execution fees, and a gas limit for callbacks. Additionally, it includes a flag indicating whether native tokens should be unwrapped. This structure is designed to be used by other contracts or off-chain systems to organize and pass withdrawal-related data efficiently.
