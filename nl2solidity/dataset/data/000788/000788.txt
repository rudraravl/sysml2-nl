This contract defines a data structure, `Position.Props`, to represent a trading position within a decentralized exchange or similar financial protocol. It stores comprehensive details about a user's position, including the `account` holding the position, the `market` it's traded on, and the `collateralToken` used. Key numerical attributes like `sizeInUsd`, `sizeInTokens`, `collateralAmount`, and various funding-related figures (`borrowingFactor`, `fundingFeeAmountPerSize`, `longTokenClaimableFundingAmountPerSize`, `shortTokenClaimableFundingAmountPerSize`) are maintained, alongside timestamps for when the position was `increasedAtTime` or `decreasedAtTime`. A boolean flag, `isLong`, indicates the position's direction. The contract also provides a pure function, `getPositionKey`, which deterministically generates a unique identifier for any given position based on the account, market, collateral token, and position direction. This contract does not implement any state-changing functions, access control, or emit events; it solely defines a data structure and a utility function for identifying positions.
