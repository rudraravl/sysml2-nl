This contract provides a comprehensive library for fixed-point arithmetic operations, primarily using a WAD (1e18) scaling factor for precision. It offers functions for multiplication and division of both unsigned and signed integers, with options for rounding down or up, and includes both checked and unchecked versions for overflow safety. The contract also implements advanced mathematical functions like exponentiation (expWad), natural logarithm (lnWad), and the Lambert W function (lambertW0Wad), which are approximations for fixed-point numbers. Additionally, it provides full-precision multiplication and division utilities (fullMulDiv, fullMulDivUnchecked) that handle 512-bit intermediate products to prevent overflow. The contract's purpose is to enable precise financial calculations on-chain by handling the complexities of fixed-point arithmetic and large number operations, guarding against common errors like overflow and division by zero through custom error messages.
