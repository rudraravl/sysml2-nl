This contract acts as a proxy for an oracle, allowing its underlying oracle implementation to be updated. It maintains a single state variable: the address of the current oracle implementation. Upon deployment, the contract's creator becomes its owner. The owner is the only entity permitted to change the oracle implementation, which they can do by calling a specific function that takes the new oracle's address as an argument. This action emits an event, logging both the old and new oracle addresses. All other operations, such as retrieving the number of decimals, fetching the latest exchange rate, or peeking at the spot rate, simply delegate the call to the currently set oracle implementation. The contract itself provides a static name "Proxy Oracle" and symbol "Proxy". There are no fees, upgradeability mechanisms beyond the oracle implementation swap, or integrations with other protocols directly implemented within this contract.
