This contract acts as a specialized vault for ERC20 tokens, integrating with the Blast ecosystem for yield generation. It stores a reference to a Blast token registry and a designated address for receiving fees. Callers can deposit supported ERC20 tokens into the vault, but only if the specific token has been explicitly enabled by the contract owner. The owner has exclusive control over enabling or disabling tokens for deposit, setting the fee recipient address, and directly interacting with Blast precompiles. Designated operators can claim accumulated gas yields and native token yields from Blast, directing them to the fee recipient. The contract emits events when a token's deposit status changes or when the fee recipient is updated, allowing off-chain monitoring. It ensures that only registered native yield tokens can have their yields claimed.
