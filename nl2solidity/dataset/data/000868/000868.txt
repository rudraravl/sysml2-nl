This contract serves as a factory for creating new SavETHVault instances. It maintains a single, unchangeable reference to a base SavETHVault implementation, established upon its deployment. Any caller can request the creation of a new SavETHVault. When a new vault is deployed, the factory uses a minimal proxy pattern to efficiently create a new instance, then immediately initializes it with a specified liquid staking manager and an LP token factory. The address of the newly deployed and initialized vault is returned to the caller, and an event is emitted to signal its creation, allowing off-chain systems to track new vault deployments. There are no fees or complex access controls; anyone can deploy a new vault.
