This contract provides a standardized way to manage royalty information for NFTs, adhering to the ERC2981 standard. It maintains a default royalty receiver and a royalty fraction, and can also store specific royalty information for individual token IDs, overriding the default. Callers can query the royalty information for any token ID and a given sale price, which returns the designated receiver address and the calculated royalty amount. The contract allows setting and resetting both the default royalty and per-token royalties, specifying a receiver address and a fee numerator. Important constraints include ensuring the royalty receiver is never the zero address and that the fee numerator does not exceed the fee denominator, which defaults to 10000 (representing basis points). The contract also supports the ERC165 interface for introspection.
