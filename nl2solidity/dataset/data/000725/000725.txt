This contract provides a set of mathematical functions designed for precise multiplication and division of unsigned 256-bit integers, specifically handling cases where intermediate products might exceed 256 bits but the final result fits within that range. It maintains no state on-chain. Callers can use two main operations: `mulDiv`, which calculates the floor of (a * b / denominator), and `mulDivRoundingUp`, which calculates the ceiling of the same expression. Both functions ensure full precision by internally using 512-bit arithmetic for intermediate calculations. Access to these functions is unrestricted. The contract does not emit any events, nor does it involve fees, upgradeability, or integrations with other protocols. It includes security guards to prevent division by zero and to ensure the final result does not overflow a 256-bit unsigned integer.
