This contract acts as an upgradeable proxy, allowing for the logic of a deployed contract to be changed over time without altering its address. It maintains an immutable administrator address, set at deployment, which is the sole entity authorized to perform administrative tasks. The contract stores the address of the current implementation contract it delegates calls to. Callers can query the current administrator and the active implementation address. The administrator can initiate an upgrade to a new implementation contract, optionally executing a function on the new implementation immediately after the upgrade to initialize it. Any other function calls made to the proxy are forwarded to the current implementation contract, unless the caller is the administrator, in which case the call will revert. This design ensures that only the designated administrator can manage the proxy's upgrade lifecycle.
