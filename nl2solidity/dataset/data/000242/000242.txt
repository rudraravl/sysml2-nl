This contract provides a utility for retrieving and verifying historical Ethereum block hashes, extending beyond the standard 256-block limit. It maintains no internal state but interacts with a predefined history storage address to fetch block hashes. Callers can query the hash of any past block number, receiving zero if the block is in the future or outside the supported history. Additionally, the contract allows verification of a block's integrity by comparing a provided RLP-encoded block header against its stored hash, reverting if there's a mismatch or invalid encoding. It also offers a function to extract key header fields like parent hash, state root, and transaction roots from an RLP-encoded header for efficient processing. This contract is designed to be a stateless library, providing essential block data access and verification for applications requiring deep historical chain data.
