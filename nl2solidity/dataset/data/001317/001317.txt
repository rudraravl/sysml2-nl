This contract implements a transparent upgradeable proxy, allowing its logic to be changed over time without altering the contract's address. It stores the address of the current implementation contract and an administrator address. Calls made to the proxy are delegated to the stored implementation contract, except when the caller is the designated administrator. The administrator can upgrade the implementation to a new contract, optionally executing an initialization function on the new implementation, or change the administrator address itself. An `Upgraded` event is emitted when the implementation changes, and an `AdminChanged` event is emitted when the administrator changes. This design prevents function selector clashes between the proxy's administrative functions and the implementation's functions, ensuring that only the administrator can perform administrative actions.
