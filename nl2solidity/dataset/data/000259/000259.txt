This contract provides a robust JSON parsing utility, enabling on-chain smart contracts to interpret and interact with JSON data. It does not maintain any persistent state itself, acting purely as a library of functions. Callers can parse a JSON string into a structured `Item` representing the root of the JSON tree. From this `Item`, they can query its type (array, object, number, string, boolean, or null), retrieve its raw string value, or navigate its structure. For arrays, items can be accessed by numerical index; for objects, by a double-quoted, JSON-encoded string key. The contract also offers utility functions to parse unsigned integers, signed integers, and unsigned integers from hexadecimal strings, as well as to decode JSON-encoded strings. All operations are pure, meaning they do not modify the blockchain state, and any invalid JSON input or parsing error will cause the transaction to revert.
