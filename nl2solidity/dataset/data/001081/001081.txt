This contract implements a utility library for managing a price rate cache, designed to store and retrieve price rate information efficiently within a single 32-byte word. It maintains a current price rate, an old price rate, a duration, and an expiration timestamp. Callers can fetch the current rate, the old rate, the duration, or both the duration and expiration time. It provides functions to update the current rate, copy the current rate to the old rate, and set a new duration, which automatically recalculates the expiration time based on the current block timestamp. Additionally, there's a comprehensive decoding function to retrieve all stored values. The contract ensures that price rates do not exceed a maximum value, reverting if an overflow would occur. This library is purely functional, operating on passed-in `bytes32` values and returning modified ones, without maintaining any internal state on-chain.
