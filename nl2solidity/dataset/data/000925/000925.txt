This contract provides utility functions for verifying Merkle Tree proofs on-chain. It does not maintain any state itself, acting purely as a stateless library. Callers can use its `verify` function to check if a single `leaf` hash is included in a Merkle tree, given the tree's `root` hash and a `proof` array containing sibling hashes. There are also `multiProofVerify` functions to check if multiple `leaves` are part of a tree, requiring additional `proofFlags` to guide the reconstruction. All verification functions are pure, meaning they do not modify blockchain state, and they perform no access control as they are public utilities. The contract internally reconstructs the Merkle root from the provided leaf(s) and proof, then compares it to the given root. It includes calldata-optimized versions of its main functions for efficiency. There are no fees, events, or upgradeability mechanisms, as it's a foundational cryptographic utility.
