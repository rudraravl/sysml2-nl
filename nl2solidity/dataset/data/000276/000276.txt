This contract implements a min-heap data structure, which is a specialized tree-based data structure that satisfies the heap property: for any given node, the value of that node is less than or equal to the value of its children. It can operate on data stored either in the contract's persistent storage or in temporary memory during a transaction. The contract maintains the heap's elements as an ordered list of `uint256` values. Callers can add new values to the heap, retrieve and remove the smallest value, or replace the smallest value with a new one. There's also a function to add a value and conditionally remove the smallest if the heap exceeds a specified maximum length, useful for bounded priority queues. Additionally, callers can query the current number of items in the heap or retrieve the `k` smallest items without altering the heap. All operations are public and do not have any access control. If an operation attempts to retrieve a value from an empty heap, it will revert.
