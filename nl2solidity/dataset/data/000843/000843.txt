This contract provides a utility library for managing time-based and block-number-based deadlines. It defines two data structures, `Timestamp` and `BlockNumber`, each storing a single 64-bit unsigned integer representing a deadline. For both types, callers can set a deadline, retrieve the current deadline, or reset it to zero. The contract also offers functions to check the state of a timer: whether it is unset (deadline is zero), started (deadline is non-zero), pending (deadline is in the future), or expired (deadline has passed). There are no access controls, events, or fees associated with these operations; the contract simply provides pure and view functions to interact with the deadline values stored in the provided timer structs. This library is intended to be integrated into other contracts to manage their internal timing logic.
