This contract provides a utility library for verifying cryptographic signatures on the blockchain. Its primary purpose is to determine if a given signature is valid for a specific signer address and a hashed message. It supports two main types of signatures: those from externally owned accounts (EOAs) using ECDSA, and those from smart contract wallets that implement the ERC-1271 standard. The contract maintains no persistent state; all operations are pure functions that perform calculations based on their input parameters. Callers can invoke several `isValidSignatureNow` functions, which differ in how the signature data is provided (as a single `bytes` array, `bytes calldata`, or as separate `r`, `s`, `v` components). There are also dedicated `isValidERC1271SignatureNow` functions for explicitly checking ERC-1271 signatures without an EOA fallback. Additionally, the contract includes helper functions to format a hash into an Ethereum Signed Message hash, as per EIP-191. There are no access control mechanisms, fees, or upgradeability features, as it is a stateless library.
