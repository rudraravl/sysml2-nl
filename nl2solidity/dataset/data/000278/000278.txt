This contract provides utility functions for verifying P256 elliptic curve digital signatures on-chain. It does not maintain any persistent state itself but interacts with pre-deployed verifier contracts or precompiles. Callers can verify a signature against a message hash and a public key, with an option to include a malleability check. The contract also offers functions to determine if the necessary P256 precompile or a custom verifier contract exists on the current blockchain, which is useful for ensuring secp256r1 signature recovery is supported. Additionally, it includes helpers for normalizing signature values and decoding public key points from byte arrays. There are no access control mechanisms, fees, or events; all operations are pure or view functions, designed for integration into other contracts requiring P256 signature validation.
