This contract extends a standard access control mechanism to support cross-chain interactions. It maintains a set of roles, each identified by a unique hash, and tracks which addresses possess which roles. The core purpose is to differentiate between calls originating from the same blockchain versus those originating from a different, connected blockchain. When a function protected by a specific role is called, the contract checks if the caller is on the same chain. If so, it verifies the caller holds the standard role. If the call originates from another chain, it instead checks if the caller holds a specially derived "aliased" version of that role, and also verifies the sender address as identified by the cross-chain messaging system. This ensures that permissions are managed distinctly for local and cross-chain operations, preventing unauthorized access from identical addresses on different chains.
