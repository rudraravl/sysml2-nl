This contract serves as a reentrancy guard, preventing malicious reentrant calls to functions it protects. It maintains a single internal state variable, a storage slot, which acts as a lock. When a function marked with the `nonReentrant` modifier is called, the contract sets this lock. If another call attempts to enter a protected function before the initial call completes and releases the lock, the contract will revert with a `Reentrancy()` error. The lock is reset upon the completion of the initial function call. A `nonReadReentrant` modifier is also provided for view functions, which only checks the lock without modifying it, preventing read-only reentrancy attacks. There are no external functions, events, or access controls; its purpose is solely to be inherited by other contracts for security.
