This contract serves as a proxy for an ERC721 non-fungible token collection, enabling upgradeability for its underlying logic. When deployed, it immediately initializes an implementation contract, setting its name to "Infinite Shades OF Eternity" and its symbol to "ISOE". All subsequent calls to this proxy contract are transparently delegated to the fixed implementation address, meaning the proxy itself does not maintain any state beyond the address of its implementation. Callers can query the current implementation address. This architecture allows the core ERC721 functionalities, such as minting, transferring, and managing NFTs, to reside in a separate, upgradeable contract, while the proxy's address remains constant. There are no specific access controls or events defined within the proxy itself, as these would be handled by the delegated implementation contract.
