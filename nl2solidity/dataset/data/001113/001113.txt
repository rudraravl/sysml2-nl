This contract is a cross-chain gauge designed to facilitate the transfer of a specific Balancer token to a recipient address on a different blockchain, using Chainlink's CCIP. It maintains state regarding its immutable Chainlink router and LINK token addresses, the destination chain ID, and an optional set of extra arguments for the CCIP message. It also tracks the recipient address on the child chain. Callers can initialize the gauge, setting its relative weight cap, a checkpointer, the child chain recipient, and the destination chain. The owner can update the extra arguments for CCIP messages, emitting an event when this occurs. The contract allows anyone to calculate the fee for a cross-chain transfer and to build the CCIP message structure. When a minting action occurs, the contract attempts to send the minted tokens to the child chain recipient, prioritizing payment of CCIP fees in native currency if available, otherwise using LINK. Any leftover native currency or LINK after a transfer attempt is returned to the caller. A `CCIPTransferMessage` event is emitted upon each transfer attempt, indicating the message ID.
