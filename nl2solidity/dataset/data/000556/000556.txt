This contract provides a set of utility functions for calculating a user's financial health within a lending protocol. It does not maintain any state itself, but rather operates on data provided by other contracts, such as reserve configurations, user-specific settings, and price oracle information. The core functionality is to compute a user's total collateral and debt in a common base currency, their average Loan-To-Value (LTV), average liquidation threshold, and health factor. It also calculates the maximum additional amount a user can borrow based on their current collateral and debt. These calculations consider "Efficiency Mode" (EMode) categories, which can modify LTV and liquidation thresholds for specific asset groups. The contract interacts with external ERC20 tokens and scaled balance tokens to determine user balances and debts, and with a price oracle to get asset prices. It does not have any access control or emit events, as it is purely a computational library.
