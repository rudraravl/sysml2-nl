This contract provides utility functions for working with CAIP-2 identifiers, which are standardized strings representing blockchain networks. It does not maintain any on-chain state. Callers can retrieve the CAIP-2 identifier for the current blockchain network, formatted as "eip155:chain_id". Additionally, it allows callers to combine a namespace and a reference into a CAIP-2 string, or to parse an existing CAIP-2 string into its constituent namespace and reference components. There are no access controls, fees, or events; all operations are pure utility functions. The contract relies on external libraries for string and byte manipulation.
