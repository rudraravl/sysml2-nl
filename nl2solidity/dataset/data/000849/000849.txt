This contract provides a double-ended queue data structure, designed to store and manage a sequence of `bytes32` values efficiently. It maintains the queue's internal state using two 128-bit signed integer pointers, `_begin` and `_end`, which track the boundaries of the stored items, and a mapping `_data` to hold the actual `bytes32` values indexed by these pointers. Callers can add items to either the front or the back of the queue using `pushFront` and `pushBack`, respectively. Items can be removed from either end using `popFront` and `popBack`, which also return the removed value. The contract also allows callers to inspect the items at the front or back without removing them via `front` and `back`, or access any item by its index using `at`. It provides functions to check if the queue is `empty` and to retrieve its `length`. A `clear` function resets the queue to an empty state, though it does not delete the underlying data. Operations will revert with `Empty` if attempting to access an item from an empty queue, or `OutOfBounds` if an invalid index is provided. There are no access control mechanisms or events, as this contract is a utility library meant to be integrated into other contracts.
