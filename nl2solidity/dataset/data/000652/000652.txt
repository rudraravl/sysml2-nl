This contract defines a collection of data structures, acting as a blueprint for organizing information within a larger lending protocol. It does not maintain any state itself, nor does it implement any functions or operations. Instead, it provides standardized formats for representing various protocol components like reserve data, user configurations, and parameters for different actions such as liquidations, supplies, borrows, and repayments. These structures include details about asset configurations (like collateral value, liquidation thresholds, and borrowing limits), interest rates, timestamps, and addresses of associated tokens. It also defines structures for tracking user-specific data, such as which assets they are using as collateral or have borrowed. The contract also includes several deprecated fields within its structures, indicating past versions or features that have been superseded.
