This contract provides a set of internal utilities for managing the state and interest rates of a lending pool reserve. It tracks the reserve's liquidity index, variable borrow index, and the last time these were updated, along with the current liquidity and variable borrow rates, and the addresses of associated aToken and variable debt token contracts. Callers can initialize a reserve by providing the aToken and variable debt token addresses, which sets initial index values. The contract allows for updating the reserve's state, which involves recalculating and storing new liquidity and variable borrow indexes, and accruing a portion of the interest to a treasury based on a reserve factor. It also enables updating the interest rates and a virtual balance based on liquidity added or taken, and emits an event when reserve data is updated. A caching mechanism is used to optimize state updates by reducing redundant storage reads.
