This contract provides utility functions for converting data between raw bytes and Base64 string representations. It does not maintain any persistent state on-chain. Callers can encode a byte array into a standard Base64 string or a Base64Url-safe string, which omits padding characters. Conversely, callers can decode a Base64 string (either standard or URL-safe, with or without padding) back into its original byte array. There are no access control mechanisms; all functions are publicly available for use. If an invalid character is encountered during decoding, the operation will revert with an `InvalidBase64Char` error, indicating the problematic character. The contract primarily focuses on efficient in-memory string manipulation for these conversions.
