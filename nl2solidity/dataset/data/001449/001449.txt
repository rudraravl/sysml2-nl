This contract serves as a central registry for critical system addresses, enabling controlled updates and providing a single point of truth for other components. It maintains state for a `governor` address, a `proposedGovernor` address, a `providersAggregator` contract, and a `stableCoinProvider` contract. The contract is initialized once with an initial governor. Only the current `governor` can propose a new governor, which then must explicitly accept governorship. The `governor` also has exclusive rights to update the `providersAggregator` and `stableCoinProvider` addresses. All updates to the governor and provider addresses emit corresponding events, allowing off-chain systems to track these changes. This contract is designed to be upgradeable, allowing for future enhancements without redeployment.
