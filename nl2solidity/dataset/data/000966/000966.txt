This contract serves as a custom oracle for the Pendle token, providing its price against WETH using a specific Uniswap V3 pool. It maintains immutable state variables including the Uniswap V3 factory address, the target Pendle token, the Uniswap V3 pool address, the two tokens within that pool (one of which must be Pendle and the other WETH), and a global amount representing one unit of the Pendle token for price calculations. Upon deployment, it validates that the provided pool matches the one derived from the factory and that the correct tokens are present. Callers can query the `latestAnswer` function to get the current price of the Pendle token in terms of WETH, based on the current tick of the specified Uniswap V3 pool. It also exposes `decimals`, `latestRoundData`, and `getRoundData` functions, which return the configured precision and price information, respectively, aligning with common oracle interfaces. There are no fees, upgradeability, or explicit access controls beyond the initial constructor validations.
