This contract provides a stateless utility for verifying digital signatures using the P256 (secp256r1) elliptic curve cryptography standard, specifically for ERC-7913 compliant signatures. It does not maintain any on-chain state. The primary operation is a `verify` function that takes a public key, a message hash, and a signature as input. It checks if the provided signature is valid for the given hash and public key. If the key and signature lengths are appropriate for a P256 signature and the verification succeeds, the function returns the selector of the `verify` function itself; otherwise, it returns a specific error code (0xFFFFFFFF). This contract is designed to be called by other contracts or off-chain services that need to validate P256 signatures without storing any data.
