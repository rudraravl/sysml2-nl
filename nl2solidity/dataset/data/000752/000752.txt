This contract facilitates interactions with a decentralized exchange for managing liquidity. It maintains references to several external ERC20 tokens, including WETH, USDC, and a specific GM token, along with interfaces to an exchange router, a data store, and a reader. An Oracle contract is also referenced to fetch price data, initialized at deployment. Callers can query the USD price of a market token. The contract allows users to create a deposit order by transferring USDC to the contract, which then forwards it along with an execution fee to a deposit vault. Similarly, users can create a withdrawal order by transferring GM tokens and an execution fee to a withdrawal vault. Both deposit and withdrawal operations return a unique key identifier. The contract does not store user funds directly but acts as an intermediary for interacting with the underlying exchange protocol.
