This contract provides a set of secure mathematical operations for unsigned and signed 256-bit integers. Its purpose is to prevent common arithmetic errors like overflow and underflow, which can lead to critical vulnerabilities in smart contracts. It maintains no state itself, acting purely as a utility library. Callers can perform addition, subtraction, and multiplication on `uint256` values, and addition and subtraction on `int256` values. Each operation is designed to revert the transaction if the result exceeds the maximum or falls below the minimum representable value for its respective integer type. There are no access controls, events, fees, or upgradeability mechanisms, as it serves as a foundational component for other contracts requiring robust arithmetic.
