This contract serves as a utility for encoding various Aave protocol operation parameters into a compact `bytes32` format, primarily to reduce transaction costs on Layer 2 networks. It maintains a single immutable state variable: the address of the Aave `Pool` contract it interacts with to retrieve asset-specific data. Callers can invoke functions to encode parameters for common actions such as supplying assets, supplying assets with a permit, withdrawing, borrowing, repaying, repaying with a permit, repaying with aTokens, swapping borrow rate modes, rebalancing stable borrow rates, setting collateral usage, and executing liquidation calls. Each encoding function takes standard input parameters and returns one or more `bytes32` values representing a compressed form of those parameters. There are no access control mechanisms, fees, or events emitted by this contract; its sole purpose is to provide these encoding services as a view-only utility, relying on the `Pool` contract for actual state changes.
