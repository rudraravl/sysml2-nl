This contract implements a token that represents a user's share of a pool, where the balance scales over time based on an index. It maintains each user's scaled balance and their last recorded index. Callers can query their scaled balance, the total scaled supply, and their previous index. The contract allows for the minting, burning, and transferring of these scaled tokens. When tokens are minted, the actual amount received by the user is adjusted by the current index, and a `Mint` event is emitted along with a standard `Transfer` event. Burning tokens similarly adjusts the amount based on the index, potentially resulting in a `Mint` event if accrued interest exceeds the burn amount, or a `Burn` event otherwise, alongside a `Transfer` event. Transfers between users also account for accrued interest, emitting `Mint` events for both sender and recipient if applicable, in addition to the standard `Transfer` event. The contract integrates with a Pool contract and uses specific math libraries for calculations.
