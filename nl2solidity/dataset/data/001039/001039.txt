This contract implements a smart wallet that can hold and manage assets, compatible with the ERC-4337 standard for account abstraction. It maintains a list of owners, which can be Ethereum addresses or WebAuthn public keys, and tracks a nonce for replay protection. Callers can initialize the wallet with an initial set of owners. The primary operations involve executing single or batched transactions, either directly by an owner or through an EntryPoint contract as part of an ERC-4337 UserOperation. A special `executeWithoutChainIdValidation` function allows certain whitelisted operations, like adding/removing owners or upgrading the contract, to be replayed across different chains by signing a UserOperation hash that excludes the chain ID. Access to execute transactions is restricted to either the EntryPoint or any of the designated owners. The contract supports signature validation for both standard ECDSA and WebAuthn signatures. It also includes an upgrade mechanism, allowing owners to update the contract's logic. Any attempt to re-initialize an already initialized wallet or to perform an unauthorized action will revert the transaction.
