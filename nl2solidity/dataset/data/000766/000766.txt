This contract serves as a designated receiver for funding fees within a decentralized exchange ecosystem. It maintains no internal state of its own, instead relying entirely on an external data store to track claimable funding amounts. Callers can query the amount of a specific token claimable for a given market by this contract. The primary operation allows anyone to trigger the claiming of funding fees for a predefined set of markets and tokens (currently WETH and USDC for the GM_TOKEN_ETH_WETH_USDC market). When this function is called, the contract interacts with an external exchange router to initiate the claim, directing the collected fees to itself. There are no access control mechanisms; any external caller can execute the claim function. No events are emitted, and there are no fees, upgradeability, or security guards implemented within this contract.
