This contract provides helper functions for a Fluid vault protocol, primarily used by `operate()` and `liquidate()` methods of a `CoreModule`. It maintains state related to exchange rates, tick data, and branch information for managing user positions and liquidations. Callers can calculate new vault exchange prices without updating storage, or trigger an update to these prices on storage, which emits an event. The contract also allows fetching a user's latest position after liquidation, including their final tick, debt, collateral, and associated branch. It internally manages a mapping of ticks that have outstanding debt and can determine the next highest tick with debt. Additionally, it can add debt to a specific tick, handling cases where a tick is new or has undergone liquidation, and can set a new top tick for the vault, adjusting branch information as needed. Access control is not explicitly defined within these helper functions, implying that permissions are managed by the calling `CoreModule`.
