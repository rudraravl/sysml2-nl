This contract acts as an upgradeable proxy, allowing its underlying implementation logic to be changed while maintaining the same contract address and state. It stores the address of the current implementation and an administrator's address. The administrator has exclusive control over critical functions: they can retrieve the current administrator's address, query the current implementation's address, transfer administrative privileges to a new address (emitting an `AdminChanged` event), upgrade the contract to a new implementation, or upgrade and then immediately call a function on the new implementation. Any calls made by non-administrators are delegated to the current implementation contract, effectively executing its logic. The contract prevents the administrator from directly calling functions intended for the delegated implementation.
