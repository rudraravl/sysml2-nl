This contract provides utility functions for other contracts operating on Arbitrum Layer 2 to interact with cross-chain messages originating from Layer 1. It does not maintain any state itself. The primary operations it offers are determining if a current function call is a cross-chain message and, if so, identifying the original sender of that message from Layer 1. Access to these functions is internal, meaning only other contracts can utilize them. There are no events emitted. A notable mechanic is the reliance on the `ARBSYS` precompile contract on Arbitrum to perform these checks, and it will revert if `crossChainSender` is called on a non-cross-chain message.
