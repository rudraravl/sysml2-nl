This contract provides utility functions for deriving the unique address of a Uniswap V3 liquidity pool. It does not maintain any on-chain state itself. Its primary operation is to deterministically compute a pool's address given the Uniswap V3 factory address, the two token addresses forming the pair, and the pool's fee tier. A helper function ensures that the token addresses are always ordered consistently (token0 < token1) to form a canonical `PoolKey` structure, which is then used in the address computation. The contract uses a fixed `POOL_INIT_CODE_HASH` constant, representing the bytecode hash of a standard Uniswap V3 pool, as part of the address derivation, ensuring that the computed address corresponds to a valid, deployable pool. There are no access controls, events, or upgradeability mechanisms, as it serves purely as a stateless library for address calculation.
