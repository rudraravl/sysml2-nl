This contract implements a linear bonding curve for asset liquidation, where the price of an item continuously declines over a defined period. It maintains no internal state, instead relying on input parameters for all calculations. Callers can query information about buying items using `getBuyInfo`, which calculates the required input value, trade fees, and protocol fees based on a given spot price, a delta representing the curve's start and end timestamps, and the number of items. This function also validates that the current time falls within the curve's active period. The contract explicitly disallows selling items through the `getSellInfo` function. Utility functions, `packDelta` and `unpackDelta`, are provided to encode and decode the start and end timestamps into a single delta value. There are no access control mechanisms or events emitted, and the contract does not support upgrades.
