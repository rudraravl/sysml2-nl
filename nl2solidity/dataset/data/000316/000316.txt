This contract provides a utility library for managing storage slots, enabling dynamic allocation and invalidation of storage references. It defines two primary structures: `Bump`, which represents a storage slot that can be invalidated, and `Ref`, a pointer to a `uint256` value in storage. The contract does not maintain any state itself; rather, it offers functions to interact with storage slots provided by other contracts. Callers can retrieve the current storage slot associated with a `Bump` instance, effectively generating a unique slot based on its internal counter and a predefined seed. They can also "invalidate" a `Bump`, which increments its internal counter, causing subsequent calls to `slot()` to return a new, distinct storage slot. Additionally, the contract provides functions to create `Bump` and `Ref` instances from a given storage slot, allowing other contracts to easily manage and access specific storage locations. There are no access controls, fees, or events, as this is purely a low-level storage utility.
