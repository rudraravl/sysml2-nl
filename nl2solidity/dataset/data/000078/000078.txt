This contract defines a standard ERC20 token with an enforced maximum total supply, known as a cap. The contract stores this cap as an immutable value set only once during its creation. Callers can query this cap at any time. The core functionality of transferring tokens and managing balances is inherited from a standard ERC20 implementation. However, a critical modification prevents the total supply from ever exceeding the predefined cap. Specifically, when new tokens are minted (i.e., transferred from the zero address), the contract checks if the resulting total supply would surpass the cap. If it would, the minting operation is rejected with an error indicating the cap has been exceeded. This ensures that the token's supply can never grow beyond its initial limit.
