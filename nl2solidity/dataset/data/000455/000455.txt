This contract provides utility functions for hashing data related to ERC721 permit signatures. It defines two constant typehashes, one for individual token permits and another for "permit for all" approvals. The contract offers two pure functions: `hashPermit`, which takes a spender address, a token ID, a nonce, and a deadline to produce a digest for an individual token permit signature, and `hashPermitForAll`, which takes an operator address, an approval boolean, a nonce, and a deadline to generate a digest for an "approve all" permit signature. These functions are designed to be called internally by other contracts that implement ERC721 permit functionality, facilitating the creation of off-chain signed messages for token approvals without directly interacting with the blockchain. The contract does not maintain any state, nor does it have any access control or emit events; its sole purpose is to provide deterministic hashing for permit data.
