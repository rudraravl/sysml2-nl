This contract provides a set of utility functions for verifying Merkle tree proofs on-chain. It does not maintain any persistent state itself, but rather operates on input data provided by the caller. The primary operations are `verify` and `processProof`, which take a Merkle proof, a root hash, and a leaf hash, and return a boolean indicating whether the leaf is part of the tree or the reconstructed root hash, respectively. There are also `multiProofVerify` and `processMultiProof` functions for verifying multiple leaves simultaneously. These functions are available in both memory and calldata versions, and can optionally accept a custom hashing function. All functions are `internal pure` or `internal view`, meaning they do not modify state and are intended to be called by other contracts. Access control is not applicable as these are library functions. An error `MerkleProofInvalidMultiproof` is reverted if a multiproof is malformed.
