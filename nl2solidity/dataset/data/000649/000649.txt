This contract provides a set of mathematical functions for performing percentage calculations with a fixed precision of two decimal places, represented by a scaling factor of 10,000. It does not maintain any state on-chain, nor does it have any access control or emit events. Callers can use its pure functions to multiply a value by a percentage, with options for standard rounding, ceiling, or floor rounding. Similarly, it offers functions to divide a value by a percentage, also with standard rounding, ceiling, or floor rounding. These operations are designed to be gas-efficient through the use of assembly code and include checks to prevent overflow errors during calculations. The contract's sole purpose is to serve as a utility for other contracts requiring precise percentage arithmetic.
