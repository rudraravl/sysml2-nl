This contract provides a suite of pseudorandom number generation utilities. It does not maintain any persistent state itself, but offers functions to manipulate a `PRNG` struct for in-memory random number generation and a `LazyShuffler` struct for storage-based shuffling. Callers can seed an in-memory `PRNG` state and then generate various types of random numbers: a general `uint256`, a `uint256` uniformly distributed within a given upper bound, or samples from standard normal and exponential distributions. Additionally, it offers functions to perform Fisher-Yates shuffling on arrays of `uint256`, `int256`, `address`, or `bytes` in memory, either fully or partially. For storage-based shuffling, a `LazyShuffler` can be initialized with a specific length, grown to a larger length, or restarted to allow re-shuffling. Callers can query the number of shuffled elements, the total length, or check if the shuffler is finished or initialized. The core operation for the `LazyShuffler` is `next`, which performs a single shuffle step and returns the next element, requiring external randomness as input. There are no access control mechanisms, fees, or external integrations; all functions are pure or view, operating on provided data or storage references.
