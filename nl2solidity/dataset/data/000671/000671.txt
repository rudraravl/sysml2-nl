This contract serves as a base for managing token transfers, specifically designed to interact with an incentives controller and a rewards administrator. Upon deployment, it permanently records the addresses of an incentives controller and a rewards administrator. It maintains these two addresses as its primary state. Callers can query these addresses at any time. The contract allows only the designated rewards administrator to initiate an emergency withdrawal of any specified ERC20 token from the contract to a recipient address, emitting an event to log the withdrawal details. It also defines a virtual function for performing general transfers, which is expected to be implemented by inheriting contracts, and restricts certain functions to be callable only by the incentives controller.
