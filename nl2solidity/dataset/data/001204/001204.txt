This contract acts as a bridge for ERC721 and ERC1155 tokens, facilitating their transfer from a Layer 2 (L2) network to a Layer 1 (L1) network, and vice-versa. It maintains a mapping between L2 collection addresses and their corresponding L1 collection addresses. The contract allows for the one-time initialization of implementation addresses for both ERC721Bridgable and ERC1155Bridgable contracts, which are used to clone new L2 token collections deterministically. When tokens are bridged from L1 to L2, the contract receives a message from the L1 bridge, deploys new L2 token contracts if they don't exist, and then mints or transfers the tokens to the specified recipient on L2. Conversely, when tokens are bridged from L2 to L1, the contract receives the tokens from the L2 sender, stores them, and then sends a message to the L1 bridge to complete the transfer. Only the designated cross-domain messenger and the L1 bridge contract are authorized to initiate these cross-chain operations. Events are emitted for finalized bridges, started bridges, and royalty claims, providing transparency into the bridging process. The contract also supports claiming royalties for L1 collections on the L2 network, with the L1 bridge validating the royalty holder.
