This contract extends a core governance system to implement a simple voting mechanism for proposals. It tracks the votes for each proposal, specifically distinguishing between "Against," "For," and "Abstain" votes. For every proposal, the contract maintains the total "Against" votes, "For" votes, and "Abstain" votes, and records which addresses have already cast a vote for that specific proposal. Callers can query the total votes for a given proposal and check if a particular address has voted. The contract defines how a quorum is reached, requiring the sum of "For" and "Abstain" votes to meet a certain threshold, and how a vote succeeds, which occurs when "For" votes strictly exceed "Against" votes. When a vote is cast, the contract updates the relevant vote counts and marks the voter as having participated, preventing them from voting again on the same proposal.
