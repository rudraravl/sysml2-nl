This contract provides a utility library for verifying cryptographic signatures on-chain, supporting both externally owned accounts (EOAs) and smart contract wallets (like Argent and Gnosis Safe) that implement the ERC-1271 standard. It does not maintain any state itself but offers several pure and view functions to check signature validity. Callers can verify signatures provided in various formats (full bytes, `r`/`vs` components, or `v`/`r`/`s` components) against a given signer address and message hash. The contract intelligently determines whether to use `ecrecover` for EOAs or to call the `isValidSignature` method on a smart contract signer. Additionally, it includes functions to handle ERC-6492 signatures, which can trigger the deployment or preparation of a smart account if necessary, with both reentrancy-safe and non-reentrancy-safe variants. It also provides helper functions to compute the Ethereum Signed Message hash as per EIP-191. There are no access control mechanisms, fees, or events, as it's a stateless library.
