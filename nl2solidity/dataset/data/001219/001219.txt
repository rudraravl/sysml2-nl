This contract serves as a read-only utility to fetch comprehensive data about SuperPools and user deposits within a lending protocol. It is initialized with the addresses of the core Pool and RiskEngine contracts, which it uses to retrieve information. The contract does not maintain any mutable state itself, acting purely as a data aggregator. Callers can query for the current state of a specific SuperPool, including its underlying asset, total assets, idle assets, value in ETH, and a weighted interest rate, along with details of its deposits into individual sub-pools. Additionally, users can retrieve their deposit data for a single SuperPool or across multiple SuperPools, which includes the amount, value in ETH, and associated interest rate. All calculations involving value in ETH rely on an oracle provided by the RiskEngine, and interest rate calculations for SuperPools are weighted averages of their underlying pool interest rates. There are no access control restrictions, fees, or events emitted, as its sole purpose is to provide view-only data.
