This contract provides a double-ended queue data structure on-chain, allowing callers to manage an ordered collection of 32-byte values. It maintains the queue's internal state, including its beginning and end pointers and its current length. Callers can add new 32-byte values to either the front or the back of the queue using `pushFront` and `pushBack`, respectively. They can also remove values from either end using `popFront` and `popBack`, which return the removed value. The entire queue can be emptied with the `clear` function. Additionally, the contract offers read-only functions to inspect the queue's internal `begin` and `end` pointers, its current `length`, whether it is `empty`, and to retrieve the `front` or `back` element without removing it. Callers can also access any element by its `index` using `at_`. There are no access control restrictions, fees, or events emitted by this contract; all operations are public.
