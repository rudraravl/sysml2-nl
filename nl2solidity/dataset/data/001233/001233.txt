This contract provides a utility for deriving a "Market ID" from a given "Question ID." It doesn't maintain any state on-chain, nor does it have any access control or events. Its sole purpose is to perform a specific bitwise operation: it takes a 32-byte Question ID and returns a 32-byte Market ID by effectively zeroing out the last byte of the Question ID. This implies that multiple Question IDs sharing the same first 31 bytes will map to the same Market ID. There are no fees, upgradeability mechanisms, or integrations with other protocols.
