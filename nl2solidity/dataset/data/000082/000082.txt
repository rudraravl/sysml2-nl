This contract extends a standard ERC-20 token to allow for "permit" functionality, enabling users to approve token transfers via an off-chain signed message rather than an on-chain transaction. It maintains a record of nonces for each token holder, which are consumed with every successful permit operation to prevent replay attacks. Callers can invoke the `permit` function, providing a signed message from a token owner that specifies a spender, an amount, and a deadline. If the signature is valid, the deadline has not passed, and the signer matches the owner, the contract updates the allowance for the specified spender. It also exposes functions to retrieve the current nonce for any address and the EIP-712 domain separator used for signature generation. This mechanism allows token holders to grant allowances without needing to pay for gas themselves.
