This contract serves as a specialized interest rate strategy within a lending protocol, designed to always report zero interest rates. It maintains a reference to an `IPoolAddressesProvider` contract, set immutably at deployment, which is its only piece of state. Callers can query various rate components like `getVariableRateSlope1`, `getStableRateSlope1`, and `getBaseVariableBorrowRate`, all of which consistently return zero. The core function, `calculateInterestRates`, also returns zero for all liquidity, stable borrow, and variable borrow rates, regardless of input parameters. This contract has no access control or events, and its purpose is to provide a default, zero-interest rate mechanism for specific reserves within the larger lending system.
