This contract serves as a foundational library for on-chain assertion and logging, primarily intended for testing and debugging environments rather than production use. It maintains a single internal state variable, `_failed`, which tracks whether an assertion has failed within the current execution context. Callers can query this `failed()` status to determine if any assertion has previously failed. The contract offers a comprehensive suite of assertion functions, such as `assertTrue`, `assertFalse`, `assertEq`, `assertNotEq`, `assertLt`, `assertGt`, `assertLe`, `assertGe`, `assertApproxEqAbs`, and `assertApproxEqRel`, covering various data types including booleans, integers, addresses, bytes32, strings, bytes, and arrays of these types. These functions compare values and, if an assertion fails, they internally mark the `_failed` state and may emit detailed log events, including named values, to provide diagnostic information. A special `fail()` function allows explicitly setting the failure state. Additionally, it provides `assertEqCall` to compare the success status and return/revert data of two contract calls. The contract emits numerous `log` and `log_named` events for different data types, enabling off-chain tools to capture and display execution details and assertion results. This contract does not handle any financial operations, access control beyond its internal logic, or integrations with other protocols, focusing solely on providing robust assertion capabilities for development and testing.
