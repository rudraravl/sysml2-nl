This contract implements an upgradeable proxy that allows for future modifications to its underlying logic without changing the contract's address. It maintains a single administrative address, which is set upon deployment and stored in a specific storage slot. The contract exposes functions for the administrator to query the current implementation address, change the administrative address, and upgrade the underlying implementation. The administrator can also upgrade the implementation and immediately call a function on the new logic contract, enabling initialization. Any caller who is not the administrator will have their calls forwarded to the current implementation contract. An `AdminChanged` event is emitted whenever the administrator address is successfully updated. This design ensures that only the designated administrator can manage the contract's upgradeability and administrative settings.
