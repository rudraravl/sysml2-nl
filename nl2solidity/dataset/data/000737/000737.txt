This contract provides a time-weighted average price oracle for a Uniswap V2 pair. Upon deployment, it identifies the two tokens in the pair and stores their initial cumulative prices and the current block timestamp. It maintains the last recorded cumulative prices for both tokens, the last block timestamp an update occurred, and the calculated average prices for each token. Any caller can invoke the `update` function, which recomputes the average prices for both tokens over a fixed 24-hour period, provided at least that much time has passed since the last update. These average prices are then stored. Callers can also use the `consult` function to get an estimated output amount for a given input token and amount, based on the currently stored average prices. There are no fees or special access controls beyond the requirement that a full period must elapse before an update can occur.
