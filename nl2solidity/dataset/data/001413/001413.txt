This contract serves as a proxy for an ERC721 non-fungible token collection, enabling upgradeability for the underlying NFT logic. Upon deployment, it immediately initializes itself by setting a fixed implementation address and then calling an `initialize` function on that implementation, passing in a specified name and symbol for the NFT collection. All subsequent calls to this contract are automatically delegated to the designated implementation contract, meaning the proxy itself does not store any state beyond the address of its current implementation. The contract exposes a view function to retrieve the address of the current implementation. This design allows the core logic of the NFT collection to be updated by changing the implementation address, without requiring users to interact with a new contract address.
