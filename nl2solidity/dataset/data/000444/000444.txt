This contract defines a custom data type, `PermissionFlag`, to represent a set of binary permissions using a 2-byte value. It provides utility functions for combining permissions using a bitwise OR operation, checking for common permissions with a bitwise AND, and comparing two permission flags for equality. It also defines a library, `PermissionFlags`, which pre-defines several common permission sets: `NONE` (no permissions), `SWAP_ALLOWED` (a specific permission for swapping), `LIQUIDITY_ALLOWED` (a specific permission for managing liquidity), and `ALL_ALLOWED` (all possible permissions). This contract does not maintain any state, nor does it have any callable functions or events; its sole purpose is to define and manage these permission flags for use by other contracts.
