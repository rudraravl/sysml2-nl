This contract is a utility library designed to generate comprehensive metadata for Uniswap V3 liquidity provider (LP) NFTs. It does not maintain any on-chain state itself, but rather processes input parameters representing a specific Uniswap V3 position. The primary operation is `constructTokenURI`, which takes detailed information about an LP position, including token addresses, symbols, decimals, fee tier, tick range, and current tick, to produce a data URI. This URI encapsulates the NFT's name, a multi-part description, and an SVG image. The name includes the pool's fee tier, token symbols, and the price range. The description provides details like the pool address, token addresses, fee tier, and a disclaimer. The SVG image is dynamically generated to visually represent the LP position, incorporating unique colors and coordinates derived from the token addresses and NFT ID. The contract uses various internal helper functions for formatting numbers, handling decimal precision, escaping quotes in strings, and converting addresses to strings, ensuring the generated metadata is accurate and well-structured for off-chain display.
