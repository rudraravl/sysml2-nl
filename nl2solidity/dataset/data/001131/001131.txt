This contract provides a set of utility functions for safely interacting with ERC-20 tokens and transferring native ETH. It does not maintain any state itself, but rather offers operations that other contracts can use. Callers can initiate transfers of native ETH to any address, or transfer ERC-20 tokens from a specified address to another, or from the contract's own balance to another address. Additionally, it provides a function to safely query the balance of an ERC-20 token for a given address, returning zero if the query fails or returns invalid data. All transfer functions include robust error handling, reverting with a specific error if a transfer fails, providing details about the token, sender, recipient, attempted amount, and the actual balance at the time of failure. There are no access control mechanisms as these are general-purpose utilities. No events are emitted, and there are no fees or upgradeability features.
