This contract provides a utility for checking delegation statuses across two versions of a delegate registry. It does not maintain any internal state but interacts with external delegate registry contracts (V1 and V2) at predefined addresses. Callers can query whether a specific address (`to`) is a delegate for another address (`from`) for all rights, for a specific contract, or for a particular ERC721 or ERC1155 token ID. Some functions also allow specifying a `rights` parameter, which is a `bytes32` value representing specific delegated permissions. When checking for ERC20 or ERC1155 tokens, the contract returns the delegated amount, returning the maximum `uint256` value if a general contract-level delegation is found. The contract prioritizes checks against the V2 registry and falls back to V1 if V2 does not provide a positive result or if no specific rights are requested. There are no access control mechanisms or events emitted, as its sole purpose is to provide read-only delegation checks by statically calling external registries.
