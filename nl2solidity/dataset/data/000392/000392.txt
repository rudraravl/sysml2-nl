This contract provides a read-only interface for accessing transient storage slots. Its purpose is to allow other contracts to efficiently retrieve data that has been temporarily stored on-chain. It maintains no persistent state itself. Callers can perform two main operations: `exttload`, which retrieves the value of a single transient storage slot given its 32-byte key, and an overloaded `exttload` function that retrieves the values of multiple transient storage slots when provided with an array of 32-byte keys. There is no access control; any external caller can invoke these functions. No events are emitted, and there are no fees, upgradeability mechanisms, or integrations with other protocols. The core mechanic relies on direct access to the EVM's transient storage opcode (`tload`) for efficient data retrieval.
