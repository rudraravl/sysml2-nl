This contract provides a set of utility functions for Elliptic Curve Digital Signature Algorithm (ECDSA) operations, specifically designed to verify that a message was signed by the holder of a given address's private keys. It does not maintain any state on-chain. Callers can use various `recover` and `tryRecover` functions to determine the address that signed a hashed message, given the message hash and the signature. These functions handle different signature formats, including 65-byte standard signatures and 64-byte ERC-2098 short signatures, and can accept signature components (v, r, s) separately. The contract enforces strict validation rules to prevent signature malleability, ensuring the `s` value is in the lower half order and `v` is either 27 or 28. If a signature is invalid or malformed, the functions will revert with specific error messages indicating the reason, such as invalid length or an `s` value in the upper half order. There are no access control mechanisms, fees, or events, as its sole purpose is to provide pure, deterministic signature recovery logic.
