This contract provides utility functions for calculating interest, designed for financial applications. It does not maintain any state itself, but offers pure and view functions to compute linear and compounded interest based on provided rates and timestamps. The core operations include `calculateLinearInterest`, which determines interest accumulated linearly over a time period, and `calculateCompoundedInterest`, which computes interest using a binomial approximation to simulate compounding. A helper function `mulDivCeil` is also available for precise multiplication, division, and ceiling operations. There are no access control mechanisms as all functions are internal and intended for use by other contracts within the same system. No events are emitted. The contract explicitly ignores leap years in its calculations and uses a specific approximation for compounded interest to optimize gas costs, which might result in slight underpayments to liquidity providers and undercharges to borrowers. It relies on an external `WadRayMath` library for fixed-point arithmetic.
