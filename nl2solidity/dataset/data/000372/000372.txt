This contract provides a way to estimate the amount of tokens received or required for a swap on Uniswap V3, without actually executing the trade. It maintains a reference to the Uniswap V3 factory and the WETH9 contract. Callers can query for exact input swaps, specifying the input token, output token, fee tier, amount to swap, and an optional price limit. Similarly, callers can query for exact output swaps, providing the input token, output token, fee tier, desired output amount, and an optional price limit. There are also functions to handle multi-hop swaps by providing a path of pools. The contract temporarily stores a cached output amount for exact output single-hop swaps to ensure the full amount is received during the simulated swap. All interactions are read-only and do not alter any on-chain state; the contract simulates swaps by calling Uniswap V3 pool contracts and interpreting the revert reasons as the quoted amounts.
