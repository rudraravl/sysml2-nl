This contract establishes a robust role-based access control system for a vault. It maintains several distinct roles: Administrators, Curators, Guardians, and Allocators, each identified by a unique role identifier. Upon initialization, the contract can assign multiple addresses to each of these roles. The primary operations involve granting and revoking these specific roles to any address. Crucially, the contract defines modifiers that restrict function execution to callers possessing a particular role, or a combination of roles, including an "only owner" modifier for the default admin role. It also provides public view functions to check if an address holds a specific role. This system ensures that sensitive vault operations can be precisely controlled and delegated to authorized parties.
