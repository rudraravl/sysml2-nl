This contract serves as a data provider for liquidation-related information within a lending protocol. It maintains immutable references to the core lending pool and its addresses provider. Callers can query a user's overall financial position, including their total collateral, total debt, available borrowing power, current liquidation threshold, loan-to-value ratio, and health factor. Additionally, it provides detailed information about a specific collateral asset held by a user or a specific debt asset owed by a user, including balances, prices, and their value in a common base currency. The primary function allows callers to retrieve comprehensive liquidation details for a user, specifying a collateral and debt asset, and optionally a maximum debt amount to liquidate. This function calculates the maximum collateral that can be liquidated, the corresponding debt amount, and any protocol fees, considering factors like liquidation bonuses, E-Mode configurations, and minimum leftover amounts to avoid dust balances. Access to these functions is public, allowing any external entity to retrieve this data.
