This contract serves as a descriptor for NFT token positions within a Uniswap V4-like ecosystem, generating a data URI containing JSON metadata for a given position. It maintains immutable references to a Pool Manager contract, the address of the wrapped native token, and a byte-encoded label for the native currency. The primary operation is `tokenURI`, which takes a position manager contract and a token ID, retrieves the associated pool and position information, and then constructs a detailed metadata string. This metadata includes information about the currencies involved, their symbols, decimals, tick ranges, fees, and the current tick. A key mechanic involves determining the base and quote currencies for readability, potentially flipping them based on a predefined priority order for specific mainnet tokens (USDC, USDT, DAI, ETH/WETH, TBTC, WBTC). The contract also provides helper functions to retrieve the native currency label and to determine the priority of a currency for ratio flipping. If an invalid token ID is provided, the contract will revert.
